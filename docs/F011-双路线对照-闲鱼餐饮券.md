## 可观察差异

**立场相反。** 半佛版的落点是劝退——"能做，但别当主业""想靠它发财，劝你还是洗洗睡吧"。钱十七版的落点是推进——把四个环节讲完，给下一步动作。这不是写法差异，是两个 IP 的人设差异：半佛是评论者，钱十七是做项目的人。

**结构逻辑不同。** 半佛版按"设疑 → 拆机制 → 泼冷水 → 再泼一遍 → 给建议 → 升华"推进，节奏由情绪驱动。钱十七版按 F1 框架的真实环节推进：拿货 → 上架 → 成交 → 交付，每环解决一个问题并带出下一个。

**长度差一倍。** 半佛的语料是公众号长图文，钱十七的语料是短口播。同题下这个差距是 DNA 自带的，不是本轮的执行偏差。

**CTA 形态不同。** 半佛版收在身份签名（"我是半佛，我们下期再见"）。钱十七版按 A6 收在"资源/下一步 → 动作 → 身份"，但**目标内容没有提供真实资源**，所以退到 DNA 允许的降级形态：评论问题 + 收藏提醒 + 下期主题 + 身份。没有编造资源包或引流钩子。
