# 审稿清单（一页，给收尾用；代替读整本规则表）

> 2026-09-11 定。来源：用户 9 月 6 日到 10 日对稿件的全部判定，归成十四条，后来陆续加到十八条。审稿只按这一页过，机器退回级另由 `check-all` 报。改完只报"改了几处、哪几类"。

## 一、句子层（用户判"不通顺 / 什么意思"的根子）

1. **话说全**：省了主语宾语的补回来；一句两个意思拆两句；判断句用"是……的"（我一开始也是这么算的）；报数带名词加"是"（排最前面那条商品是七百七十多人想要）。
2. **不砍连接词**：但是、首先我们来看看、这里特别强调一点、所以、那么——一个不删。字数多了删整句。
3. **不用比喻、不造词、不起名**：到期的钟、挤不进去、吃掉流量、命门、口子、盘面、自带标签、排着队——全换白话。
4. **人话动词名词**：扛→负责、兜里→到手、最要紧→最重要、核过→核对过、进过→搭建过、开→开通、设成→设置成、这边→删。
5. **代称不用**：起了名就用名（引流款那一档 / 利润款那一档），不说"低价那档 / 贵的那档"。
6. **金句化、对仗、整齐收口一律拆平**：退的是你的时间 / 差别从这一步分开 / 说到底……——改成平铺的一句事实。

## 二、装置层（我方规定过、用户判 AI 味的）

7. 分段词只用**点**：点数照内容定（两到四点），不是分点讲的（跟着一单走、问答式等）就不编号。不用块、三件事、三条路（真是操作步骤的"第一步"可以）。
8. **妥妥的**不用；**有人是这么干的 / 做闲鱼的都知道 / 做闲鱼的还有一个说法**不用，经验直接当事实说，用本期名词。
9. **预告句不用**："最关键的是第几点""一定要看完""漏听了就坏"。
10. **承诺句不用**："学完当天就能接单""十分钟一单""必卖爆""一定出单"。
11. **交底有才说、只说一遍**：稿里真有推算的流水才说一句，并点明是哪个数（如"前面说的一天几十块，是我推算的流水，没扣成本"）；没有推算就不说（用户 2026-10-02）。
12. **为过机器硬塞的词删掉**："进价和差价这期都不给数"这类并排硬念的句子改成人话：这一块钱里能留下多少我没核对过，所以不给你算。
13. **售后 → 退款**（正文）；框架句可说"售后怎么办"。**退货 / 快递 / 运费 / 签收**虚拟品不出现。

## 三、内容层

14. **小白检查**：逐段问"一个还没开始做的人听得懂吗"，撞上受众漂移信号（拿两个卖家对比、预设你已经在跑、预设你已经有货源、没先回答"这生意到底成不成立"就进操作细节、用行业黑话不解释）的段落改掉，详见 `docs/audience-lock.md`。
15. **顺口检查**（用户 2026-10-02 定，治跳接）：按口播大声读一遍。句与句之间没过渡、每句甩一个新信息的；一句硬塞两三件事、中间没连接的；话题突然转弯的——补一句或半句承接（你可能不知道 / 结果 / 原来 / 说到这儿你可能会担心 / 那价格怎么定呢？/ 你别看……），塞多了的拆开连上。同一个承接说法一篇里别超过两次，也别篇篇都用同一个；拆成一行五十字以内时不许把连接词拆没。例：「你的店里要分两档」→「那价格怎么定呢？你的店里要分两档」（学方向，不照抄）。
15b. **前后矛盾检查**（用户 2026-10-02 定）：通读一遍，找前面说 A、后面说反 A 的地方——钱从哪来、定价、交付、主推做法——以选题核心为准改顺。用户点名的例子：剪映工程那条短视频前面讲"低价是靠网盘拉新赚钱"，后面又套一句"我从来不打价格战、价格就照一块左右定"的通用道理，自己推翻自己。通用道理跟这门生意的钱路对不上的，删掉。
15c. **"拼多多"一律写"多多"**（用户 2026-10-02：「"拼多多"会被投诉」）：口播稿、上屏字里都不写"拼多多"三个字；文件名、选题名不改。
16. **结尾不写风险大段**（用户 2026-10-02 定，所有文案）：不写"风险集中说一次 / 风险这里我只说这一遍"起头、再接几句规则封号和"想清楚再决定做不做"的那种段落；正文讲到某一步时顺带的一句具体提醒照留。
17. **"没货"类说法只给像卖货的生意用**（用户 2026-10-02 定）：资料、软件、服务类稿里出现「手里没货 / 一件货都没有 / 不用囤货 / 不压货 / 不用先买货压钱」即改（门槛换成"一部手机就能做""上手简单"）；只有引流类（淘客）、卡券转卖可以说。开头的钩子要从"这门生意让外行最意外的一点"来，不用万能反差。
18. 不贬同行（差评、退款多、杂货铺不说）；不引旧期号；页面文字转述不照念；没授权的差价不给数；不写躺赚 / 稳赚 / 月入 / 百分百 / 纯利润 / 零成本 / 白嫖 / 包上热门；三套之间同一事实换说法，故事经验不重。
