# 审稿清单（一页，给收尾用；代替读整本规则表）

> 2026-09-11 定。来源：用户 9 月 6 日到 10 日对稿件的全部判定，归成十四条。审稿只按这一页过，机器退回级另由 `check-all` 报。改完只报"改了几处、哪几类"。

## 一、句子层（用户判"不通顺 / 什么意思"的根子）

1. **话说全**：省了主语宾语的补回来；一句两个意思拆两句；判断句用"是……的"（我一开始也是这么算的）；报数带名词加"是"（排最前面那条商品是七百七十多人想要）。
2. **不砍连接词**：但是、首先我们来看看、这里特别强调一点、所以、那么——一个不删。字数多了删整句。
3. **不用比喻、不造词、不起名**：到期的钟、挤不进去、吃掉流量、命门、口子、盘面、自带标签、排着队——全换白话。
4. **人话动词名词**：扛→负责、兜里→到手、最要紧→最重要、核过→核对过、进过→搭建过、开→开通、设成→设置成、这边→删。
5. **代称不用**：起了名就用名（引流款那一档 / 利润款那一档），不说"低价那档 / 贵的那档"。
6. **金句化、对仗、整齐收口一律拆平**：退的是你的时间 / 差别从这一步分开 / 说到底……——改成平铺的一句事实。

## 二、装置层（我方规定过、用户判 AI 味的）

7. 分段词只用**点**：点数照内容定（两到四点），不是分点讲的（跟着一单走、问答式等）就不编号。不用块、三件事、三条路（真是操作步骤的"第一步"可以）。
8. **妥妥的**不用；**有人是这么干的 / 做闲鱼的都知道 / 做闲鱼的还有一个说法**不用，经验直接当事实说，用本期名词。
9. **预告句不用**："最关键的是第几点""一定要看完""漏听了就坏"。
10. **承诺句不用**："学完当天就能接单""十分钟一单""必卖爆""一定出单"。
11. **交底只说一遍**：一句"前面的数是我推算的流水，没扣成本"，不再加"不是到你手里的利润"之类第二句。
12. **为过机器硬塞的词删掉**："进价和差价这期都不给数"这类并排硬念的句子改成人话：这一块钱里能留下多少我没核对过，所以不给你算。
13. **售后 → 退款**（正文）；框架句可说"售后怎么办"。**退货 / 快递 / 运费 / 签收**虚拟品不出现。

## 三、内容层

14. 不贬同行（差评、退款多、杂货铺不说）；不引旧期号；页面文字转述不照念；没授权的差价不给数；不写躺赚 / 稳赚 / 月入 / 百分百 / 纯利润 / 零成本 / 白嫖 / 包上热门；三套之间同一事实换说法，故事经验不重。

## 固定句（2026-09-08 用户裁定，一字不改）

- 「我是圣矾。」下一行「学闲鱼，找圣矾。」
- 「这期视频干货非常多，建议先点赞收藏。」
- 「这期视频就到这儿，学闲鱼找圣矾，我们下个视频见。」
- 资料钩子：「最后圣矾给大家准备了〔彩蛋〕，这些资料圣矾分享给大家。」「有需要的同学在评论区扣个〔关键词〕，圣矾看到就发给你。」彩蛋只从五个固定彩蛋（入门版 / 自动发货工具 / 违规词 / 爆品表 / 官方知识库）的口播说法里选一个整段替换（量词由彩蛋自己带，不在第一句写死"一份"），不写"无条件"。
- 合规句：「算不算违规，上架之前自己去搜一下平台规则。」
