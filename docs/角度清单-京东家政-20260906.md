## 已经写过的两篇占了哪些角度

- 钱十七 v10.2 定稿：全链路走一遍（找券 / 怎么挂 / 交付），偏角度 2 + 3 的合集。
- 半佛 v3.1 定稿：全链路 + 泼冷水，偏角度 3 + 5。
- 过来人 v2：角度 1 + 3 + 4 各一块。

所以下一篇最不撞的是 **4 规则先于钱**、**5 三家店三种活法**、**6 需求怎么验**。主线程推荐先写 **4**：合规是这批闲鱼经验里最厚的一层（6·1 新规、经营性认定、违禁词），也是用户自己的经历（起诉三次、被下架）最硬的地方。

## 每篇的配料规矩

- 事实只取该角度那一到两环，其余环节一句带过或不提；三个数（卖价 / 进价分档 / 差价约十块）每篇都说，官价是买家省的。
- 故事：本人经历写"我"，同行案例写"我见过一家店"，公众号经验写"有人这么做 / 行业里一般"。
- 闲鱼经验每篇挑五到八条，只从该角度对应的环节挑，同一条经验两篇不重复用；⚠️ 的剥数字用，🚫 的不用；打架的观点成对引或不引。
- 事实链的一跳规则、九条不入稿、收入数字不写，照旧。
