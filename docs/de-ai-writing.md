# 去 AI 味写作规则

> 写给生成器和审稿人看。大白话，落到笔上就能对照。
> 依据：`docs/research/de-ai-flavor-20260823.md`（22 条特征、第 5 节②、第 6 节冲突表）与 `docs/research/ai-flavor-diagnosis-20260823.md`（第 4 节：该改的 / 别冤枉的 / IP 本身就有的）。
> 具体阈值数字不写死在这里，统一放 `engine/naturalness/ai-flavor-rules.json`，本文只引路径。

**AI 味不是"用了短句、反问、编号"，那些是 IP 本人的手法。AI 味是"太干净、太整齐、太压缩、和别的稿撞骨架"——一句话压到人嘴里说不出来，一段话换个 IP 也能原样用。** 下面四组规则就照着这四个毛病改。

---

## 一、必须做的（正向规则）

每条配一个坏例→好例，例子都是自造，别照抄，也别当模板复用。

1. **保留助词和宾语，不写电报体。** 为了显"高级"把主语、宾语、"是/的/了"删到不像人话，就是最刺眼的 AI 味。
   - 坏：真做时拿出来对。
   - 好：真开始做的时候，你把这条翻出来对一对。

2. **"的"字结构要有中心词。** 句尾一个悬空的"的"把宾语吞掉（"只收说得清出处的""挑对的"），是低频但高毒的 AI tell，清零。
   - 坏：只收说得清出处的。
   - 好：只收那种你能说清它从哪来的券。

3. **允许口语赘词和插入语。** 真人口播里"其实、就是、怎么说呢、我跟你讲"本来就多，它们负责喘气和转场，不是废话。别为了精炼把一段话洗得一个赘词都不剩。
   - 坏：渠道最重要，选错就白干。
   - 好：其实吧，渠道最要紧，你要是选错了，后面基本白干。
   - 注意：按 IP 人格控量，不是越啰嗦越自然（钱十七偏干脆、少赘词；半佛可略多插入语）。

4. **句子长短要有落差。** 全篇清一色 15 字上下的中短句，就是"太整齐"。半佛尤其要"长铺陈 + 短猛砸"交替：先用一个长句把事铺开，再甩一句极短的定性砸下去。
   - 坏：这活儿不难。就是费时间。回报也一般。（三句全短，节奏平）
   - 好：这活儿说难不难，无非是把别人嫌麻烦的那几步一步步做完、做细、做到不出错。就是费时间。（长铺陈 + 短猛砸）

5. **具体名词留着。** 肯德基、50 的券、30 拿 38 挂、车厘子这类具体锚点是优点，是"人味"的来源，别为了去 AI 味把它们删成抽象词。
   - 坏：用低价券换取一定差价。
   - 好：五十的肯德基券三十拿到手，挂三十八卖出去。

6. **每篇至少两处"只有这个人、这件事"才有的细节。** 把"很多人都栽在这上面"换成一个具体的人、一个具体的场景、一个具体的数。抽象泛化是 AI 最爱，具体到不能再具体才是真人。

## 一之二、用这个 IP 自己的词（用词层）

**语气对了、句式对了、稿子还是"不像这个人"，问题往往出在实词上——用了这个 IP 从来不用的词。** 写稿前必须读过该 IP 的词表（`ips/<IP>/corpus/lexicon.json`）和原始语料，实词优先用 IP 自己常用的：

- **钱十七的业务词**：货源 / 渠道 / 出单 / 上架 / 养号 / 权重 / 话术 / 客单价 / 选品 / 售后 / 发货 / 详情页。
- **半佛的评论腔词**：按半佛词表，评论腔里保留具体名词（品牌、平台、职业、产品线），不用方言词硬装口语。

四个共性毛病，全部零容忍：

1. **不缩略**：业务名词写全，别为了省字砍成单字。
   - 坏：先解决从哪**找货**。
   - 好：先解决从哪**找货源**。

2. **不生造 / 不用书面搭配**：字典里不搭、圈内人不这么搭的词组不许用。
   - 坏：券**散在**企业福利、银行联名这些**口子**里。
   - 好：券**都在**企业福利、银行联名这些**渠道**里 / **藏在**……渠道里。

3. **不硬装口语 / 不用方言腔**：这个 IP 本人不用的口语词、方言词，别为了"显得像人"硬塞。
   - 坏：**说不说得清打哪来**。
   - 好：**得搞清楚渠道从哪来** / 能不能搞清楚渠道从哪来。
   - 同类要拦：掂量掂量、蹲得住、拿捏、盘一盘等——不是钱十七会用的口语，直接换成"想清楚 / 撑得住 / 搞明白"。

4. **不压缩**：能不能 / 说不说得清 / 做不做得到 这类反复问句，钱十七很少用，改成"能不能……"或直接陈述。
   - 坏：**说不说得清**打哪来。
   - 好：**能不能搞清楚**从哪来。

判据：拿稿子里的每个实词回原始语料搜一遍，本 IP 从没用过的实词一律换。这一层由 `npm run check:lexicon` 出报告（warn 级、非 block，语料小，最终要人判）。

## 二、必须少的（密度规则）

这些手法单次出现无罪，**重复、每段一顶、每节一收才是 AI 味**。每个 IP 的上限口径见 `engine/naturalness/ai-flavor-rules.json`，本文不写死数字。

- **破折号（——）**：两个真人几乎都不用，别拿它抖包袱、接补充、做揭晓。基本不用为佳。
- **冒号金句壳**（"第一条规矩：……"这种"短语：短语"当结论）：控量。
- **引号**（给普通词强行加引号、框金句）：控量，尤其钱十七仿写偏离最大。
- **总结壳口头禅**：说白了、这就是、一句话、记住一条、核心是、本质上——硬给观点贴帽子再端出来，删壳直接说。
- **"不是 X 是 Y" / "不是 X 而是 Y" 句壳**：降密度，不清零（半佛本人高频，见第四节）。
- **连续反问**：允许反问，拦"连续多句机械轰炸"；反问之间要夹陈述句喘气。
- **每节一句金句收尾**：允许金句，禁每节都甩、禁对仗过密到读不出口。

---

## 三、必须不同的（跨稿 / 跨 IP）

最强的 AI 味铁证是"两个本该不同的 IP，产出撞上同一句骨架"。下面这些位置每个 IP 各有各的一套，**且同一 IP 的多篇之间也要换**（连接壳轮换库的缺口见 `docs/variation.md`）：

- **规矩句 / 核心判断句**：钱十七的"只收来路清楚的"和半佛的"讲不清打哪来的不碰"不得是同一句骨架。
- **结尾动作序列**："打开闲鱼 → 搜 → 发评论区"这一套两个 IP 不得同用。
- **互动句式**（点赞 / 收藏 / 三连 / 公屏的说法）。
- **下期预告句式**。

判断口径：跑 `npm run check:repetition`，跨 IP、同 IP 不同选题的重合率见 `engine/variation/repetition-rules.json`；写下一篇前先跑 `npm run ledger` 避开前几篇用过的开头、结尾、跨稿重句。

---

## 四、不能一刀切的（按 IP）

去 AI 味不能连 IP 的签名一起杀。以下是 IP 本人风格，只调不清零：

- **钱十七的编号分点与对仗**是本人签名。要拆的是"点点等长、四平八稳、每点都是动宾+动宾+动宾对仗"的僵硬，**不是编号本身**。
- **半佛的短句成行、反问、"不是 X 是 Y"、金句收尾**是本人签名。问题只在密度（半佛短稿问号约 4 倍超标），**降密度即可，别取消**。

一句话：单次出现是风格，重复 / 空洞 / 跨稿撞骨架才是 AI 味。

---

## 五、自检顺序

写完一篇，三步走，缺一不可：

1. **跑程序检查**：`npm run check:ai-flavor -- <文件> --ip <IP>`（阈值按该 IP 口径，见 `engine/naturalness/ai-flavor-rules.json`）。
2. **跑用词核对**：`npm run check:lexicon -- --ip <IP> --drafts <文件>`。逐条过目"IP 从未用过的词"清单——warn 级、非 block，语料小，机器只出候选，最终必须人判：真是这个 IP 不会用的词就换，是本人的低频真实词就放行，并考虑回补到 `ips/<IP>/corpus/lexicon.json`。
3. **人工读一遍**，只问两个问题：
   - 有没有一句话是**"人嘴里说不出来"的压缩句**？（一口气塞多层因果、删到不像口语）——有就拆开。
   - 有没有一段是**"换个 IP 也能原样用"的**？（规矩句、结尾序列、互动壳撞了别的稿）——有就重写。

三步都过，才算去掉了 AI 味。**但请记住：六道门禁全过只代表"没有明显 AI 味"，不代表"好"；"好"的标准是这个 IP 的读者听不出换了人。** 终极判据只有一条：改完能不能感到是**一个具体的人**在说话。
