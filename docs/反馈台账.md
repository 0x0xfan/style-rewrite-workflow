## 反馈怎么给（给用户的两种省事格式）

1. **逐段勾叉**：稿子按段编号发给你，每段回一个 ✓ 或 ✗，✗ 后面最多加一个词（如"像说明书""不算账""句子太齐"）。
2. **二选一**：同一个位置给两个版本（比如两个开头），你回 A 或 B。

整篇一句"没味"我们也收，但每轮能改对的概率低得多。

- 2026-09-04 解冻待办：A7 开场池第 4 条「最要命的那一关我放在最后讲」本身是悬念式预告，与盲测第 2 条（转场不用悬念）冲突；电影票用过一次已换写法。解冻后从池里撤掉。
- 2026-09-04 盲测四条改法（给写稿会话，不改任何门禁）：
  1. **算账句**：他是乘出一个大整数再下断语（"一份三十，一万份就是三十万"）；我们是精确小数加免责（"一天出两张，一个月两三千，这是流水不是利润"）。改法：每篇至少一处把差价乘到月流水的大整数，语气笃定；免责不要跟在同一口气里，挪到别处单独一句。
  2. **转场句**："这N块里最要命的是第M块，漏听了就坏"这种悬念预告，用户的耳朵判为 AI。他的转场是平铺直叙的枚举加复述（"一共三点，注册、养号、包装。先说第一点，注册"）。改法：全篇删掉悬念式预告（含残留的"最要命的是第M"），换成枚举加复述。
  3. **人设腔**：我们一段里叠了醒醒吧、拜托、不香吗三个口头语，并且每段都用反问收尾，落得太齐；还有"递到真正需要它的人手里"这种暖心公关话。他一段最多一个口头语，有一句带火气的粗话（"凭什么去抨击自己的道德底线"），结尾不一定收得漂亮。改法：每段口头语最多一个；不要每段都用反问收尾；删公关话；允许一两句不修饰的硬话。
  4. **读屏报数**：连本人纯读数字的那段（#04）用户都判为 AI，说明"对着屏幕念数字"这种段落本身就没味。改法：每段读屏必须落到一句判断或一笔钱，不许连续两段只报数。
