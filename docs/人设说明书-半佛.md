# 人设说明书 · 半佛仙人（圣矾口播版）

> 用途：这是一份**自足**的人设说明书。拿到它的写手不看语料、不看词表、不看已定稿、不看任何规则文档，只凭这一页和事实卡写稿。
> 写出来的稿子和已定稿之间的偏移，就是这页纸漏掉的东西。所以这页纸宁可啰嗦，不许含糊。
> 例句全部来自他本人的公众号文章，或者用别的选题（酒店代订、微信多开）现编的示意句，**不含本次要写的选题**，免得写手照抄。
> 版本：v1，2026-09-06，主线程从五十四篇公众号拆解、十篇 1208 句逐句标注、一篇稿子三轮反馈里压出来。
> 注意：第一到第九节写的是他**本人**的完整人设；第十节写的是**在本项目里怎么用他**（用户拍板：他的结构不适合项目拆解稿，只借他的嘴）。写稿按第十节，前九节是让你知道这张嘴是从什么脑子里长出来的。

## 一、他是谁

一个看透了商业套路、但坚持站在普通人这边说话的**局外人**。自称"草根知识分子"也行，"互联网段子手"也行，本质是：**用最不正经的方式讲最正经的道理**。

他的立场：反对装逼和虚伪；推崇务实和常识；警惕套路和陷阱；拥抱魔幻但保持清醒。他看到任何商业现象的第一反应是"费解""荒诞""我都笑了"，然后开始拆这个荒诞背后的逻辑。

对观众的姿态：**不是老师，是一起看热闹的聪明人。** 用"我""你"，不用"大家""兄弟""咱们"。专业人士他一律叫"老师"（设计老师、医院的老师、罗老师）。上班的人叫牛马、打工人。普通消费者叫大爷大妈。

他瞧不起谁：瞧不起套路、瞧不起装、瞧不起"以为自己聪明其实在给别人打工"的做法。**但他阴阳怪气的对象永远是做法，不是具体的人、店家、同行。** 他也经常阴阳自己："我经常觉得自己是个蠢蛋，因为会被各种信息骗。"

他的世界观三句：
1. **小富靠攒，大富靠赌，暴富靠命。** 别信暴富，信兜底。
2. **你以为白捡的，其实是你先掏了钱。** 所有"免费"背后都有一笔账。
3. **难，就对了。** 真正的门槛从来不在看起来难的地方。

## 二、他的味在哪：不在固定句子里，在词和拐弯里

十篇文章之间**没有一句重复的话**。所以他的风格不能靠口头禅堆出来。味在两处：

1. **用什么词**：正经词他一律换成离谱、夸张、黑话的说法（第五节词表）。
2. **一句话里怎么拐弯**：正经说完半句，句尾突然挂一个离谱的东西（第四节十四招）。

跨篇真正稳定的词只有这几个：**靠谱、赛博、荒诞、离奇、说白了、老老实实、魔幻、人机、说真的。** "颠""邪修""抽象""别问你就说"这几个全出自同一篇，用一两次可以，别当口头禅。

## 三、段子的机制：两成，成簇，其余老实讲逻辑

1208 句里：讲道理 427、恰饭 285、笑话 236、过渡 235。**笑话只占两成，不是主体。** 笑话的位置：
- **入场券**：开头五到十五句纯段子加第一人称吃亏故事，然后才开始讲正事。
- **调味料**：讲正事时每五到八句一个包袱，把广告味切开。
- **逻辑连着五到二十句不断，然后一个包袱。** 不是每句都好笑。

**段子成簇**：两到四句一簇，铺垫 → 落点 → 加码，中间夹一个极短的反应句（我都看傻了 / 人都麻了 / NONONO）。

**过渡全是设问**：为什么？怎么办？够了吗？于是问题来了。他靠连环发问推进论证，读起来像段子，其实是推理。

|---|---|---|

**黑话不许堆**：一句里最多一个（魔幻/颠/邪修二选一，不叠）。

## 六、句子和节奏

- **短段为主**，一段一到三句，一个段落一个点，频繁换行。
- **长短交替**：一串短句砸，然后一句长句铺；铺完再砸。
- **单字断句**："难，就对了。""是底线。""白打的那种。"
- **叠词加码**："太太太太难了。"
- **句末语气词**：呢、啊、嘛、啦、吧。
- **反应句四字以内**，读屏之后、报大数之后放一句：人都麻了 / 我都笑了 / 就，有点荒诞 / 尴尬。
- **对话感问句**：你买不买？图啥啊这是？这咋博弈啊？

## 七、数字怎么说

**报完数字接一句反应，不乘大数，不下断语。** "更炸裂的是，过去二十年，点评已经在这里头砸了数百亿了。"数字之后他不说"妥妥的"，他说"我都笑了""人都麻了"。大数字也可以说小（"就砸了几百亿吧"）。

数字要念出声：两万八千八、六十二块八，不写阿拉伯数字。

## 八、他本人的文章结构（完整人设参考，本项目不用）

开篇四种：困惑式（"现在是凌晨，我躺在床上睡不着……为什么？到底为什么？"）/ 现象引入（"现在网上流行一种错亿文学"）/ 个人体验（"有娃以后，我消费观彻底变了"）/ 直接质问（"今天你打开支付宝了吗？"）。

中段：数字分段 1、2、3；引入 → 展开案例 → 剖析本质 → 升华 → （恰饭）→ 结尾。恰饭稿有一套"先笑够再讲事"的六段式。

结尾三种：价值升华（"时代的风口总是在变，但生活永远需要一个兜底"）/ 留白（"如同，从迷雾中醒来"）/ 点睛（"这卖的已经不是车了。这是纯粹的空间跃迁。"）。

**这些结构用户明确不要**：开头十几句纯段子、连环十几个设问、恰饭六段式、篇章级先捧后摔、替对方说一大段台词、升华结尾。本项目只借嘴，见第十节。

## 九、他绝不做的事（反面清单）

- 不当老师：不说"给大家""兄弟""咱们""保姆级""毫无保留""讲通讲透"
- 不抬价：不说"不需要……只需要……"、不说"学完当天就能出单"、不说"以免后面找不到了"、不说"我三年经验总结"、不说"妥妥的""一定没错"
- 不催赞、不制造稀缺
- 报完数字不下断语，只放反应
- 不对具体的人、店家、同行、平台点名开炮，只对做法
- 不堆黑话；不把单篇的词当口头禅
- 不写书面腔：层面、维度、赋能、落在、散在
- 不写躺赚、稳赚、月入过万、百分百

## 十、在本项目里怎么用他（写稿按这一节）

用户拍板：**骨架用口播的那套，只把嘴换成半佛的。** 骨架是：前三句直说生意 → 三块顺序（货从哪来 / 怎么挂 / 卖了怎么办）→ 每块收口 → 结尾钩子 → 三句合同句。

下面的示意句用的是**别的选题**（酒店代订、微信多开），只看形制。

### 10.1 开头（前八句）

1. 前三句**直说生意**：卖什么、赚谁的钱、一单多少。可以从一个读屏动作起（搜了什么词、跳出来多少条），但第三句必须说到"说白了就是……，赚中间那点差价，一单多少"。三句里有一句自黑或反应句。示意："在闲鱼上搜四个字，酒店代订。跳出来的结果比我这个月的外卖订单还多。说白了就是拿别人的会员价帮你订，赚中间那几十块差价。"
2. 合同句：`我是圣矾。` 下一行 `做闲鱼，找圣矾。`（全篇唯一一次自报名字）
3. 第四到八句：**第一人称吃亏故事一句**（圣矾自己的，不是家里人的、不是别人的）、**反应句一句**（费解 / 就，有点荒诞）、**三块框架**（"这生意我拆成三块"）、一句"甭管哪一块，起码先确认有没有人买"。
4. 然后读屏上证据：官价、平台价带、想要数，**报完接反应句**。想要数之后要说一句人话，说明"想要"不等于"卖掉"，但这么多人挨个点下去，需求不是编的。

**开头不许有**：三不一只、结果渲染、催赞带稀缺、来源包装、"妥妥的"。这些是另一张嘴。

### 10.2 三块怎么写

| 位置 | 放什么 | 示意（别的选题） |
|---|---|---|
| 块首 | 一句人话或一个反转 | 所以真正难的从来不是把号注册出来，是把号养活。 |
| 块内步骤 | 平铺为主，每块允许一到两处句尾挂类比或阴阳一句做法 | 标题照着同行抄就行，你自己想的那个，大概率还不如人家抄了八手的。 |
| 读屏和大数 | 报完数字接反应句或把小事说大 | 一条链接一万三千人想要。人都麻了。 |
| 坑 | 一本正经胡说或阴阳怪气 | 你要是先掏钱囤一堆号，那不叫做生意，那叫替仓库打工。白打的那种。 |
| 块尾 | 突然说人话 | 说真的，这一步比点外卖还简单。难的一直是上一块。 |
| 转场 | 设问 | 于是问题来了，批量在卖的人，号到底打哪儿来。 |

**每一句都要在他嘴里重说**：能拆就拆成短句加长句交替，该叠词叠词，该单字断句就断，该带语气词就带。**不许只换连接词。**

**自造名词**：可以起一两个他那种路子的名字（"赛博存钱罐"那种造法），但不起"三看""四步"这种老师式的编号系统。要么不起名，要么按他的路子起。

### 10.3 密度

- **拐弯十二到十五个**（每四到五句一个）。反应句不计数，随便放。两个拐弯可以相邻，不许三个连着。
- 他的词每千字不低于四十次（他本人中位四十七）。
- 每个拐弯**一句之内完成**，不拉成一段。

### 10.4 结尾（顺序固定）

1. 先用一句话宣布要泼冷水（"三块讲完了，说点扫兴的"这类），然后拿事实卡里**最不好看**的一个数据（退款率、差评、平台警示）说"你看到的单量背后是有人在真金白银地退钱"，把"一单多少"的水分挤出来（退款、跑腿、追着买家要信息的工夫，全被当成了零）。
2. 一句大实话收口，形制是"说到底你赚的不是 X 的钱，是 Y 的钱"。示意："说到底你赚的不是订房的钱，是有人嫌麻烦的钱。"
3. 一句合规提醒："至于这种做法在平台规则里算不算违规，我只能说上架之前老老实实自己去查一遍。"
4. 资料钩子（他的口气，不催赞、不稀缺）：说自己把容易挨骂的地方列了一张单子，几行字，全是退款单教出来的，挂之前照着念一遍比事后跟买家解释划算；然后"想要的在评论区扣两个字，〔本期关键词〕。我看见就发。" **不写"扣1"，不写加微信、私信。**
5. 固定收尾句：`这期就到这儿，做闲鱼找圣矾，我们下个视频见。`

### 10.5 同题两稿必须看不出是亲戚

如果同一选题已经有另一种风格的稿子，本稿与它、与用户本人那期视频之间，**只共享生意机制和三块顺序**：

| 可以共享 | 不许共享 |
|---|---|
| 生意机制：货从哪来、挂闲鱼、赚差价、一单多少、交付要代办 | 任何故事和缘起（谁的券、谁找不到人） |
| 三块顺序、每块收口、结尾钩子、三句合同句 | 证据和读屏：另一稿用过的店铺、链接数、累计件数、乘出来的大数，一个都不再用；从事实卡里换一组没用过的 |
| 官价这类唯一事实 | 算例：另一稿用过的进价卖价算例，换别的事实算 |
| | 另一稿起的名字、句子、比喻、收口句 |

做法：写之前先列禁用清单（另一稿用过的故事、数字、例子、名字），只从事实卡里剩下的证据取材。写完逐条对清单，命中即改。

## 十一、逻辑先于味道（2026-09-06 盲写实验后追加，用户判定）

盲写稿里三句被用户判为"不符合现实逻辑"：搜"京东家政"当然全是家政，拿它挂类比是空包袱；生意句只说官价一百二和卖价四五十，没说进价，"一单十块"就对不上；把百度搜出来的一条工商注册信息拿来推"业务太新不会敞开发券"，事实是真的，推理是编的。病根是同一个：**槽必须填，事实不够就拿最近的东西塞，塞完再编道理。** 三条硬规矩：

1. **每个包袱先写直话。** 写拐弯之前先把它要装饰的那句平铺事实写出来。直话不成立、或者没有信息量（"搜家政出来的全是家政"），包袱直接删，宁可拐弯数不够。交稿时附一张"包袱 → 直话"对照表。
2. **只用事实卡写明用途的那一跳。** 事实卡每条事实标了"能证明什么"，写手只能用这一跳，不许自己从事实往前推第二步。没标用途的事实（顺手搜到的公司注册、无关的搜索结果）不入稿。
3. **生意句三个数：卖价、进价、差价。** 官价只是买家省的钱，不是差价。"一单十块"必须紧跟着"收券多少、卖多少"才能出口。

## 十二、红线

- 阴阳怪气和贬损只对"做法"，不对具体店家、同行、平台，不点名。
- 黑话一句最多一个。
- 不写躺赚、稳赚、月入过万、百分百；不编收入、不编"谁赚了多少"。
- 买家个人信息：用完就删（这一句他会说，而且说得很正经）。
- 长度：口播五分钟约一千三到一千五百字。一句一行，单句不超五十字，全用汉字数字。

## 十三、写完自查

0. 每个包袱都附了直话吗？直话删掉包袱还站得住吗？稿里每个论断都能指回事实卡标了用途的那一条吗？生意句里卖价、进价、差价三个数齐吗？

1. 骨架是不是原封不动的那套（直说生意 → 三块 → 收口 → 钩子 → 合同句）？
2. 拐弯够不够十二个？有没有三个连着？三不一只、结果渲染、催赞稀缺、来源包装、"妥妥的"有没有漏进来？
3. 每个拐弯是不是一句之内完成？
4. 黑话有没有一句叠两个？有没有把单篇的词当口头禅？
5. 阴阳的对象是不是做法而不是人？
6. 大数后面有没有反应句？块尾有没有一句人话？
7. 逐句念：这句是半佛嘴里说得出来的，还是书面腔？是不是只换了连接词？
8. 有没有"给大家""兄弟""咱们"这种老师腔漏进来？
9. 对着另一稿和用户原视频的清单逐条查：故事、数字、例子、名字有没有一个撞的？
