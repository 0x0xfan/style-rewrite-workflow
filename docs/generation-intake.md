# 文案生成前必问

**每一次文案编写任务开始前，先问清楚这两件事，得到回答再动手。不要靠猜，也不要"先写一版看看"。**

## 必问项

### 1. 短视频还是长视频？

| | 长视频 | 短视频 |
| --- | --- | --- |
| 诱导设计 | 照旧，可以用收益数字、收益推算、资源 CTA | 换形式：悬念、反差、信息缺口、损失厌恶、互动钩子 |
| 合规层 | 不走 | 必须过 `npm run check:compliance` |
| 发布平台 | 不受本项目合规层约束 | 小红书 / 抖音 |

转换方法见 [platform-compliance.md](platform-compliance.md)。

**两种不是互相替代的关系。** 同一个选题经常两版都要，长视频版承载完整信息和转化，短视频版负责触达。

### 2. 用谁的风格？

当前可选：

- **钱十七** —— `ips/钱十七/dna/钱十七-DNA-重构版.md`。闲鱼口播，利益驱动、确定语气、边讲边推进。证据链完整但状态仍是 `draft / review_only`。
- **半佛仙人** —— `ips/半佛/dna/半佛-DNA-可执行版.md`。商业评论，局外人视角、吐槽、反常识。手写档案，无证据锚点。

新增 IP 见 [commands.md](commands.md) 的「能力一：风格拆解」。

## 建议同时确认

这两项没被明确指定时，按下面的默认值走，并在交付时说明用了什么默认值：

| 项 | 默认 | 什么时候必须问 |
| --- | --- | --- |
| 目标时长 | 长视频约 5–7 分钟；短视频按现有稿约 4–5 分钟 | 需要压到 60–90 秒时必须问——那要砍掉整段结构，不是删句子 |
| 受众起点 | 三类起点共存，开头分流，正文按最零起点写 | 见 [audience-lock.md](audience-lock.md) |
| 事实来源 | 用户提供的 contract | 没有 contract 时必须停，不能拿旧稿数字当事实 |

## 交付前：去 AI 味自检

写完、交付前必须过一步去 AI 味自检，别把"太干净、太整齐、太压缩、和别的稿撞骨架"的稿子交出去：

1. 对照 `docs/de-ai-writing.md` 的四组规则（必须做的 / 必须少的 / 必须不同的 / 不能一刀切的）。
2. 跑 `npm run check:ai-flavor -- <文件> --ip <IP>`（阈值按该 IP 口径，见 `engine/naturalness/ai-flavor-rules.json`）。
3. 人工读一遍：有没有"人嘴里说不出来"的压缩句？有没有"换个 IP 也能原样用"的段落？电报体与悬空"的"字句零容忍。

两步都过才算完成。IP 本人签名（钱十七的编号对仗、半佛的短句反问金句）只降密度、不清零。

## 为什么要硬性问

这个项目已经因为"没问就写"付出过四次代价，全是同一类问题：**生成前没锁死"讲给谁听、以什么形态发"**。

- 2026-07-29 至 07-31：三稿受众锁错，全部通过技术门禁，全部被拒。
- 2026-08-22：F011 对照稿第一版又写成面向已入行卖家；同一天，合规约束被理解成"把诱导删掉"，导致短视频版被写平。

两次都不是风格层的问题，是入参没问清楚。
