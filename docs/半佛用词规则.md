# 半佛用词规则（只借词，不借结构）· v2 修订稿

> 用户 2026-09-05 拍板：「半佛的文章结构并不适合写我那种项目拆解的文章，所以只用半佛的一些用词就行了，他的结构可以不用。」
> 依据：十篇公众号 1208 句逐句拆解（笑话 236 / 道理 427 / 恰饭 285 / 过渡 235）+ 词库 232 条。
> 这是写稿人看的规则，不是门禁。

## 〇、一句话

**骨架照钱十七线定稿的那套（直说生意 → 接缝抬价 → 块内平铺 → 收口），只把嘴换成半佛的。** 半佛的味不在固定句子里，他十篇之间没有一句重复，味在两处：用什么词，以及一句话里怎么拐弯。

## 一、什么算"词"（借），什么算"结构"（不借）

| 借 | 不借 |
| --- | --- |
| —— | 钱十七的抬价手法：三不一只、结果渲染、催赞带稀缺、来源包装、妥妥的式断语（它们是钱十七的嘴，不是骨架）|
| 他的形容词和名词（第二节词表） | 开头十几句纯段子加吃亏故事 |
| 句内拐弯：句尾挂一个离谱类比、字面夸实则损、把小事说大、一本正经胡说、自黑一句 | 一口气十几个短问句的连环设问 |
| 叠词加码、单字断句、句末语气词、反应句 | 恰饭六段式、先笑够再讲事 |
| 自造名词（赛博存钱罐、行业冥灯那种造法） | 替对方说一大段台词、复读上头 |
| 突然说人话（一串损话后一句大实话） | 篇章级的先捧后摔 |

## 二、词表：他的词 ← 正经词

造新词先看正经词在哪一列，再往那一列的方向找。

| 方向 | 他的词 | 正经词 |
| --- | --- | --- |
| **说一件事离谱** | 魔幻、荒诞、离奇、迷惑、费解、抽象、颠、邪修、人机、花里胡哨、幺蛾子、牛鬼蛇神、草台班子 | 不合常理、有问题、不专业 |
| **说一件事厉害** | 炸裂、吊打、超进化、人都麻了、能处、更 6 的、干到了、愣是、摁着 | 很厉害、差距大、做到了、坚持 |
| **说风险和责任** | 坑、掉坑、见坑识坑、兜底、翻车、作死、被生活毒打 | 风险、承担责任、失败、冒险、教训 |
| **说做法** | 玩法、玩透了、玩得好、套路、底层逻辑、顺风局、对线 | 做法、运营、规律、有利局面、争论 |
| **说人** | 老师（设计老师、医院的老师、罗老师）、牛马、打工人、大爷大妈、老板 | 专业人士、上班族、普通消费者 |
| **说钱** | 剁手、砸钱、一杯奶茶钱、账单比钱包的命都长 | 消费、投入、少量收益、亏损 |
| **口头连接** | 说白了、甭管、还是那句话、再说一遍、说真的、我只能说、我都笑了、就，、毕竟、尤其是、起码 | 其实、不管、重申、总之 |
| **加码手法** | 叠词（太太太太难了、很难很难很难、完全完全）、单字断句（难，就对了。是底线。）、句末语气词（呢/啊/嘛/啦） | 很难。完整句。 |
| **自造名词** | 赛博存钱罐、行业冥灯、黄金主理人、错亿文学、赛博朋克四合院、【物理】 | 不起名 |

跨篇真正稳定的只有这几个：靠谱、赛博、荒诞、离奇、说白了、老老实实、魔幻、人机、说真的。颠、邪修、抽象、别问你就说，全出自支付宝那一篇，用一两次可以，别当口头禅。

## 三、句内拐弯：怎么在不改结构的前提下抖包袱

每种一句话的做法，配他的原句和正经说法。

| 拐法 | 他的原句 | 正经说法 | 我们怎么用 |
| --- | --- | --- | --- |
| 句尾挂离谱类比 | 有去研究这个的功夫，还不如跟楼下大爷大妈捡纸皮更划算 | 研究这个不值得花时间 | 正经说完一句，句尾加"还不如…"或"跟…有啥区别" |
| 字面夸实则损 | 好啦，这回罗老师可高兴啦 | 他这下有得打了 | 只对做法阴阳，不对店家、不对同行个人 |
| 把小事说大 | 一个五菱在停车场，解决所有战场 | 一辆车能覆盖多种场景 | 说券、说店铺数据时用 |
| 一本正经胡说 | 离河边远点，水深危险 | 别做这种梦 | 说坑的时候用 |
| 反过来自黑 | 我经常觉得自己是个蠢蛋，因为会被各种信息骗 | 我常被误导 | 来源包装那句可以用：圣矾自己先踩过 |
| 突然说人话 | 你可以不懂车，但是大家真懂七万块 | 不懂车也知道七万块意味着什么 | 一串损话后落一句大实话，正好当块尾收口 |
| 反转 | 观点不仅不新，还很旧 | 观点不新鲜 | 前半句立、后半句拆，一句之内完成 |
| 反应句 | 我都看傻了 / 人都麻了 / 我都笑了 | 删掉 | 读屏之后、报大数之后放一句，四字以内 |

## 四、密度：放在骨架的哪几个位置（2026-09-05 v1 后修订）

v1 按"六到八个拐弯"写，用户判「跟钱十七的太像了，半佛的用词太少了」。原因有两个：一是上限定低了——他自己的笑话占两成，每五句一个，六个拐弯只有他一半；二是钱十七的抬价手法（三不一只、结果渲染、催赞带稀缺、来源包装）原样留在开头，那是钱十七的嘴，不是结构。修订如下：

**钱十七的手法不带过来。** 骨架只保留：前三句直说生意、三块顺序、每块收口、结尾钩子、三句合同句。开头的三不一只、结果渲染、催赞带稀缺、来源包装、妥妥的式断语一律不写；开头换成他的路子：直说生意 → 第一人称吃亏故事一句（老婆那张约不出去的券正好是）→ 一句反应句 → 三块框架。

**每一句都要重说，不许只换连接词。** 和钱十七稿逐字重合的，只允许合同句、四个系统名、数字。其余句子必须在他嘴里重新说一遍：能拆就拆成短句加长句交替，该叠词叠词，该单字断句就断，该带语气词就带。

| 骨架位置 | 半佛线放什么 |
| --- | --- |
| 前三句 | 直说生意，其中一句自黑或反应句 |
| 第四到八句 | 吃亏故事一句、反应句一句、三块框架、一句"先看有没有人买" |
| 读屏和大数 | 报完数字接反应句或把小事说大 |
| 块首 | 一句人话或一个反转 |
| 块内步骤 | 平铺为主，但每块允许一到两处句尾挂类比或阴阳一句做法 |
| 坑 | 一本正经胡说或阴阳怪气 |
| 块尾 | 突然说人话 |
| 结尾 | 钩子、合同句不变 |

**密度目标**：拐弯十二到十五个（每四到五句一个），反应句不计数、随便放；两个拐弯可以相邻，但不许三个连着。半佛词库短语不低于每千字四十次（他本人中位四十七，v1 未测）。

## 五、和钱十七的区别，写的时候别串

| | 钱十七 | 半佛 |
| --- | --- | --- |
| 词往哪个方向使劲 | 抬价值、压门槛、压不确定 | 说离谱、说厉害、说坑 |
| 对观众的姿态 | 老师带学生，兄弟、咱们 | 旁观者吐槽，我、你、老师 |
| 数字 | 乘出大数后笃定断语 | 报完数字后一句反应 |
| 断语 | 妥妥的、一定没错 | 说白了、我只能说 |
| 收口 | 结果句 | 一句大实话 |

## 六、红线（半佛线额外的两条）

- 阴阳怪气和贬损只对"做法"，不对具体店家、同行、平台，不点名。
- 黑话不许堆：一句里最多一个（魔幻/颠/邪修二选一，不叠）。
- 其余同钱十七线：不写躺赚/稳赚/月入过万，不编收入，不搬他的具体名词，句子不超五十字，五分钟约一千三到一千五百字。

## 七、写完自查

1. 骨架是不是原封不动的那套？
2. 拐弯够不够十二个？有没有三个连着？钱十七的三不一只、结果渲染、催赞稀缺有没有漏进来？
3. 每个拐弯是不是一句之内完成，没有拉成一段？
4. 黑话有没有一句叠两个？有没有把支付宝那篇的词当口头禅？
5. 阴阳的对象是不是做法而不是人？
6. 大数后面有没有反应句？块尾有没有一句人话？
7. 逐句念：这句是半佛嘴里说得出来的，还是书面腔？
8. 对着钱十七稿和用户原视频的清单逐条查：故事、数字、例子、名字有没有一个撞的？

## 八、同题两稿必须看不出是亲戚（2026-09-05 v2 后追加）

用户判 v2「还是差不多，要完全不一样才行。结构可以一样，但是钱十七的和我原文都有『我老婆』这个事，不能这样，你要改的完全看不出来才行」。

规则：**半佛稿与钱十七稿、与用户本人那期视频之间，只共享生意机制和三块顺序，其余全部不共享。**

| 可以共享 | 不许共享 |
| --- | --- |
| 生意机制：收券、挂闲鱼、赚差价、一单十块、券只有两条出口、交付要代约 | 任何故事和缘起（老婆的券、全市一个师傅、拿着券找不到人） |
| 三块顺序、每块收口、结尾钩子、三句合同句 | 证据和读屏：钱十七稿用过的店铺、链接数、累计件数、乘出来的大数，一个都不再用；从事实卡里换一组没用过的 |
| 官价一百二这类唯一事实 | 例子：六十三收四十卖赔二十三这类算例，换别的事实算 |
| | 钱十七稿起的名字：收券三看、线报群收券法、详情页三件套、代约四步一律不用；半佛稿要么不起名，要么按他的路子另起 |
| | 钱十七稿的句子、比喻、收口句 |

做法：写之前先列两张清单——钱十七稿和用户原视频里出现过的所有故事、数字、例子、名字；事实卡里还没用过的证据。半佛稿只从第二张清单里取材。写完逐条对第一张清单，命中即改。
