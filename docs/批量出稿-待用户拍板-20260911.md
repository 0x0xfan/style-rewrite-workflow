## 二、跨期要统一定的规矩（定一次，所有期照改）

1. **"先出单再去同行那里买"能不能说**（34 三套、39 B 套、18 C 套相关）。词表 U038 把它标成"套用错"，但那是京东家政那期的预防条目；这几期是你自己视频里的真实做法。默认：保留，紧跟一句"那份货多半是别人的课程转卖的，你自己得清楚"。要不要把 U038 限定只管京东家政？
2. **"淘金子不如卖铲子"**（27 B、31 B、39 C）。是你原话，但规矩说不用比喻；三处有的改成平铺，有的保留。默认：保留原话（它是你的口头禅，不是写手造的比喻）。
3. **推算的总账要不要出现**：18 C 套"差价加起来是四万多"（那家店不只卖多开），28 B 套"按三成算九百多单、流水一万八千多"（贴近你原版"赚了将近两万"），34 C 套"一个店铺挂几十条，量是靠这样铺出来的"。默认：保留，都带"我推算的、没扣成本"。你要是觉得这类账都不该算，三处各删一两句。
4. **进价说法二选一**（18）：事实链写"一两块、一单差六块"，词表写"一块到两块、一件赚六块"。默认按词表。
5. **别的期的故事当通用经验用**（20、22、30、45 等）：写手借了其他期的亲历（比如海底捞那期的事放进驾考）。默认：只当"我做别的品时遇到过"说，不说成这个品的事。
6. **授权口径不是你原话**（31、40 的 Z 口径是按任务书整理的）：比如美国注册的成本数字"一百三十一美金套餐"是 2021 年教程价。默认：保留并带"几年前的价"。
7. **事实卡都还没抽检**：26 期的事实卡状态都是"终版候选"或"草稿"。挑稿时发现哪句事实不对，直接告诉我，我回头改卡和三套。
