# Project Brief

## 项目定位

风格仿写是一个内容生产工作流：先从参考文案中抽取表达风格，再只使用用户自己的事实、证据、素材和 CTA 进行仿写。

## 当前使用者

项目拥有者本人，用于沉淀可复用的短视频口播和引流文案风格。

## 当前第一条可验证链路

```text
本地样本文案
-> 风格卡
-> 飞书文档正文与素材读取
-> 事实/证据/CTA/风险抽取
-> 选择风格卡
-> 生成仿写入口与风险检查
```

## 当前已实现

- 钱十七闲鱼口播样本的风格卡。
- 飞书文档真实读取和素材索引。
- 本地工作台的风格库、改写风格选择和语音合成入口。
- 改写稿元引用泄漏拦截。

## 明确不做

- 默认复用参考文案的收益、案例、教程、资源清单、截图、平台策略或 CTA 关键词。
- 自动发布到闲鱼、公众号或其他平台。
- 在没有真实 TTS 服务时伪造音频成功。
- 未经确认引入重型风格迁移模型或小说写作系统。

## 成功证据

以 `docs/verification.md`、`feature_list.json`、真实 API 回读和可复现命令为准；用户对首篇仿写稿的人工接受仍是 F003 的最后验收条件。
