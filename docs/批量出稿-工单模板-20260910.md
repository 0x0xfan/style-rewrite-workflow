## 一、三套是什么（用户 2026-09-11 定）

同一份事实卡链（项目事实固定）× 三个不同的开头大类 × 三批不同的故事和闲鱼经验 × 三次不同的真人语料抽样 = 三套，**每套各自从头写**，不是改开头。三套之间：故事不重、经验编号不重、开头大类不重；生意机制和三点顺序可以一样。已经有一套交付稿的选题（18、20、24、35、38、41）只补两套，大类避开已用的。

## 二、省额度的规矩（用户 2026-09-11 定，硬规矩）

- **事实卡链只建一次**，以后所有轮次复用；建它的子 agent 用 **Sonnet**（`model: "sonnet"`）。已有 `事实卡-终版.md` + `事实链-*.md` 的选题直接用，不重建。
- **产物限长**：事实卡 ≤ 一万二千字符、事实链 ≤ 八千字符、开头角度清单 ≤ 四千字符。
- **配料包一律 `--lean`**（写手版，两万六千字上下）。
- **一个写手子 agent 写完三套**（主模型），一套接一套写，只读三份配料包，**不自己跑检查、不自己改**。
- **检查由 worker 跑脚本**，只把退回级命中交回去改；提示级不动。审稿按 `docs/审稿清单.md` 一页过，不读整本规则表和词表。
- 一期总共三个 agent：worker（主模型）、事实卡链子 agent（Sonnet）、写手子 agent（主模型）。都用 `run_in_background: false`。
