# 发布平台合规层

**适用平台：小红书 / 抖音**

这是项目级约束，不属于任何单个 IP。任何要发到这两个平台的成稿，生成后必须过一遍。

## 它是什么，不是什么

- **是**：把已知高风险表达挡在生成阶段的保守启发式规则。
- **不是**：平台官方审核规则的复现。这些规则没有从官方政策条文核验过。

**通过检查不代表一定能发出去，未通过也不代表一定发不出去。** 不要把 PASS 说成"合规通过"。

另有一套完全不同的规则管**闲鱼商品发布**（下架、扣保证金），在 `D:/项目仓库/闲鱼知识库/5-违规词库/`。两者不能互相替代——本项目实测过，闲鱼那套扫本稿只命中一处，还是把"第一单"误判成极限词。

## 怎么用

```bash
npm run check:compliance -- ips/钱十七/outputs/闲鱼餐饮券-口播版.md
```

规则表在 `engine/compliance/platform-rules.json`，检查器在 `engine/compliance/check-copy.mjs`。

`npm test` 里有一条测试直接断言已交付稿件必须 PASS，所以往稿子里加收益数字会让测试变红。这是刻意的：**可选的门禁等于没有**，这是本项目 2026-08-22 之前四次受众漂移换来的教训。

## 拦什么

| 类别 | 级别 | 例子 |
| --- | --- | --- |
| `income-claim` 收益承诺 | block | 月入过万、轻松破万、日赚 300 |
| `income-math` 收益推算 | block | 一天 100 单就是 800、一个月两万四 |
| `get-rich` 暴富话术 | block | 躺赚、稳赚不赔、零风险 |
| `absolute` 绝对化承诺 | block | 保证赚、百分百、包教包会 |
| `traffic-divert` 站外导流 | block | 加微信、私信我、扣 1、主页链接 |
| `recruit` 招徕语气 | warn | 我带你做、手把手带、免费领取 |
| `commercial-tone` 营销号语气 | warn | 风口、红利期、赶紧上车 |
| `money-density` 赚钱词密度 | block | 单个词都不违规，但整体密度超过 2% |

收益推算的匹配会先去掉所有空白，避免"一天 100 单"这种写法绕过。

## 和钱十七 DNA 的冲突

**这一层会削掉钱十七 DNA 的一部分核心控制，必须记录，不能装作没有。**

| DNA 控制 | 冲突 | 处理 |
| --- | --- | --- |
| A1 开头先摆一组数字建立"为什么值得看" | 收益数字正是 block 的第一类 | 改用具体现象（"五十块的券卖三十几"）建立钩子，不用收益数字 |
| A5 价格与利润计算放在变现机制附近 | 利润计算 = `income-math` | 只讲机制方向（"单张空间薄，靠件数不靠单张"），不给数字 |
| A6 资源 / 身份 CTA | 资源 CTA 极易被判导流 | 退到 DNA 允许的降级形态：评论互动 + 下期主题 + 署名 |
| 整体利益驱动、边讲边卖的推进感 | 与平台对赚钱类内容的审核方向直接对立 | 立场从"教你做这个赚钱项目"改为"讲清这门生意怎么回事 + 它累在哪" |

**后果**：合规版本必然比原版更弱的"钱十七味"。判断 DNA 像不像的时候，得把这一层扣掉再看，否则会把平台约束造成的差异算到 DNA 头上。

**未决问题**：在这个约束下，F1（项目/机会全路径拆解）可能不再是最优框架。F2（筛选判断教程）的避坑立场天然更适合这两个平台。本轮保留 F1 未擅自更换，留给用户决定。

## 本轮实测

同一稿在加合规层前后：

| | 合规前 | 合规后 |
| --- | --- | --- |
| 检查结果 | FAIL，7 处 block | PASS，0 block 0 warn |
| 赚钱词密度 | 1.05% | 0.15% |
| 有效字符 | 1,613 | 1,374 |
| 时长（240 字/分钟） | 约 6:43 | 约 5:43 |

被拿掉的：月入过万、一天 100 单就是 800、一个月两万四、一单赚 8 块、想多赚一万就得多出一千五百单。
