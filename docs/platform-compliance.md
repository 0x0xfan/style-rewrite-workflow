# 短视频诱导设计转换

**作用域：只管短视频稿。长视频稿不走这一层，诱导设计照旧。**

这不是"把诱导删掉"。诱导设计一条不少，只是换一种形式做——因为收益数字和承诺在小红书/抖音这类平台上会直接影响能不能发出去，而好奇、悬念、损失厌恶不会。

## 转换表

| 诱导目的 | 长视频形态 | 短视频形态 |
| --- | --- | --- |
| 开头建立价值 | 具体收益数字（"一张券本钱三十，卖出去赚八块"） | 反差现象（"五十块的券卖三十几，你以为是黄牛，其实不是"） |
| 留住人 | 收益推算、赚钱路径预告 | 悬念 + 信息缺口（"第二关刷掉的人最多，而大部分人压根不知道有这一关"） |
| 段落之间推进 | 阶段性收益兑现 | 段末留扣子（"薄到什么程度？薄到这件事压根不靠单张成立。那靠什么？往下听"） |
| 驱动行动 | 收益预期（"月入过万是能摸到的"） | 损失厌恶（"你辛苦养的号，可能就毁在一批来路不明的券上"） |
| 身份代入 | "你想做副业" | "没在闲鱼买过券的，从第一关听" |
| 结尾 | 资源 CTA、引流 | 互动钩子 + 下期悬念 + 署名（"四关里你觉得哪一关最难？评论区说说"） |

**核心判断**：诱导的能量来自"我想知道后面是什么"和"我怕踩坑"，而不是"我能赚多少"。前两个不受平台约束，后一个受。

## 检查器

```bash
npm run check:compliance -- ips/钱十七/outputs/闲鱼餐饮券-短视频版.md
```

规则表 `engine/compliance/platform-rules.json`，检查器 `engine/compliance/check-copy.mjs`。

`npm test` 里有两条测试锁住作用域：短视频稿必须 PASS，长视频稿必须 FAIL。后者是刻意的——防止以后有人把这层当成全局规则，把长视频稿也洗一遍。

## 拦什么

| 类别 | 级别 | 例子 |
| --- | --- | --- |
| `income-claim` 收益承诺 | block | 月入过万、轻松破万、日赚 300 |
| `income-math` 收益推算 | block | 一天 100 单就是 800、一个月两万四 |
| `get-rich` 暴富话术 | block | 躺赚、稳赚不赔、零风险 |
| `absolute` 绝对化承诺 | block | 保证赚、百分百、包教包会 |
| `traffic-divert` 站外导流 | block | 加微信、私信我、扣 1、主页链接 |
| `recruit` 招徕语气 | warn | 我带你做、手把手带、免费领取 |
| `commercial-tone` 营销号语气 | warn | 风口、红利期、赶紧上车 |
| `money-density` 赚钱词密度 | block | 单个词都不违规，但整体密度超过 2% |

**注意拦的都是"收益/承诺/导流"，没有一条拦悬念、反差、缺口、损失厌恶。** 短视频的诱导就往这几样上做。

收益推算的匹配会先去掉所有空白，避免"一天 100 单"这种写法绕过。

## 它是什么，不是什么

- **是**：把已知高风险表达挡在生成阶段的保守启发式规则。
- **不是**：平台官方审核规则的复现。这些规则没有从官方政策条文核验过。

**通过检查不代表一定能发出去，未通过也不代表一定发不出去。** 不要把 PASS 说成"合规通过"。

另有一套完全不同的规则管**闲鱼商品发布**（下架、扣保证金），在 `D:/项目仓库/闲鱼知识库/5-违规词库/`。两者不能互相替代——实测那套扫短视频稿只命中一处，还是把"第一单"误判成极限词。

## 和钱十七 DNA 的关系

短视频版会压掉 DNA 的 A1（开头摆收益数字）和 A5（利润计算贴变现机制）的**数字部分**，但保留它们的**职责**：A1 仍然在前三句建立"为什么值得看"，只是换成反差；A5 仍然把机制说清（"不靠单张，靠件数"），只是不给数字。

A6 的资源 CTA 在短视频里退到互动 + 下期悬念 + 署名。

判断 DNA 像不像的时候，短视频版要扣掉这一层再看，长视频版不用。

## 90 秒档的钩子密度

压到 90 秒后，四个环节讲不完，结构改成钩子密度驱动：大约每 10 秒一个。

钱十七 90 秒版的钩子序列：反差（五十块卖三十几）→ 反转（你以为是黄牛？不是）→ 强缺口（十个八个栽在同一地方，而且不是你以为的那个）→ 二次反转（先说你以为的：没货源。不是）→ 揭晓 → 设问（说不清会怎么样？）→ 损失厌恶（养了半年的号）→ 新缺口（薄到什么程度？）→ 连环设问（靠什么？靠件数。件数又靠什么？）→ 金句收 → 互动 CTA。

半佛 90 秒版用自己的钩子语法：困惑式开篇（现在是凌晨……我充满了迷惑）→ 图啥 → 假和解（听起来挺和谐）→ 推翻（真的吗？我不信）→ 黑幕揭露 → 魔幻定性 → 金句收（看起来简单是这世上最贵的四个字）。

两者的钩子密度相近，但钩子类型完全不同——这正是 F011 要对照的东西。
