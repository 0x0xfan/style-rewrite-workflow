# 风格（用户 2026-10-02 定，10-03 上线）

## 风格是什么

"风格"就是一个人说话的样子：他讲事情时带着什么**情绪**（兴奋、吐槽、笃定……）、用什么**腔调**（长句往下推、短句一句一行、口水词多……）、跟观众是什么**关系**（急着把好东西塞给你的学长、拉你一起翻白眼的损友、给你交底的老师傅……）。

用户说现在的长稿"只有一套风格""像说明书"，最缺的就是这三样。所以 10-03 上线让三个横版账号各学一个人的风格。

## 为什么只放整篇原文、不拆

以前把对标 IP 拆成规则、词表、人设卡，用户的评价是"拆出来的感觉完全不对"，人设卡"太过于倾向于他的角色定位"。

这次盲测是让写手**直接通读几篇整篇原文**，然后用那个风格讲我们的选题，四篇里用户觉得这样写的三篇都比现行写法好。

所以这个目录**只放原文，不放任何拆解、总结、规则、人设**。以后也别往这里加"××说话特点"之类的文件。

其他账号（黑黄、荧光绿、署名墙的横版，全部竖版，聊天记录，真人出镜）先照旧写法。

讲述人永远是圣矾本人，照样自报家门；借的只是说话的样子，不是借他们的身份、事、数。

怎么用这些原文写稿，见 `.claude/skills/daily-write/SKILL.md` 的「风格号写法」一节。

## 每个文件长什么样

- 一篇原文一个 `.txt`。
- 第一行是 `# 来源：<原文件路径>`，第二行起是原文，一个字没改（原文里的错别字、识别错误也照留）。

## 怎么加一个新风格

1. 用户找一个想学的对标 IP，挑 3–5 篇他觉得"这就是那个味儿"的**整篇**原文，贴到飞书。
2. 在这里新建一个文件夹（用这个 IP 的名字），每篇存一个 `.txt`，第一行写来源，后面原样照抄。不删、不改、不拆、不写总结。
3. 告诉主会话这个风格配哪个账号，由主会话把它写进 daily-plan 的账号表和 daily-write 的「风格号写法」。
