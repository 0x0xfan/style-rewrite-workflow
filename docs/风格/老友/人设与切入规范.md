# 老友风格（用户 2026-10-09 定上线）

## 1. 人设与心理定位
- **角色**：极度懂普通人难处、不制造任何焦虑、像端着茶坐在你对面的“知心老师兄 / 引路老友”。
- **情绪**：真诚诚恳、温和耐烦、毫无压迫感、放慢镜头手把手带你过关。
- **与观众关系**：理解你没时间、理解你怕被坑、陪你从零赚到第一个钢镚的“陪伴型朋友”。
- **讲述人**：依然是圣矾本人，自报家门两行，面向想在闲鱼赚钱的小白，讲真实生意。

## 2. 五种防撞车开头切入轮换池（核心铁律：第 1–2 句必须包含【闲鱼】+【具体项目/数据结果/想要人数】，然后紧接「我是圣矾。学闲鱼，找圣矾。」）
每篇开写前，从以下五种结构中轮换使用，避免连续两篇采用同一种套路（但第一句必须把闲鱼和数据立起来）：
1. **接纳焦虑型**：“在闲鱼帮别人做XX，一单赚XX，排在前面的同行有几千个人想要。很多想找副业的朋友总发愁自己没特长，其实这种小需求就是最省心的轻生意。”
2. **身边普通人故事型**：“上个月有个新手朋友在闲鱼试着挂了XX资料，一份卖几块钱，没想到几天就出了几十单。很多朋友总觉得闲鱼做虚拟很难，其实找对小众刚需，真的一点都不费劲。”
3. **真实生活刚需型**：“你在闲鱼搜一搜XX，一份整理好的资料标价几块钱，排在前面的同行有一千多个人想要。很多做晚辈的朋友总想帮家里长辈解决XX问题，这个小痛点在闲鱼就是极稳定的小生意。”
4. **真诚安利型**：“在闲鱼做XX代充，挂两块钱卖出，排在前面的同行有两千多人想要。今天坐下来像老朋友聊天一样，给你安利这个我看了很久、门槛极低极踏实的副业。”
5. **打破心理门槛型**：“做闲鱼很多人第一步迈不出去，总把生意想得太难。其实在闲鱼卖XX，排在前面的同行靠整理好的网盘资料卖了上千单，今晚跟着做就能上架第一单。”

## 3. 规矩约束
- **核心铁律**：第一句（或前两句内）必须点名【闲鱼】+【具体项目/数据结果/想要人数】，然后紧接「我是圣矾。学闲鱼，找圣矾。」。绝不能前面只聊泛生活/泛认知而前两句不提闲鱼！
- 遵守长稿全部硬规则（R001–R055）：纯汉字数字、单句不超50字、一行一句、自报家门两行、无解释“想要是什么”、资料钩子两行、固定收尾句一行。
