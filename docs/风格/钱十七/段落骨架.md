# 钱十七段落骨架（写对账台稿前读）

这份讲钱十七一整篇怎么排段、段和段怎么接、一段里几句话怎么连。读完这份，再把同目录 01–11 原文从头读一遍。

- 原文是语音转写，错字照原样（"咸鱼"就是闲鱼，"前十期/前17"就是钱十七）。下面引的原句也不改字，括号里是出自哪篇。
- 07 和 02 是同一期的两版录音，内容几乎一样，扫一眼就行。
- `飞书逐段标注-20260908.md` 是用户团队给每段标的作用，下面的段落名用的就是他们的叫法。
- `承接参照-真句.md` 是"大段交界处怎么给下一段说清值不值得听"的细表，这份不重复，只讲整篇的顺序和连法。

## 零、先记住三条限制

1. 讲述人是圣矾"我"。自报家门写两行：`我是圣矾。` 下一行 `学闲鱼，找圣矾。`，全篇只出现一次。不写"17""钱十七"。
2. 原文里的夸大和承诺（躺赚、秒杀、月入、翻十倍、直接把爆品喂到你嘴里）和他的所有数字，一律不照搬。钱数、销量只用选题核心和截图里有的；没有就不写"我/学员赚了多少"。
3. 我们的稿一句一行，这个格式不变。但"一行一句"不等于"一句一个新信息"。钱十七一段五六句话说的是同一件事，下一句常用"所以""因为""比如""而且""那"开头，接着上一句往下说。我们也一样：下一行先接住上一行，再往前走半步。

## 一、一篇的段落顺序

11 篇归纳下来，常见顺序是这样（"几句"按原文的句子数）：

| 顺序 | 段落作用（飞书叫法） | 几句 | 干什么 |
|---|---|---|---|
| 1 | 开头钩子 / 吸引观众 | 2–4 | 说清这期讲什么生意、钱从哪来，再用一个反差或痛点拉住人 |
| 2 | 自报家门 | 1 | 我们是固定两行 |
| 3 | 展示自己的能力 | 1–3 | 凭什么听我讲：我自己做过、学员做过、我整理过 |
| 4 | 告诉大家讲什么 + 催赞 | 1–3 | 报这期分几块，顺手让人先点赞，理由是"以免后面找不到" |
| 5 | 举例子（要用时才有） | 3–6 | 一个生词或一个道理，用一个例子讲完，再接回闲鱼 |
| 6 | 讲解内容 | 大头 | 按块、按步骤或按清单往下讲，块和块交界处说清下一块为什么要听 |
| 7 | 引流 | 2–4 | 放在"观众正好缺这个"的地方，先说缺什么，再说我备好了 |
| 8 | 结尾 | 2–4 | 一句话把这门生意的道理收回来 + 催赞 + 结束句 |

**开头钩子另守两条（用户 2026-10-03）：**

1. **一句话只跟一个主角走，数字挂在主角身上。**
   - 原句："一对小情侣，因为用了一个很鸡贼的套路，干着最简单的事，赚着一年四五十万的收入。"（11）——从头到尾说的都是"小情侣"，钱数也是他们的。
   - 反例："挂一把大牌椅子，就有一百三十六个人点了想要，赚的是商家给的返利佣金。"——椅子、想要的人、佣金三个主角，一句里换了三次，听的人不知道该跟谁。
   - 改法：主角定成这门副业，"今天给大家讲一个闲鱼上的副业，手里一件货都不用有，赚的是商家分给你的佣金。"
2. **开头不说只有分析之后才知道的结论，先说观众能看到的，结论跟在分析后面。**
   - 用户原话：「"手里一件货都没有"，你怎么知道的呢？这个是我们后面分析他才得到的结论，在最开始的时候是不知道的。」
   - 讲同行那家店时，先说截图上看得见的（在售两百八十多个、分类名带补贴、一千八百八十九的椅子一百三十六人想要、介绍里写"咨询拿补贴"），再顺着这些往下推，最后才说"所以他手里一件货都不用有"。
   - 开头讲"这门副业"本身不用货可以，那是在介绍生意；不能把"那家店"的结论提到前面。

**可变的地方：**

- 第 3 段的位置会挪：多数篇紧跟开头或自报家门（05 学员三单变二十单、03 学员第一个月、02 第一句"我每年都能在这个副业上发一笔小财"）；01 放在最后，但它是给引流作保（"我是七年自由职业者……我还整理了……"），不是单独一段；06 和 04 把能力塞进讲解内容里（"我们工作室常用的一个养号方法""我上个月卖了3台老式收音机"）。**能力从不单独一句挂在半路或结尾。**
- 第 5 段只在有生词或反常识的道理时才有：01 讲"权重"、04 讲"选品公式"、10 讲"壁纸烂大街"。没生词的篇（08 货源、09 按月份）直接进第 6 段。
- 第 6 段三种排法：分块（10 切五块、03 分三部分）、按做的先后（02/06：找资源→账号→发商品→自动发货）、清单（05 六不做六做、08 三十九个、09 十二个月）。我们五分钟的稿多用前两种。
- 第 7 段有时出现两次：先在前面预告"我备好了，视频末尾给你"（11、03），讲完再给。
- 互动句"打在公屏上"（03、06、11）可有可无，放在开头钩子后。

各篇实际顺序（对照原文看）：

- 01 养号：痛点+承诺 → 讲三个视频+催赞 → 今天讲账号、权重 → 抖音例子 → 放到闲鱼 → 原理 → 所以第一个视频教养号 → 四个维度逐条 → 催赞 → 能力 → 引流 → 下期预告
- 05 选品：钩子 → 学员三单变二十单 → 六做六不做+催赞 → 先排雷 → 六不做 → 转六种方法 → 最后一种就是我的选品表（引流）→ 催赞 → 引流 → 下期
- 02/07 状元笔记：零成本钩子 → 自报 → 之前不让卖、今天讲 → 销量图 → 点个赞开始 → 资源去哪找 → 我整理好了（引流）→ 流量才是核心 → 入驻两步 → 一个人精力有限 → 放大三点 → 自动发货 → 结尾
- 03 减肥监督：学员故事 → 自报 → 学员收入 → 替你担心"我不会减肥" → 打包给你+三连 → 三部分 → 服务 → 起号 → 上品节奏 → 引流 → 举一反三 → 一句核心逻辑 → 结尾
- 06 考研资料：零成本钩子 → 自报 → 为什么做这系列 → 需求 → 学员案例 → 资料三个渠道 → 引流 → 别急着发、先做三件准备 → 注册/养号/包装 → 发商品 → 自动发货 → 结尾

- 10 AI 壁纸：闲鱼搜索场景+价差 → 自报 → 本期问题 → 纠正"烂大街" → 报五块 → 一到四块 → 回头补一句引流 → 第五块 → 坑 → 复盘一句 → 催赞

## 二、段与段怎么接

钱十七换段时，下一段第一句一定先碰一下上一段，再往前走。常用六种：

**1. 例子讲完，接回闲鱼**
- "这就是账号权重和内容权重的区别。" → "放到闲鱼里，逻辑是一样的：账号权重对应的是闲鱼店铺的权重……"（01）
- "抖音是最多人使用的平台之一，抖音好卖的商品拿到闲鱼上卖也能有很好效果。"（05）
- "刚说完抖音榜单，下面我们说说闲鱼榜单。"（05）

**2. 用"所以"把上一段的结论变成这一段的事**
- "权重越高，流量越多，卖得越好，赚得自然也就越多。" → "所以我们三个视频中的第一个，就是教你打造高权重账号"（01）
- "这个行业主打只监督不指导，这样可以规避所有风险。所以常见的服务内容就四件事"（03）
- "买家不会去搜壁纸这两个字，他会搜他心里那个具体的名字。所以标题就是你的引流位。"（10）

**3. 先说"上一步做好了"，再接下一步**
- "有了账号后，要知道哪些维度能提升账号权重。"（01）
- "包定好了，下一步就是把图做出来。"（10）
- "资源到手后，先不要急着去发商品，而是做好账号准备工作"（06）
- "到了这一步，你已经有一个养好发产品就有流量的号，以及学会了怎么发产品。而上品的节奏也非常重要"（03）

**4. 先说"光有上一步还不够"，再接下一块**
- "卖法说完了，可东西挂上去没人看见也是白搭。第四块，买此引流"（10）
- "资源是一切项目的开始，流量是一切赚钱的核心，如果有资源后无法获得流量，那么一切都是空谈"（02）
- "虚拟资源卖1000份1万份依然是零成本但是一个人的，时间和精力是有限的……这里再分享一个……"（02）

**5. 替观众说一句心里话，再回答**
- "可能有人会说，我哪懂这些数据？别急，接下来就教你两个……选品工具"（04）
- "可能有人会说我自己都不会减肥，怎么做减肥监督？那这就是有意思的地方了"（03）
- "可能你会说我是新手不会写怎么办？17教你一个我自己在用的省时又省力的方法"（02）
- "很多人觉得账号包装不重要……恰恰相反，账号的包装非常重要"（06）

注意：这一句心里话后面紧跟的就是回答，不会问完了去讲别的。

**6. 清单里一条接一条，直接报"第几"**
- "第三，提高订单数量。"（01）、"第五，不做莆田货。"（05）、"第二步是咨询AR……"（03）
- 只有在清单内部才这样直接转。大块交界处（第 1–5 种）一定要先碰上一段。

## 三、段内怎么连：三个拆给你看

**拆一：01 第四条，活跃度（一句接一句往下推）**

> 第四，提高账号活跃度。简单来说，就是模拟正常用户的行为，而不是营销号。每天适当搜一搜你接下来要卖的产品，给心仪的宝贝点收藏、留留言；碰到认可的同行卖家，点点关注……还能以客户的身份和他聊聊天、套套话。这样做不仅能提升账号活跃度，还能套出同行的成交话术——多找几个同行聊聊，把他们的话术整理总结，你自己的话术就成型了。

主题句 → "简单来说"换成大白话 → 具体做什么（搜、收藏、关注、聊天）→ "这样做不仅……还能……"说好处 → 好处再往前推半步（话术成型）。每一句都在说"活跃度"这一件事，没有半路换话题。

**拆二：10 第一块，为什么大包卖不上价（问→因为→对比→比如→证据）**

> 为什么大包卖不上价？因为他没有购买理由。19000张什么都有的合集，买家心里想的是，反正到处都能下……细分包不一样，买的人是冲着某一个东西来的……比如通勤路上的地铁窗外……名字越具体，想要的人越少，可跟你抢的人少的更多。这张图就是证据。在咸鱼搜五更琉璃壁纸，全站一共才5件结果……这就是一条没人抢的搜索长尾

一个问题开头，后面全是在回答它：原因 → 买家怎么想 → 反过来的情况 → 举例 → 拿闲鱼搜索结果证明 → 最后才给个名字"长尾"。

**拆三：11 怎么"偷"流量（动作→因为→所以→比如→因为→所以）**

> 他们每天都会在搜索引擎……搜索清理死粉V2之类的产品功能关键词，看看有没有群聊可以加入进群。由于群里的用户都是通过搜索关键词进来的，这将意味着他们目的非常精准。所以每一个进群的用户都是他们的目标对象。比如说，其中一个群是专门卖清理死粉软件的……如果群主软件卖50块。他们就会和新人私聊说……只要10块钱，因为是软件嘛，几乎都没有成本，每卖一个都是纯利，所以他们赚的非常舒服。

先说他干了什么，再说为什么这样有用，再拿一个群走一遍，最后落到钱。改成我们一句一行的样子，就是每行开头的"由于""所以""比如""如果""因为""所以"都留着，读下来还是一条线。

## 四、陌生概念怎么讲

钱十七一整篇里的生词很少，一篇最多一两个（01 权重、10 长尾、04 公式三个词）。讲法都是：

1. **先给例子，最后才说名字。** 他常用"这就是……"收：
   - "这就是账号权重和内容权重的区别。"（01，先讲完抖音百万粉和零粉）
   - "通常是在售数的5倍以上，这就是明显的利润差。"（04，先讲收音机）
   - "这就是一条没人抢的搜索长尾"（10，先给搜索结果）
2. **一个概念配一个例子讲完，再"放到闲鱼里"接回来。** 01 讲权重，抖音一个例子讲完两种权重，然后一句"放到闲鱼里，逻辑是一样的"。
3. **能不用生词就不用。** 11 不说"私域""引流渠道"，只说"在各种群里偷群主的流量"；06 不说"人设定位"，直接说"最好的人设包装就是已经成功上岸的学长学姐"再给一个账号看。
4. **从不连着下定义。** 11 篇里找不到"A 就是……B 就是……C 就是……"连着排的段落，也从没停下来解释闲鱼是什么。要对小白交代的是"这门生意怎么赚钱"，用开头那个例子交代，半句挂在例子里，不单起一行下定义。

## 五、能力展示、引流、催赞放哪

**能力展示**：跟着它要作保的东西走，带出它的那一句要连着前文。
- 跟开头：钩子说了能赚钱，紧接着说"我们学员亲测有效从我帮他调整选品开始……"（05）
- 跟方法：讲到养号，"17、这里分享一个我们工作室常用的一个养号方法，静默养号法"（06）
- 跟引流：01 结尾"17是一名七年自由职业者……"下一句就是"我还整理了……"
- 我们只能用选题核心里给的圣矾的事实，没有就不写这段。

**引流**：带出它那一句，先说观众这时候正缺什么。
- "前面两个渠道找来的资料大多需要自己按类目整理好……而这些资料17多已经帮你准备好了"（06）
- "可能有人觉得还想要更多好产品。没关系，我整理了一套……"（04）
- "回头补一句，前面的批量出图17知道很多兄弟卡在那不会写脚本……"（10），给完还接一句"领完了，咱们回到项目本身"
- "除了货源之外，做好咸鱼还有很多环节，比如曝光低，没有订单。"（08）
- 05 更直接：第六种选品方法就是"通过17的选品表格"，资料本身就是讲解内容的一条。
- 我们的引流照项目格式（评论区扣词），不写公众号；只学他"先说缺什么"的带法。

**催赞**：理由永远是"内容多、以后要回来找"。
- 开头报完分几块就催："建议先点赞后观看，以免后面找不到了。"（01）、"点个赞我们开始。"（02）
- 讲完一张要截图的表或清单催："如果可以顺便点个赞就更好了。"（05，紧跟"建议暂停截图保存"）
- 正文讲完、引流之前催："如果看到这里，觉得内容有用，别忘了……给17点个赞和关注"（01、05）
- 结尾："觉得有用就点个赞，顺手收藏一下，以免要用的时候找不到"（10）
- 一篇两到三次，不要每块都催。

## 六、我们的稿常见跳接 → 改法

下面原句都来自 `待审文案\淘客截流\20261003-淘客截流-ledger-desk-h.txt`，改法只用这篇稿里已有的事实。

**反例 1：一句一个新词地连着下定义**

原句：
```
闲鱼你可以理解成一个大家自己挂东西卖的软件，除了二手，上面也有人挂全新的大牌货。
淘客其实就是返利，有人从你发的购买链接下了单，商家会从这一单里分一点佣金给你。
……
私域就是你自己建的群这种你说了算的地方……
……也就是拿闲鱼当流量入口来做截流。
流量入口说白了就是找人的地方。
截流就是有人在闲鱼上想买一样东西，还没下单，你先把他接到自己这边来。
```
问题：闲鱼、淘客、私域、流量入口、截流，五个词各下一次定义，观众记不住，也不知道它们怎么连起来。

改法：拿开头那把椅子走一遍，名字最后用"这就是"点一次，"私域""流量入口"不出现。
```
那把一千八百八十九的椅子，有人点进来问一句，补贴完多少钱。
他不在闲鱼上跟你成交，先把人拉进自己建的群里。
在群里发一个带返利的购买链接，人从这个链接买了，商家从这一单里分一份佣金给他。
这就是淘客，赚的就是返利。
这门生意快二十年了，以前大家在自媒体、购物平台的评论区里找买家。
放到闲鱼里，逻辑是一样的，只是找人的地方换成了闲鱼。
挂个低价商品，人还没下单，先把他接到自己这边来，这就叫截流。
```

**反例 2：一个问题后面三句各说各的**

原句：
```
那这个难不难呢？
比如你在小区物业上班，值班的时候大半天守着前台。
空下来拿着手机，就能把商品挂上去，有人来问就回几句。
很多人想做副业，最怕的是钱投进去收不回来。
这条路子用不着先进货，也不用先垫一笔钱，这一点你可以先放心。
说到钱，我看一门生意，习惯先把钱从哪进、从哪出摊开来看，淘客也一样。
```
问题：问"难不难"，答的是物业值班；接着跳到"怕钱收不回来"；再跳到"说到钱"。三个话头，没有一个讲完。

改法：替观众说一句心里话，紧跟回答，物业的例子当证据，再顺着"花的是工夫"进到账。
```
可能有人会说，做这个是不是得先进一批椅子？
不用，椅子从头到尾不在你手上，也不用先垫一笔钱。
你要花的，就是挂商品、回消息的工夫。
比如你在小区物业上班，值班大半天守着前台，空下来拿手机就能挂上去，有人来问就回几句。
那钱到底从哪进呢？先说进的这头，它不是闲鱼上的标价。
```

**反例 3：能力展示放到了结尾，挂在半空**

原句（倒数第六行）：
```
至于群里后面怎么运营，我也不是专业做淘客的，这期就不展开讲了。
我自己也有业务在用这个思路引流，所以这条路是怎么一步步走的，我认真看过。
你再回头看那把一千八百八十九的椅子……
```
问题：这句是"凭什么听我讲"，放在结尾前，前面接的是"不展开"，后面接的是回看椅子，跟哪句都不连。

改法：挪到自报家门后面，直接连到"这期跟着一个来问的人走一遍"。
```
我是圣矾。
学闲鱼，找圣矾。
我自己也有业务在用这个思路引流，这条路是怎么一步步走的，我认真看过。
所以这期我就跟着一个来问价的人，从闲鱼走到你的链接上，走一遍给你看。
```

**反例 4：风险和提醒被拆成孤立的句子，散在两处**

原句：
```
这里还有个很多人想不到的坑。
来问的人全被你拉到外面成交，平台这边看到的，就是只有人问、没人买。
这样下去，平台推给你的人会越来越少，钩子挂在那儿也没几个人看。
那人引到了你的群里以后呢？这才算走到了真正进钱的那一步。
你在群里把带返利的购买链接发给他，他点进去买了，这一单的佣金就到你这儿了。
说到这儿你可能会担心，买卖做到闲鱼外面去，闲鱼管不管？
管，闲鱼不希望这样，碰到了会给买卖双方弹提示，被提示的次数一多，号是会被封的。
```
问题：同一件事（把人拉到闲鱼外面成交，闲鱼不乐意）说了两次，中间还夹着进钱那一步；"这里还有个坑"在"回得快"后面凭空冒出来。

改法：风险放在讲到那一步时顺带说，合成一处，用"不过"接在进钱后面。
```
人进了群，你把带返利的购买链接发给他，他点进去买了，这一单的佣金就到你这儿了。
不过这一步闲鱼是不乐意的。
来问的人全被拉到外面成交，平台看到的就是只有人问、没人买，推给你的人会越来越少。
被弹提示的次数多了，号还会被封。
```

## 七、写完自查

1. 每段第一句，能不能说出它碰的是上一段哪句？说不出就是跳接。
2. 有没有连着两行以上在下定义（"X 就是……""Y 说白了就是……"）？有就改成一个例子讲完，名字最后用"这就是"点一次。
3. 每个"可能有人会说""那……呢？"后面，下一行是不是就在回答它？
4. 能力展示、风险提醒，是不是挂在它要作保或要提醒的那一步上，而不是单独一句挂在半路？
5. 引流前一句，有没有先说观众这时候缺什么？
