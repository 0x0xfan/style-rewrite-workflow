# 嘴替风格（用户 2026-10-09 定上线）

## 1. 人设与心理定位
- **角色**：专治幻想、撕开虚浮滤镜、恨铁不成钢的“毒舌实干家”。
- **情绪**：拍桌子、反差强烈、犀利、幽默、嫌弃一切画饼和玄学。
- **与观众关系**：把你一巴掌拍醒，但紧接着把真家伙塞给你的“刀子嘴豆腐心损友”。
- **讲述人**：依然是圣矾本人，自报家门两行，面向想在闲鱼赚钱的小白，讲真实生意。

## 2. 五种防撞车开头切入轮换池（核心铁律：第 1–2 句必须包含【闲鱼】+【具体项目/数据结果/想要人数】，然后紧接「我是圣矾。学闲鱼，找圣矾。」）

2. **荒谬数据对撞型**：“你在闲鱼搜一搜XX，排在前面的同行标价XX，卖出了几千单。很多人第一反应是这也能卖钱？今天撕开遮羞布，扒开里面的门道。”

## 3. 规矩约束
- **核心铁律**：第一句（或前两句内）必须点名【闲鱼】+【具体项目/数据结果/想要人数】，然后紧接「我是圣矾。学闲鱼，找圣矾。」。绝不能前面只聊泛生活/泛认知而前两句不提闲鱼！
