## 每篇抽什么

### 1. 开头层（只存结构，不存原句）
读开头到"落到正题"那一句为止（通常三到十句）。写成：
- 切入方式（从十七种里选，没有就新起一种并说明）
- 结构：每句干什么，用"① ② ③"编号，动词开头（自报家门 / 引一句传言 / 一个画面 / 否定三个答案 / 揭晓 / 进编号……）
- 适合讲什么内容
- 出处：作者 + 文章名。**不抄原文**，最多留五个字的线索
- 招生头（"关注我送你五个项目"）不算开头，跳过再数
- **作者的"大家好我是谁"不算结构，跳过。** 用户定的规矩：开头先包装本期内容，包装完再自报家门，再立框架。所以每条结构从"怎么包装本期"起，在包装完成的位置标一个 ⓪（自报家门放这里），之后才是立框架或进编号

### 2. 说法层（原句照录）
按九个场景找，每篇通常五到十句，没有就没有：
A 以前怎么做、现在怎么做（两段并排）/ B 报一个数 / C 讲退款售后 / D 讲定价 / E 劝新手 / F 替读者提问再接一句 / G 转场 / H 块尾收口 / I 结尾和资料钩子
每条：原句（完整一句到三句，不删不改）、作者、文章、场景字母、口播标记（✅ 能对着镜头直接说 / 图文腔 念出来别扭）。
**收入数字、效果倍数、招生话术不收**；句子里夹着的话，整句不收。

### 3. 原声层（原句照录）
买家、学员、厂家、家人、卖家自己回的话，带引号或明显是对话的。每条：谁说的、原句、情境一句、出处。

### 4. 作者档案
每个作者一段：他是谁（身份、年限、卖什么）、怎么说话（三到五个特征，举一句）、擅长讲哪几块、要剥掉什么（招生头尾、鸡汤、书面比喻）。

## 品类标记（用户 2026-09-08 定）
这批文章作为闲鱼运营经验**默认全是通用的**，只有一档要单标：**实物专用**。判据一条：这句话离了实物就不成立——退货、运费、快递、物流、品控、面单、囤货、包邮、运费险、七天无理由退货、签收、破损、发货慢。开头、说法、原声三层都加这个字段，值只有两个：通用 / 实物专用。不再细分虚拟资料、卡券、服务。虚拟选题生成配料包时机器剔掉实物专用；交稿前机器查这十几个实物词。

## 口播那道筛
标记标准只有一条：一个闲鱼博主对着镜头会不会这么说。四字成语堆叠、对仗、"回旋镖砸中眉心"这类比喻、超过五十字的长句，标"图文腔"。拿不准的标"？"，我最后统一筛。

## 用户 2026-09-08 追加的五条
1. **亲历标记**：说法层每条加字段"纯措辞 / 含作者亲历"。含亲历的（"我第一个月只赚了三百"），写稿时只许学句式，里面的事必须换成圣矾自己的（用户原话："换"）。
2. **借形不借句**：说法层是给写手学措辞的，不许整句搬。交稿时整个语料包进十二字连抄检查的对照库。
3. **用过的期**：每条开头结构、每条说法都留一个"用过的期"字段（初始为空），同一条隔几期才能再用。
4. **开头句数**：每条开头结构标它原文用了几句进正题；超过五步的注明"口播要压缩"，五分钟口播的开头预算是八句含合同句和框架。
5. **三个来源的优先级**：节奏听风格说明书，措辞听语料包，事实听事实链；冲突时按这个顺序。
