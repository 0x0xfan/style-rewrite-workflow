## 一、主线程细读结论：钱十七的六层（原文）

1. **讲的是一台赚钱机器，全程算账。** 他嘴里钱的数字不断："一份卖三十，一万份就是三十万，妥妥的躺赚""拼多多两块闲鱼八块，一天出十单赚六十""这些笔记我花了一千多块买来的"。我们的稿把钱藏起来了。本篇怎么做：京东官价一百二、闲鱼挂四十到六十、收券六十三四、沐浴露六十五，这些真价要反复拿出来算：差价八十、一张券四十到六十、"你要是一天能出两张，一个月下来流水两三千"（**假设句式，说流水不说利润**）。**红线**：不编利润数、不编"我/学员赚了多少"、不写"躺赚/稳赚/月入过万/百分百"（engine/compliance/platform-rules.json 的 block 词全避开，虽然 long 档不跑合规门，但用户要的是能发的稿）。

2. **人设是"谈钱不伤感情"的江湖人。** 口头语与句式："醒醒吧""拜托，我们不偷不抢""能抢的先抢，能抄的赶紧抄""进去就是送人头""懂的都懂""不香吗""对吧""妥妥的""巨坑""接盘侠""信息差""套利""系好安全带准备发车""动动发财的小手""观众老爷""轮椅级教程""把家底掏出来""很多兄弟一听……第一反应就是……"。**要用这种腔，但不能抄他原句**（对语料跑 12 字连抄必须 0），自己按这个腔造句。语气上是带点痞、带点炫、反问多、感叹多。

3. **每期至少一句认知反转金句。** 他的："烂大街的从来不是壁纸，是大而全的壁纸包""赚钱是设计出来的，不是熬出来的""钱不是赚来的，是找出来的""你知道这是库存货，买家以为是绝版品，这就是认知差"。本篇要有两到三句自己的，围绕：券是京东白送的、买家只知道便宜了八十；这生意的门槛不在开店在收券；"卖的不是保洁，是信息差"之类。

4. **什么都起名字、编数字。** 他的："静默养号法""三档梯度""六做六不做""黄金选品公式三个词""三个万能渠道""收益翻倍策略三个关键点"。本篇给几个：券从哪来叫"两条路"，收券叫"线报群收券法"或类似自造名，详情页三样叫"详情页三件套"，约单叫"代约四步"之类，全篇至少四个带名字带数字的小系统。

5. **案例是拿来炫的，不是拿来警示的。** 他的："这个卖了两万多份资料的账号，昵称洛曦学姐""这家店累计卖了七千件"。本篇的王牌案例是事实卡 A10 那家**专营店**（"京东家政一直有"，来闲鱼八年、累计卖出九千八百三十五件、好评率九十九、在售九个链接全是家政券、重庆两小时挂六十六块四千零六十八人想要），还有 A8（六年、累计一万五千六百七十一件、好评九十九、一条二十六块五的券六千四百八十六人想要）。开场或案例段拿这两家炫，Top1 那家（九年、两万八千八百九十三想要、十一万浏览）也用，但它有平台红条和八十五好评，可以在售后段当反面教材"你别学他"。**店铺数字要说"店铺累计卖出"，不能说成这条券卖了多少**（这是事实红线，说法上照样可以炫）。

6. **敢打包票。** 他的："保证新手看完就能用""三天你就能养出一个完美活跃度的新号""绝对全网最全"。本篇可以打的包票是关于**动作**的："照着做今天就能把第一条挂上去""这四步走完你就是一个能接单的家政券卖家""这份清单拿走，上架前对一遍，退款能少一半"——承诺动作和流程，不承诺收入。

### 结构（钱十七的骨架）

钩子（反差+案例炫，1–3 句，禁"今天给大家分享一个"）→ "我是圣矾。"→"做闲鱼，找圣矾。"（§E：全篇唯一自称句）→ 路线图（"这期圣矾切成四块讲……全是当天能上手的活"）+ "建议先点赞收藏，回头找不到别怪我" → 案例展开+算账（专营店那家）→ 四块正文，每块：起名字+编号+具体操作+"这里特别强调一点"式贴士+反问/感叹 → 坑（"千万不要碰，是个巨坑"式）→ 天花板与信息差金句 → 资料钩子（"圣矾把上架前核对清单整理好了，评论区扣个家政"——不要"扣1"这种数字写法、不要"加微信/私信"）→ 收尾"这期就到这儿，做闲鱼找圣矾，我们下个视频见"（不许再出现"我是圣矾"）。

### 每层的红线怎么守住的（写稿时的实际处置）

- **①**：流水句是**假设 + 只说流水**，紧跟一句自拆（「这是流水不是你的」）。全篇零利润数字、零"我/学员赚了多少"、`platform-rules.json` block 词 0 命中、赚钱类词密度 0.28%（上限 2.00%）。
- **②**：口头语全部按腔**自造**，不抄原句——对语料跑 12 字连抄 **0 命中**。`SIGNATURE_BLOCKLIST` 八条招牌话术（先点赞后观看／以免后面找不到了／暂停截图保存／动动发财的小手／点赞是我更新的动力／一键三连／谈钱不伤感情／打在公屏上）**一条都没用**，同义位置全部改写（例：「建议先点个赞收藏，回头要用找不着别怪我」「建议你暂停一下，把这张卡截下来存好」）。
- **③**：三句金句全部落在**已核实事实**上（赠品券 / 官价差 / 收券才是门槛），不引申成收益承诺。
- **④**：五个命名系统的每一条内容都能回到事实卡（两条出口=B1；收券三看=B3+B8+B6；详情页三件套=A9+A7+B6；代约四步=B4+A9）。
- **⑤**：三家店全部说「店铺累计卖出」，单品只说「想要」。京东 App 截图的「已售 500 万+」一个字都没写（事实卡 B13 红线）。
- **⑥**：三个包票全是**动作与流程**，没有一个是收入。唯一带量的那句是「能挡掉一大半退款」（属流程效果，非收入），终审若判为夸大，删「一大半」三字即可。

## 四、给下一轮改提示词/规则的三条建议

1. `check-ai-flavor` 的 `questionPer1000` 上限 2.0 低于钱十七本人单期实测最高值 3.98，属**上限门压住了 IP 的签名手法**（与 2026-09-03 诊断里「把风格标志当 AI 味删了」同一类事故）。建议改为按 IP 分档，钱十七档取 4.0–4.5。
2. `style-floor-rules.json` 的 `calibrationNote` 写着阈值是按**拆解型内容**打的 55% 折。v3 起文体已换成教程/江湖腔，动作指令、确定句、利益句三项实测分别是 0.12 / 0.15 / 0.10，都远超折后下限，说明这套折扣对新文体过松，建议重新校准。
3. `SIGNATURE_BLOCKLIST` 与「要写出这个 IP 的味」之间需要一条明文口径：黑名单拦的是**原句照搬**，不是**功能位**。建议在名单旁边给每条配一个「同功能可用改写」的例子（本次已产生两条：点赞收藏前置、暂停截图指令），避免每次写稿都重新发明。

## 五、第七层：铺垫引导（2026-09-04 v4 追加）

> 来由：用户对 v3 的原话——「这次还可以，但是感觉缺少了钱十七那种铺垫引导。」六层写对了「说什么」，缺的是「怎么把人从上一块领进下一块」。这一层是主线程重新盯语料里**每一块开始前那三四句**读出来的，与前六层同级，**写稿时必须逐块过一遍**。

### 7.1 形制：四拍

钱十七从不硬切段。每进一块之前固定走四拍，走完才报编号：

1. **收上一块**——用一句话把刚讲完的东西封口，顺带说它「还不够」。
2. **讲这一块为什么重要**——三种写法任选其一：
   - **原理句**（把这一块抬成整个生意的命门）
   - **误区反转**（先说大多数人怎么想，再「恰恰相反」）
   - **替观众提问**（把观众心里的疑问先替他问出来，再「别急」）
3. **预告 + 抬价值 / 留悬念**——说接下来要给什么，并给一个「不看完会亏」的理由。
4. **才进编号**——「一共有 N 点，先说第一点……」

另有两种也算铺垫，用在长段之后：

- **进度回收**：「到了这一步，你已经有……以及学会了……」——把观众已经拿到的东西点一遍，成就感换注意力。
- **节奏铺垫**：「前三天……三天后……半月后……」——用时间轴替代编号推进。

### 7.4 三条写作纪律

1. **六处不许同拍**。四块之间的「为什么重要」必须在原理句 / 误区反转 / 替观众提问之间轮换；本稿六处落在六种不同写法上，「恰恰相反」全篇只用一次。用同一拍开四块，听感立刻变成模板。
2. **悬念必须落在本稿真有的东西上**。「小字最要命」指的是规则卡那两行、「有一条你漏了」指的是收券三看的第三看、「第三件写不写」指的是详情页三件套的第三件——都是后文当真讲到的具体物，不是空吊胃口。空悬念会同时触犯诚信与 AI 味两头。
3. **铺垫吃字数，要拿同义重复句去换**。本稿补 17 句约 390 字，为守 ≤3000 字删掉了十来处相邻句的同义复述（如「一单退款你就白忙一场」「看漏了就是给自己埋雷」）。删的顺序是：语气复述句 → 结论复述句 → 逐句去虚字；**事实、指图话术、设问一律不动**。

### 7.6 给下一轮改提示词的建议

`cli/lib/prompt.mjs` 的文体段目前只写了「怎么写一块」，没写「怎么进一块」。建议加一条硬要求：**每个编号块之前必须有三到五句铺垫，按四拍写，且四块之间第二拍的写法不许重复**；并在 `check-style-floor` 里考虑加一项「块前铺垫覆盖率」（每个 `第[一二三四]块 / 第[一二三四]点` 之前 5 句内是否出现预告词或反转词），否则模型的安全解仍然是硬切段。

### 8.5 v5 的取词纪律（写这个 IP 时照这三条）

1. **压缩词一律展开成完整短语**。判据不是「够不够短」，是「一个闲鱼博主对着镜头会不会这么说」。两三字的生造搭配（干货密／过期不延／真章／杂货不掺）一律不许出现。
2. **该带的虚词必须带**：的／了／个／就／都／还／很／非常／其实／就是。句子宁可长一点，也不去虚词。单句 ≤50 字是字幕硬约束，**用逗号断开继续说完，不是把词压掉**。
3. **不许自造比喻和对仗**。「钱从两句话中间长出来」「券躺在账号里不会自己变成钱」「一头压着…一头压着…」这三类是 v4 的典型病灶，一律改成平铺直叙。生动化动词（砸出来／挡掉／拖成差评／扯皮你有底）换成平常说法。
4. **江湖腔的词是他本人的，保留**：醒醒吧／拜托／不香吗／巨坑／送人头／信息差／能抢的赶紧抢能抄的赶紧抄／懂的都懂／妥妥的／接盘侠。判据是「他说过这类话吗」，不是「够不够猛」。
