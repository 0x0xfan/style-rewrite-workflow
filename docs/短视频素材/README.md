# 短视频素材（两个库）

写短视频或长稿时可以从这里取材，写法照各自技能。一共两个库，各管一类用法。

| 库 | 在哪 | 管哪类稿子 | 能写数吗 |
|---|---|---|---|
| 产品库 | `产品库/` | **讲一个**：一条讲透一个产品 | 单价、想要人数能写，收益不写 |
| 盘点产品清单 | `盘点产品清单.md` | **盘点**：一条带过 3–5 个产品 | 一个数都不写 |

另外两份原表是参考，不是素材：
- `小红书文案零件-原表.md`：飞书里小红书时期的文案零件。写盘点开头时，只看"开头"那一栏学**结构**，句子不抄；里面的收益、月入、"回来感谢我"、时间词、小红书都不能进稿。
- `小红书经验文案-原表.md`：小红书时期的经验文案，只当参考，不当事实。

"经验"类稿子不用这里的东西，素材从闲鱼知识库找（见规格 v2）。

## 产品库

用户自己 47 期视频的字幕整理出来的产品卡。一期一张卡文件（有的一期拆成好几个产品，卡号写成 P36-1、P36-2 这样）；第 20、36、38 期合在 `产品卡-20-36-38.md` 一个文件里。

**怎么用**：先看 `产品库/总表.md` 挑产品，再打开"文件"那一列写的卡看全文。只用卡上的事实；卡上"不能说的"不进稿；标了"用户定"的照办。

`说明-*.md` 是整理每一批卡时的记录（读了哪份字幕、为什么这样拆卡、哪些栏空着），核对时看，写稿时不用看。

### 用户新录了一期，怎么加一张卡

1. 拿到那期字幕：跑 `node engine/brief/srt-find.mjs --episode <期号>`，从头到尾读完。
2. 照现成的卡（比如 `产品卡-46.md`）新建 `产品卡-<期号>.md`，一个产品一节，这些栏按顺序写：
   - 期号、期名、产品名、虚拟子类
   - 卖什么 / 谁在买 / 怎么交货
   - 钱数
   - 为什么卖得动
   - 要注意的坑/红线
   - 圣矾本人经历（字幕里圣矾自己做过、自己说的；没有就写"无"）
   - 闲鱼数据（想要、浏览、标价、已售）
   - 截图
   - 适合拆成的"讲一个"角度（两三个，每个写字幕依据）
   - 盘点用一句话
   - 不能说的
   - 字幕识别拿不准的词
   - 核对
3. 写的时候守这几条：
   - **钱数只抄原话**，每条后面带字幕时间戳，比如 `[00:00:54]–[00:01:01]`；不自己推算、不换算。圣矾自己的推算照抄原话，但在"不能说的"里注明"这是推算，不进稿"。
   - **没实搜过的写"无（待实搜）"**：闲鱼数据、截图没有就这么写，不去别处找来凑。
   - **内部编号挪到卡末"核对"那一行**：事实卡的表号（A1、B5 这种）、字幕文件路径这些只给核对的人看，不写进写手看的栏里。
   - **轻卡**：一期里只是点名带过、没有展开讲的产品（比如 P46-2 好想来代金券），只写 卖什么 / 钱数 / 盘点用一句话 / 不能说的 四栏，卡号后面标"（举例，轻卡）"。
   - 字幕里只是顺嘴提一下、连一句专属信息都没有的，不立卡，在说明里写一句为什么不立。
4. 在 `产品库/总表.md` 最后追加一行：卡号、产品名、子类、有无钱数、有无闲鱼数据、有无截图、文件名。
5. 这一批的整理记录写成 `说明-<期号>.md`（或几期合一个 `说明-<期号>-<期号>.md`）。

> 卡里写的 `scratch/产品库/<期号>/字幕.txt` 是当时的临时转写，没有搬进仓库；要看原话按卡上的 NAS 路径或重新跑上面的命令。

## 盘点产品清单

来自用户飞书多维表格「虚拟资源-产品」（小红书时期积累），一行一个产品，编号 Q01、Q02……

**怎么用**：只拿产品名当选题思路。"小红书原数"那一列的单价、销量**不进稿**，也不许说成闲鱼上的数。所有产品都能写，稿里讲的是闲鱼。

### 用户在飞书里加了新产品，怎么同步

用户说"同步一下"时做：

1. 飞书位置：多维表格 base token `DjO8b4JlGaQrVPsiW3LcrXBanng`，表「虚拟资源-产品」，表 ID `tblHAOQ3wnoLUO00`。
2. 拉数据：
   ```bash
   lark-cli base +record-list --base-token DjO8b4JlGaQrVPsiW3LcrXBanng --table-id tblHAOQ3wnoLUO00 --limit 200 --format json --as user
   ```
3. 提示登录过期，就先跑 `lark-cli auth login --domain docs,wiki,drive,base --no-wait --json`，把授权链接给用户，用户点完再拉。
4. 拿"产品"那一列和清单比，清单里没有的新行按 Q 编号接着往后加（Q69、Q70……）：产品名一列，小红书上的数放"小红书原数（不入稿）"那一列，没有就写"无"。
5. 旧行不改、不删、不重排编号；改完把清单开头"同步 N 条"的条数和日期改成这次的。
