## P25-1　AI提示词包（生图/生视频提示词资料）

- **期号**：25　**期名**：提示词（文件夹 `25.提示词`）
- **产品名**：AI提示词包（生图/生视频提示词资料）
- **虚拟子类**：资料类

**卖什么**：把网上公开免费的生图/生视频提示词整理打包，配网盘链接自动发货，可以整包卖也可以按模型、按题材、按节日拆开卖。原话：「这些提示词的渠道，在网上面也有免费的，圣矾这里有一个网站它的，做了各种各样的提示词都有」[00:02:01]–[00:02:07]；「你可以打包卖，也可以分开卖」[00:02:48]–[00:02:51]。

**谁在买**：会用AI生图生视频、但不会写提示词、想直接买现成的人。原话：「越来越多人做出了非常好的视频，而且又有很多人不会写提示词，就想直接买现成的提示词，所以这就有了需求」[00:00:59]–[00:01:15]。

**怎么交货**：夸克网盘发货，拍下自动发。原话：「像这种提示词发货，全部都是夸克网盘发货」[00:01:24]–[00:01:28]；「最主要的是他是完全自动发货的」[00:03:42]–[00:03:45]。

**钱数**（照字幕原话口径，不换算，本卡不出利润数字）：
- 「像这种品标价只有一毛钱」[00:00:07]；两条开场同行案例都是「小刀价一毛，直接买一块/一块五」这个价位段（画面数字，见闲鱼数据栏）
- 「这个美女的她的提示词，她是卖两块8毛8」[00:01:51]–[00:01:54]
- 新春写真提示词：「这个提示词它一共有170个人想要……一单按7块钱来算」[00:03:24]–[00:03:39]（画面标价实为¥6.90，口播说成"7块钱"是取整）
- 网盘拉新收益：「夸克网盘的转存，它的单价就是3毛钱，而百度网盘的这个转存价格是0.45一次」[00:01:32]–[00:01:39]（这是网盘平台给的拉新钱，不是提示词本身的卖价）
- 收益话术（不入稿，见下）：「靠网盘拉新，把它的收益做到一单利润在一块钱左右……他最起码也能出个几百单，这一个品就赚了几百块」[00:00:07]–[00:00:20]；「转化率可能是在30%左右，那么也就是大概会有四五十个人买……那么他这一个品也能赚个几百块钱」[00:03:31]–[00:03:39]

**为什么卖得动**：AI生图生视频火，但很多人不会写提示词——[00:00:48]–[00:01:15]；提示词本身单价不低——「它的单价在闲鱼上面的价格都是不低的，最高的有卖到几十块的」[00:01:19]–[00:01:24]；可以跟热点走——「随着这种视频生成越来越火，会有越来越多不同的这种模板出来」[00:01:44]–[00:01:51]；跟节日热点铺品能拿流量——「你可以根据当下的节日，或者是比较爆火的内容，找到相关的提示词，然后迅速的在闲鱼上面铺上这个品，你就能够拿到很大的流量」[00:03:45]–[00:03:57]。

**要注意的坑/红线**：字幕本身没有讲版权/侵权风险，只讲了货源和方法（讲版权这层是2026-09事实卡核实到的，不算本期字幕内容，本卡按规则不外加自己的判断，只如实标注这是事实卡另外核到的）。

**圣矾本人经历**：有一处，圣矾自己整理并分享了一个提示词网站。「圣矾这里有一个网站它的，做了各种各样的提示词都有」[00:02:03]–[00:02:07]；「这个网站我也给你打包好了，在彩蛋里就可以领取」[00:02:53]–[00:02:55]。字幕里没有"我自己在闲鱼卖过提示词包、出过多少单"这类第一人称出单记录。

**闲鱼数据**（来源：字幕原话 / 事实卡-终版.md）：
- 字幕原话：开场两条同行链接「这链接4,177个人想要3万浏览」「这个链接3,600多个人想要也是3万浏览」[00:00:00]–[00:00:06]；美女类提示词「1,000多个浏览，68个人想要」[00:01:51]–[00:01:56]；新春写真提示词「170个人想要」[00:03:27]
- 2026-09事实卡核实：今天在闲鱼搜原来那个词"ai绘画提示词"，一条结果都没有，页面直接写"没有找到你想要的宝贝"；换成"绘画"这个泛词能搜出东西，但翻了两屏全是真人代画和画材，没有一条是在卖提示词包的——说明这门生意跟着模型换代在换词，去年的搜索词今天已经搜不到了
- 那条卖两块8毛8提示词的店铺，来闲鱼9年、全店累计卖出1204件（是全店所有东西加起来的，不是这一条）
- 圣矾提到的那个提示词网站，视频类有580多条，全站一共3130多条提示词

**适合拆成的"讲一个"角度**：
1. "去年的搜索词今天已经搜不到了，得跟着模型换词"——依据今日"ai绘画提示词"零结果与字幕[00:48]–[01:15]"去年图片今年视频"对照
2. "同一条提示词，标价一毛，直接买才是真价"——依据[00:00:00]–[00:00:07]两条开场案例
3. "跟节日热点铺品怎么拿流量"——依据[00:03:24]–[00:03:57]新春写真案例+方法论
4. "网盘拉新是这门生意的第二笔钱"——依据[00:01:24]–[00:01:41]

**盘点用一句话**：一毛到几块的资料生意，钱不在一条链接上，在铺量和跟热点——依据[00:00:07]与[00:01:44]–[00:01:51]。

**不能说的**：
- 不能把「一单利润一块钱左右」「几百单赚几百块」[00:00:07]–[00:00:20]、「四五十个人买、一单7块、赚几百块」[00:03:31]–[00:03:39]当成核实过的收益说，这些是圣矾自己的推算叠推算
- 网盘拉新的钱[00:01:32]–[00:01:39]是口播数字，没有画面佐证，不给具体数
- 美女/颜值类提示词那一条[00:01:51]–[00:01:57]只能引用它的想要数和浏览数，不能把"美女""变装"当卖点或举例来讲
- "五条悟与宿傩"这类动漫专有名词[00:02:26]–[00:02:30]不必要点名照搬
- 提示词包本身来自公开免费网站和网友整理，字幕没讲这批内容的版权归属，不能说"零成本随便拿去卖"

**字幕识别拿不准的词**：「有这种NATO Banana的生图的」[00:02:07]–[00:02:10]——"NATO Banana"应为"Nano Banana"（识别可能有误）；「所以我所以也就是我们还可以再」[00:01:28]–[00:01:30]——"所以我所以"重复，疑为识别卡顿；「这个叫五条悟与宿傩宿命般的巅峰对决」[00:02:26]–[00:02:30]——动漫角色专有名词，识别是否准确未核。
