## P23-1　AI账号拼车（GPT/Gemini/Claude大模型订阅拼车账号）【已放开】

- **期号**：23　**期名**：ai拼车（文件夹 `23.ai拼车`）
- **产品名**：AI账号拼车【已放开，风险见"不能说的"】
- **虚拟子类**：账号/会员拼车类

**卖什么**：把GPT、Gemini等大模型的官方团队版/家庭组账号，开出多余名额按月分摊卖给别人拼车用。原话：「这个team拼车的版本，就是前面这个plus的版本」[00:01:08]–[00:01:09]；「拼车账号，主要利用的就是Openai官方的这个渠道，官方你可以通过这个商业版开通一个plus的账号，这个plus的账号是母号，这一个母号你可以授权给4个子账号」[00:04:34]–[00:04:46]。

**谁在买**：用国外大模型的人。原话：「不只是程序员在用AI了，写代码的、做内容的、跑工作流的、剪视频的，很多人都在用这个低成本的高生产工具」[00:00:43]–[00:00:51]。

**怎么交货**：字幕没有单独讲"给买家发什么"这一步（不像后面几期讲了网盘自动发货），只讲了这门生意的交付性质。原话：「这种用户他的需求很明确，交付就很轻，他不一定每单赚很多，但是他一定很适合你自动发货和常委出单」[00:03:21]–[00:03:28]（"常委"疑为识别有误，见文末标注）。

**钱数**（照字幕原话口径，不换算）：
- GPT官方价：「plus是20美金一个月，Pro是200美金一个月」[00:00:53]–[00:00:58]；拼车价：「你的成本可能是5块钱一个月」[00:01:00]–[00:01:03]
- Gemini官方价：「Jimmy Pro正常一个月是20美金，这个AI Ultra是250美金一个月」[00:01:11]–[00:01:17]；闲鱼拼车价：「你购买这个三个月的订阅是39块9」[00:01:21]–[00:01:23]
- 母号成本：「而你的成本大概是在3块钱左右」[00:04:49]–[00:04:52]（事实卡标注：进价未核实，不能拿这个数字去减出利润）
- 同行代理价：「同行卖5块，他肯定有的赚」[00:05:21]–[00:05:23]
- 开场同行案例：「标的是6块6毛6，一共1,470人想要，9,000多个浏览」[00:00:00]–[00:00:01]；圣矾推算「他应该能出300到500单，平均一单能有个2到5块钱的利润，也就是说他卖这个东西已经赚了几千块」[00:00:05]–[00:00:14]（这是圣矾对同行链接的推算，不是同行自己晒的后台数据，事实卡列为收入话术，不建议直接搬进新稿当结论）
- 另提到一门不相关的生意：「移动拉新，一单七块，会员分成30%」[00:03:34]–[00:03:37]（这是网盘拉新，不是拼车账号本身的钱）

**为什么卖得动**：「从闲鱼购买的渠道会比官方的渠道便宜太多了，而且跟官方原版是没有任何区别的」[00:01:26]–[00:01:32]（后半"没有任何区别"是未核实的断言，见不能说的）；「这种用户他的需求很明确，交付就很轻」[00:03:21]–[00:03:24]；「它对于闲鱼虚拟的选品来说，是一个比较稳的类目」[00:03:16]–[00:03:19]。

**要注意的坑/红线**：「这个品圣矾可以告诉你是有风险的，虽然说这个品非常的爆……同行当中有几千人想要的，这种数据应该会有不少才对，看到的比例非常的少，太暴力了，所以就导致很多人上链接一上就封」[00:01:47]–[00:02:07]；「卖这个产品的风险就是很容易封号以及被封链接，因为这个产品真的是太火爆了」[00:05:42]–[00:05:51]；「可以说是利用漏洞搞出来的账号」[00:02:53]–[00:02:59]。

**圣矾本人经历**：有，两处。「圣矾自己我都是四五个账号轮着用。open AI的j p t、谷歌的Germany、还有cloud的账号，我都在循环反复地利用」[00:02:14]–[00:02:24]（ASR把GPT、Gemini、Claude识别错了，见文末标注）；「圣矾自己有渠道，因为圣矾是一个个人IP，有很多的有资源的人愿意来找圣矾合作」[00:05:32]–[00:05:39]。

**闲鱼数据**：
- 字幕原话：同行链接「标的是6块6毛6，一共1,470人想要，9,000多个浏览」[00:00:00]–[00:00:01]
- 2026-08-26闲鱼实采：搜"ai拼车"第一页30条里，真正的拼车链接有11条显示想要人数，最多的两条是17人想要；详情页往下翻的推荐位里，有一条国产大模型会员开通的，9块8，2100多人想要，一条国外编程工具官方订阅的，135块，500多人想要——泛词搜出来量不大，热度在具体品词上

**截图**：无——manifest.json 里 `assets/ai-pinche/` 路径下没有任何图片条目（本期在 research-runs 目录下另有一批截图，但不在 manifest.json 里，按规则不采用）。

**适合拆成的"讲一个"角度**：
1. "想要数低不代表没人买，真需求藏在具体品词里"——依据搜索页想要数低但推荐位具体品词想要数高的对比
2. "开一个母号能带出几个位置来卖"——依据[00:04:34]–[00:04:52]开团队版母号带子账号
3. "封号是这个品最大的命门"——依据[00:01:47]–[00:02:07]+[00:05:42]–[00:05:51]
4. "货源三条路怎么选"——依据[00:04:30]–[00:05:39]自建/找同行代理/找上游三条路

**盘点用一句话**：官方订阅贵、拼车便宜，但账号是"利用漏洞"来的，容易封号——依据[00:00:53]–[00:01:03]与[00:02:53]–[00:02:59]。

**不能说的**：
- 产品名后加【已放开】：圣矾原话自己讲这是「利用漏洞搞出来的账号」[00:02:53]–[00:02:59]，账号共享/多账号拼车是否符合各平台服务条款字幕里没核实，能不能正面出稿要用户先定
- 不能说"跟官方没有任何区别"[00:01:26]–[00:01:32]（未核实断言，同行自己在详情里都写着掉了要换）
- 不能把圣矾对同行链接的推算「2-5块钱利润」「已经赚了几千块」[00:00:05]–[00:00:14]当成收益承诺搬运
- 不能把母号成本"3块钱左右"[00:04:49]–[00:04:52]当成核实过的进价去算利润
- 移动网盘拉新的钱[00:03:34]–[00:03:37]跟这门生意（AI账号拼车）是两件事，不能混着算账

**字幕识别拿不准的词**：「open cover特别的火爆」[00:02:07]——应为"OpenAI"或"Codex"；「open AI的j p t」[00:02:19]——"j p t"应为"GPT"；「谷歌的Germany」[00:02:21]——应为"Gemini"；「还有cloud的账号」[00:02:22]——应为"Claude"；「证明你也是一样，证明你官方这个AI Pro的账号」[00:04:55]–[00:04:57]——两处"证明"疑为"Gemini"识别有误；「适合你自动发货和常委出单」[00:03:26]–[00:03:28]——"常委"疑为"长期"识别有误。
