## P24-1　电影票代买（低价电影票代下）

- **期号**：24　**期名**：电影票（文件夹 `24.电影票`）
- **产品名**：电影票代买/代下（低价电影票）
- **虚拟子类**：代买/代办服务类

**卖什么**：帮买家用比官方更低的价格代订电影票，靠配套AI软件自动识别座位、自动报价下单、自动发取票码。原话：「在闲鱼上面买低价电影票，你把电影院的座次表截图发给客服，告诉他你在哪个城市，Ai就会自动识别影院和座位，自动下单，全程无人值守，全部都是自动化操作」[00:00:25]–[00:00:39]。

**谁在买**：想便宜看电影的人，覆盖面很宽。原话：「而电影票这个东西上到七老80，下到两三岁都有受众」[00:01:54]–[00:01:59]。

**怎么交货**：买家把想看的场次座位截图发过来，系统识别后自动报价下单，再把取票码发回去，配套用专门的代下软件管理接单和发货。原话：「你把电影院的座次表截图发给客服，告诉他你在哪个城市，Ai就会自动识别影院和座位，自动下单」[00:00:27]–[00:00:35]；「在这里还有回复文案……闲鱼功能……在这能够看到有下单拦截发货退款，重新获取票码，打招呼问答人工等等等等」[00:03:36]–[00:03:59]。

**钱数**（照字幕原话口径）：
- 客单价：「平均客单价是20-60块」[00:00:03]–[00:00:06]
- 单利（2026-09-04用户已授权入稿口径）：「一单的利润少有几块，多则会有十几块」[00:00:06]–[00:00:08]；「基本上是20%30左右的利润，也就是说他其实一单最起码能挣个三五块钱，我们就按三块钱算」[00:01:16]–[00:01:26]
- 3D/IMAX厅节假日高价场：「像这种像这种什么万达，万象影城，这些都是大城市里面才有的……可能一张在节假日的时候，会卖到100多，这种100多的，它的利润可能就有个二三十块钱」[00:02:08]–[00:02:28]（这是圣矾对高价场的利润推测，非实测，不建议单独出数字）
- 总账话术（不入稿，见下）：「它这一个链接总共就能赚几十万」[00:00:08]–[00:00:10]；「按三块钱算的话，那么他这个店总共赚了60多万，这是纯利润60多万」[00:01:26]–[00:01:33]

**为什么卖得动**：需求量大且长期存在——「每到节假日必卖爆」[00:00:39]–[00:00:41]；受众极宽——[00:01:54]–[00:01:59]；不同地区价格分层——「像这种电票……而且每个地区的电影院也是不一样的，比如说小城市有一些电影院，它是在大城市里面没有的，而小城市的小电影院价格又比较低」[00:01:15]–[00:02:08]；「像这种像这种什么万达，万象影城，这些都是大城市里面才有的，这一些电影票它的价格高，利润也高」[00:02:08]–[00:02:16]；全部自动化，闲鱼操作也简单——「因为全部都是自动化的，你只需要把闲鱼以及配套的这个软件搭建好」[00:02:40]–[00:02:49]。

**要注意的坑/红线**：字幕本身没有单独点名这个品的风险（没讲票源从哪来、售后纠纷、平台规则这些），只讲了淡旺季差异：「像淡季的时候出单就不会特别的多了，主要靠旺季冲销量」[00:02:35]–[00:02:40]。（事实卡另外核实到：同行详情页自己写着"出票后不退不换""出票不保证百分百成功""座位可能被系统自动调座"这几条售后硬约束，字幕口播里没讲这些，是2026-09实采另外核到的，不算本期字幕内容。）

**圣矾本人经历**：有一处朋友转述案例（非圣矾自己出单）。「圣矾有一个朋友，他当时就是做电影票代下，靠卖哪吒二三个月提了一辆宝马三系」[00:00:51]–[00:00:58]（这是朋友的战绩转述，不是圣矾本人做过这个项目出过单）。圣矾本人在本期演示过配套代下软件的后台配置，属于"拆过这个题"的经历，不是"自己卖出过票"的经历。

**闲鱼数据**（来源：字幕原话 / 事实卡-终版.md）：
- 字幕原话：同行链接「47万人想要99万浏览」[00:00:00]–[00:00:01]，客单价20-60块[00:00:03]；「他的店铺一共是卖了20万件宝贝」[00:01:10]；其他同行想要数「三万多个人想要，6000多个想要，2000多个想要，这个也是两万多个想要」[00:01:40]–[00:01:46]

**适合拆成的"讲一个"角度**：
1. "同一条链接一年后价格塌了一半"——依据字幕开场47万想要/99万浏览与事实卡今日49万/95万、9.9起对照
2. "大小城市影院怎么分利润高低"——依据[00:01:54]–[00:02:16]
3. "旺季冲量、淡季别指望"——依据[00:02:35]–[00:02:40]
4. "全自动化配套软件是怎么接单的"——依据[00:03:22]–[00:04:02]

**盘点用一句话**：客单价20-60块、一单赚几块到十几块，节假日冲量、淡季不多——依据[00:00:03]–[00:00:08]。

**不能说的**：
- 不能把「它这一个链接总共就能赚几十万」[00:00:08]–[00:00:10]和「这个店总共赚了60多万，纯利润60多万」[00:01:26]–[00:01:33]当成核实过的收入说，这是想要数反推的收入话术
- 不能把朋友转述的「靠卖哪吒二三个月提了一辆宝马三系」[00:00:51]–[00:00:58]写成圣矾本人的战绩
- 3D/IMAX厅"一单利润二三十块"[00:02:17]–[00:02:28]是圣矾的推测，不是实测，不单独出这个数字
- 票源从哪来、有没有合法出票资质，字幕里没讲，不能替同行说"正规渠道"

**字幕识别拿不准的词**：「大家都知道二五年年初哪吒二爆火光」[00:00:41]–[00:00:45]——"爆火光"读法拿不准，可能是"爆火"后多识别出一个字；「比方说有的时候会有三d max，是的影院」[00:02:17]–[00:02:20]——"三d max，是的影院"应为"3D、MAX厅的影院"（识别可能有误）；「基本上是20%30左右的利润」[00:01:20]——疑似"20%到30%左右"漏识别了"到"字。
