## P08-1　AI代部署（cloudbot/Openclaw等桌面agent自动部署）

- **期号**：8　**期名**：ai待部署（对应文件夹应为AI代部署相关期）
- **产品名**：AI产品代部署，圣矾字幕里点名的工具叫cloudbot，也叫Openclaw、"IM什么来着"、motorbot（同一个工具的不同别名），配合一个国产桌面agent实现自动化部署
- **虚拟子类**：软件工具类/代办服务类

**卖什么**：帮买家把某个AI工具（cloudbot/Openclaw这类）自动部署到电脑/服务器上，靠一个国产桌面agent把部署说明发给它，让它自动完成安装配置。原话：「闲鱼做AI产品待部署，让AI帮你一键部署，0成本套利」[00:00:02]–[00:00:08];「这节课我们讲的loadbot这个产品」[00:01:59]–[00:02:02]；「就是这个东西它也改名了，它叫Openclaw，它也叫cloudbot，它还有一个名字叫IM什么来着我忘了，这个motorbot还有一个名字叫这个，它其实都是一样的」[00:03:16]–[00:03:31]。

**谁在买**：字幕没细说具体买家画像，只说这类产品对搜索这类工具的用户来说图的是"靠谱的技术"。原话：「对于搜索这一类产品的用户，他们需要的就是一个靠谱的技术，他们并不需要那么多花里胡哨的东西」[00:02:25]–[00:02:32]。

**怎么交货**：从闲鱼接单后远程操作客户电脑，在客户电脑上装桌面agent，把整理好的部署说明发给桌面agent，让它自动完成部署；客户如果要接入QQ/飞书/企微这类额外需求，可以再加钱。原话：「你从闲鱼接到单之后，远程客户的电脑，在客户的电脑上安装桌面agent，把整理好的cloudbot部署说明复制发给这个桌面agent，它就会给你进行自动地部署了」[00:08:03]–[00:08:14]；「当客户提出其他需求的时候，根据其他需求再进行收费，比如说客户他还要求你把这个部署接入QQ或者接入飞书，那么你可以再对它进行额外的收费」[00:08:24]–[00:08:35]。

**钱数**（照字幕原话口径，不换算）：
- 「这个部署的收费，大家的定价是从30块钱到100多块钱是不等的」[00:03:33]–[00:03:40]
- 一个同行「像这个它是卖61块钱」，服务内容是「接远程待安装配置，Mac Windows Linux，接飞书和各大模型，然后向日葵to desk远程操控」[00:03:40]–[00:03:52]（圣矾原话备注：「当然我不知道他的实际价格是不是这个价格」[00:03:56]–[00:03:59]）
- 另一个同行「他这个10块肯定不是实际价格」[00:04:13]–[00:04:16]
- 接飞书/企微/千牛这类额外定制：「你看这个是卖99块钱，它是做的cloudbot搭建对接飞书，还有对接企微的，还有搭建对接千牛的，这些全部都有」[00:08:38]–[00:08:49]
- 圣矾对整体收益的推算：「不过一个月下来赚个零花钱肯定是能做到的，一个月赚个几百块钱是能做到的」[00:04:29]–[00:04:35]

**为什么卖得动**：桌面agent能自动执行部署，省人力；圣矾自己也是先用了这个组合工具，觉得比同类免费好用。原话：「我自己也尝试了用一个桌面agent进行电脑的安装部署啊操作……它就能够自动地帮我对本地文件进行操作了」[00:00:51]–[00:01:05]；「这个AI工具它目前是一个免费的，它不收费。我之前找到这个AI之后，我还找了一些其他家的，其他家的要么是收费，要么很智障」[00:01:18]–[00:01:33]。产品原理是靠AI知名度低但需求真实：「这个产品它对于国内人来说还是比较，它的知名度还是比较少的」[00:04:35]–[00:04:42]（对比同类更知名的Deepseek本地部署想要数/已售数好几百，说明知名度高的同类产品需求量更大，但cloudbot这类不知名工具的部署需求仍然真实存在，只是体量小）。

**要注意的坑/红线**：字幕本身没有点出这个品的具体风险（没讲部署过程中的数据安全、远程操控客户电脑的授权边界等）。

**圣矾本人经历**：有，圣矾本人做过桌面agent自动部署的操作演示（但不是"闲鱼出单卖过这个服务"的经历，是圣矾自己拿这套工具给自己工作室提效）。原话：「我自己也尝试了用一个桌面agent进行电脑的安装部署啊操作……我只需要在这里描述清楚这个任务，下面这勾选上任务执行，它就能够自动地帮我对本地文件进行操作了」[00:00:51]–[00:01:05]；「我这边目前没有合适的人以及时间去做，所以我做的就是虚拟的」[00:01:47]–[00:01:54]（说明圣矾自己做的是虚拟资料类项目，不是这个代部署服务本身）。

**闲鱼数据**（来源：字幕原话，带时间戳）：
- 「他是卖61块钱……一共是40个想要」[00:03:54]–[00:04:02]
- 「他这个10块肯定不是实际价格」[00:04:13]–[00:04:16]（没给想要数）
- 「因为目前通过这些同行数据看，是没有看到有想要数很高的，破百的都没有」[00:04:19]–[00:04:29]
- 对比同类（Deepseek本地部署，非本产品本身）：「想要数已售数都有好几百的了」[00:04:50]–[00:04:56]；「他的最高销量是889个人想要」[00:05:57]–[00:05:59]

**截图**：无（待实搜）

**适合拆成的"讲一个"角度**：
1. "用AI桌面agent，让AI帮你把AI部署好"——依据[00:00:51]–[00:01:05]
2. "客户要接飞书/企微/千牛，都能再加钱"——依据[00:08:24]–[00:08:49]
3. "小众工具的部署需求，比大众工具小但也真实存在"——依据[00:04:35]–[00:05:59]

**盘点用一句话**：定价30到100多元一单，一个月能赚零花钱到几百块——依据[00:03:33]–[00:03:40]与[00:04:29]–[00:04:35]。

**不能说的**：
- 不能把圣矾对整体收益的推算「一个月赚个几百块钱是能做到的」[00:04:29]–[00:04:35]当成实测收入承诺，这是圣矾的推算，不是同行自报或圣矾亲测数字
- Deepseek本地部署的想要数/销量数据是同类对比参照，不是这个cloudbot/Openclaw产品本身的数据，不能混着当成这个产品的销量说
- 远程操控客户电脑这一步，字幕没讲授权和数据安全边界，不能替这个操作模式背书"安全可靠"

**字幕识别拿不准的词**：「这节课我们讲的loadbot这个产品」[00:01:59]–[00:02:02]——"loadbot"读法拿不准，结合后文"cloudbot"，疑似识别错误，应为"cloudbot"（识别可能有误）；「它还有一个名字叫IM什么来着我忘了」[00:03:23]–[00:03:27]——具体第三个别名字幕没说清楚。
