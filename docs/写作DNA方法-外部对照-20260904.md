## 0. 一页结论

1. **writing-dna-skill 的价值是流程，不是内容。** 仓库 965 star，但 `templates/` 里五份产物模板**全是「待填写」空壳**（实测每份 14–363 字节）。它真正提供的是：六层维度定义、七步工作流、逐篇元数据 schema、以及一条我们完全没有的硬规则——**每次写作前必须重读全部分层产物 + 检索 5 篇最像的原文**。

4. **当前稿（首句「京东官网上一次两小时的保洁，标价一百二。」，106 行）在这三项上全是 0。** 问号 0、指图 0、赚/利润/差价 1 次（语料 79 次）。它有价格，但从不把价格换算成钱——这是最像又最不像的地方。

## 1. writing-dna-skill 读透

仓库：https://github.com/larashero3-dotcom/writing-dna-skill ｜ ★965 ｜ 最近推送 2026-08-24 ｜ MIT ｜ 中文原生
配套：https://github.com/larashero3-dotcom/lieflat-less-ai-tone ｜ ★599（去 AI 味，随主仓安装）

### 1.1 它的维度清单（六层）

| 层 | 分析对象 | 它规定的提取方法 | 产物文件 |
|---|---|---|---|
| **L1 表层语言** | 词频、句长、标点、修辞 | **脚本统计** | `语言DNA.md` |
| **L2 文章结构** | 开头 hook、正文架构、转折、结尾收束 | **人工标注** | `文章结构模板.md` |
| **L3 选题逻辑** | 发布时机、切入角度、话题优先级 | 归纳分类 → **选题判断树** | `写作视角与认知框架.md` |
| **L4 素材策略** | 引用来源类型、权威对象选取标准、数据使用方式 | 阅读归纳 → 素材偏好清单 | 同上 |
| **L5 认知框架** | 世界观、价值判断、核心假设 | 深度阅读 → **核心命题列表（≥3 条非显而易见）** | 同上 |
| **L6 视觉风格** | 配图策略、排版格式、字体层级、色彩 | 图文统计 + 截图采样 | `视觉风格指南.md` |

它自己给的口诀：**L1–L2 是「怎么写」，L3–L5 是「怎么想」，L6 是「怎么呈现」。**
并明确警告三种失败模式：只复刻语言 →「读着像但想法不像」；只复刻结构 →「框架像但语气不像」；忽略视觉 →「文字像但看着不像」。

每层它规定要量的东西，细到这个程度：

- **L1**：高频名词 100 个 / 高频动词 50 个 / 高频副词（它认为过度使用的副词 = 噪声，要过滤）；平均句长（字符）、短句 ≤15 字占比、长句 ≥50 字占比、段落平均句数；破折号 vs 括号使用比、引号使用场景、小标题平均字数、中英混用模式。
- **L2**：`[hook 类型]+[字数] → [第一转折点] → [正文结构：总分/对比/时间线/Q&A] → [结尾：收束/悬念/呼吁/自然结束]`，然后**按内容类型**归纳成多套模板。
- **L6**：图文比、每隔多少段一张图、图片类型分布、首图风格、来源模式；**图片功能六分类**（证据型/演示型/数据型/叙事推进型/情绪型/权威型）；**图文协作模式**（引导语→截图→解读？截图即论证？文字概括+截图精确？）；每千字加粗次数；分隔方式。

### 1.2 跨层原则：图片必须打开看

单独立了一节，要求「至少抽样 5–10 篇文章逐张查看图片内容」，理由是截图往往是论证链的承重件，精确数据经常**只存在于图片里**。这一条同时影响 L2（转折点在截图里）、L4（截图是核心素材形式）、L6。

### 1.3 七步工作流

1. 收集 ≥20 篇完整文章 → `raw/`，命名 `YYYY-MM-DD 内容类型 标题-来源.md`
2. **逐篇元数据 → `_meta/`**（不可跳过）：`title / date / author / column / article_type / topic_tags / hook_type / structure_pattern / source_types / word_count / notable`
3. 脚本分析 L1
4. 结构标注 L2
5. 深度阅读归纳 L3–L5（明写「无法用脚本替代」）
6. 视觉分析 L6
7. 整合成 `Writing-DNA.md`

### 1.4 校验环节

**有，但是软的。** 只有第五节一张自检清单，六条：

- [ ] 喂 `Writing-DNA.md` 给 AI 能否写出该风格文章（**评分 ≥7/10**）
- [ ] L2 结构模板覆盖**至少 3 种内容类型**
- [ ] L5 提炼出**至少 3 条非显而易见**的核心命题
- [ ] 元数据覆盖 ≥80% 语料
- [ ] L6 覆盖配图/排版/色彩三维度
- [ ] `Writing-DNA.md` **≤4000 字**（过长 = 没蒸馏干净）

全部靠人读判断，**没有一条能机器跑**。没有词表、没有阈值、没有脚本。

### 1.5 最有价值的一节：第六节「使用蒸馏产物写作」

这是整个仓库里我们最缺的东西，它写成了硬性步骤：

1. **每次写作前重读全部四份分层产物 + 整合文档，一份都不跳过。** 理由写得很准：「整合文档是压缩后的结论，具体的语感、句子长短、过渡方式和标点习惯只存在于分层产物和原文里。」明令禁止「只凭 `Writing-DNA.md` 或凭上一轮对话的记忆下笔」。
2. **再读 5 篇体裁题材最接近的 `raw/` 原文**，按 `_meta/` 的 `article_type` + `topic_tags` 筛，超过 5 篇取最近的（近期文章更代表当前风格），不足则同体裁不同题材补齐。目的写得很明白：**不是找素材，是校准分层产物描述不出来的东西——句子的呼吸感、段落怎么接、什么时候突然用一个短句。「读完要能说出这 5 篇的共同语感」再动笔。**
3. **冲突优先级**：用户本次明确指令 > 匹配当前体裁的 L2 结构模板 > L1 语言 + L6 视觉 > L3–L5 认知框架。
4. 原文的**具体观点和事实不能搬进新文章**——复刻写法不复刻内容。
5. 输出不像时，对照三份分层产物**逐项自检后重写**。

### 1.6 去 AI 味的挂接方式

`skills/lieflat-less-ai-tone/`（28KB，11 条规则）作为**最后一道工序**，白名单式改写：只处理清单内规则，未命中的句子逐字保留，不动结构。每条规则带**可定位触发标记 + 实测倍率**（例：顿号罗列过密「AI 3.21/千字、人类 1.78，倍率 0.56」；相邻句结构同款「AI 每百段 9.41 处、人类 4.81，2 倍」），基于 300 篇 AI 输出 vs 329 篇真实文章实测，明确拒绝「读起来像 AI」这种语感判断。

**关键设计**：`蒸馏产物 > 去 AI 味规则`。「那是目标作者的真实写法，不是 AI 痕迹。比如某作者本来就爱用破折号，就不该按通用规则删掉。」

> 这一条我们已经独立踩到并解决了——`prompt.mjs` 里「风格标志段优先级高于所有『少做什么』清单」正是同一个结论，且我们的实现更强（注入位置在负面清单**之后**）。

### 1.7 中文/口语支持

- **中文原生**，README/SKILL 都是中文优先，产物文件名就是中文。
- 明确分离「对话语言」与「产物语言」：可以用中文下指令、产出英文 Newsletter DNA。
- **但它只面向图文**：长文、公众号、博客、Newsletter、专栏、小红书图文。**没有任何口播/短视频/逐字稿的处理**。L6 整层（字号层级、色彩、加粗密度）对口播稿直接不适用；语速、停顿、断句、口头禅、称呼语这些口播核心变量它一个都没有。
- 语料门槛 ≥20 篇。我们钱十七只有 10 期，**低于它的下限**。

### 1.8 它没做的

- 产物模板是空的，没有任何填好的样例（`examples/format-only/` 只有 `.gitkeep`）。
- 没有防抄袭 / 泄漏检查（我们有 12 字重合检查）。
- 没有合规词表（我们有平台违禁词）。
- 没有事实边界（我们有事实卡 + 知识包 + 证据登记）。
- 没有任何脚本。README 说「用脚本分析的方式沉淀总结」，仓库里**一个脚本都没有**（`agents/openai.yaml` 只有 251 字节）。

### 4.4 `写作视角与认知框架.md`（L3–L5）

**L3 选题逻辑（六层完全没有这一维）**

- **只写「一个具体品类 + 一个具体平台动作」**。从不写心态、认知升级、时间管理这类无动作的题。每期都能落到「今晚就能上手的活」。
- **切入时机 = 窗口期还开着的时候**，并把窗口期本身当卖点：「这些品类的窗口期最多3个月，大卖家看不上，等他们进来的时候你早就赚够跑路费了」。
- **不写的题**：需要重资产的、需要专业资质的、需要长期积累才见效的。他的选题门槛线明写在语料里——「不需要推广，不需要发货，不需要投入一分钱」「所有服务都围绕低时间成本，不用专业知识」。
- 角度固定为**当事人视角**（我做过 / 我学员做过 / 我小伙伴在做），从不用旁观者视角。

**L4 素材策略**

- 主素材是**平台界面截图**：销量图、搜索结果页、榜单、同行店铺宝贝列表、商品详情页。
- **精确数据只存在于截图里**，口播只负责指认和解读——这正是 wdna 跨层原则说的「截图是论证链承重件」。
- 权威对象的选取标准很特别：**权威不是专家，是「已经跑出数字的同行」**。他引用的「权威」全是洛曦学姐、原创壁纸小屋、那家卖了两万多份的账号。
- 敏感信息处理：**明写风险并甩责**（「请不要囤货」「知名IP新手一律别碰」「一律指给官方客服」），但**不放弃项目本身**。

**L5 核心命题（它要求 ≥3 条非显而易见，实测有 4 条）**

1. **钱不是赚来的，是找出来的。**（信息差 / 套利 / 认知差是唯一的钱源）
2. **赚钱是设计出来的，不是熬出来的。**（反努力叙事，明确反对「感动自己」）
3. **烂大街的从来不是品类，是大而全。**（细分才有购买理由；「大类是词，细分是名字」）
4. **不偷不抢，搬运信息差不需要道德负担。**（「拜托，我们不偷不抢」「能抢的先抢，能抄的赶紧抄」）

**人设关系（借 ArticleSkill 的维度）**：他与观众的关系是**已上岸的老江湖对新手**，不是老师对学生。所以他敢说「我小伙伴」「我贿赂了他很久」「17偷偷分享」——**私授** 而非 **公开教学**。

### 4.5 `视觉风格指南.md`（L6 · 口播版 = 口播如何指涉画面）

wdna 的 L6 原义（字号/色彩/加粗）对口播稿不适用，但它的**图文协作模式**问法直接可迁移。实测：

- **指图话术 39 处**（这张图/你看/图中/看这/这家店/截图/榜单/如图/画面/数据是），平均**每期近 4 处**。
- **图文协作模式是固定的三段式**：`口播抛出判断 → 指认画面 → 从画面读出数字 → 回到判断`。
  例：「这张图就是证据。在咸鱼搜五更琉璃壁纸，全站一共才5件结果，系统还专门提示你结果较少。这就是一条没人抢的搜索长尾。」
- **图片功能分类**（套 wdna 六型）：**证据型**（销量图、搜索结果页）与**数据型**（榜单）占绝对多数；**演示型**（一步步点哪里）在保姆级教学期占多数；几乎无情绪型、无权威型。
- **专属互动位**：「建议暂停截图保存」5 处——这是**口播独有的、把画面变成资产**的动作，图文体裁里根本不存在。
- **结论：钱十七是对着屏幕讲的，不是对着摄像机讲的。** 他的稿子默认观众正在看一块屏幕，随时可以被叫去看某一处。

### 7.4 只能靠人眼的

- **「老观众听不出换了人」**——这是 `prompt.mjs` 自己写的判据，任何计数器都证明不了。wdna 的自检第一条（评分 ≥7/10）同样承认这一点。
- **金句是不是真的「反转」**——可以数句式，不能数它有没有真的翻掉一个常识。当前稿第 5–6 行有反转的**形**，没有反转的**力**，这个差别机器判不了。
- **算出来的账可不可信 / 合不合规**——数字关系机器能查，但「这个假设流水在这个品类里合不合理」只能人判。
- **体裁选得对不对**——模板 A/B/C 选错时每一项计数都可能达标，稿子照样不像。
- **江湖气的分寸**——「懂的都懂」用一次是味道，用三次是油腻。上限比下限难定，建议先只设下限，由人看上限。

**建议排期**：F1 + F2（流程，一天内可做完，预期收益最大）→ P1/P2/P3（prompt 三节，半天）→ C1/C2/C3/C5/C6（简单计数器，半天）→ C4（中文数字算账检查，单独一天）→ F3（文档重构）→ P5（需用户先定字幕约束）。
