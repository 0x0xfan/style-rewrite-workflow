## 三、跨期稳定文案模式

### 1. 开场钩子：数据先行 + 极短悬念 + 自报IP + 互动小钩子

近乎铁律的"冷开场"（intro 之前就甩数字），四拍：
1. **价格/客单价**（"售价18块8""标的6块6毛6""1到4块"）
2. **想要数 + 浏览量**（"702个人想要将近1万浏览"）
3. **推算利润 / 总成交**（"账号卖了2000多个宝贝""一单净赚八块""赚了一二十万"）
4. **自报家门 + 系列包装 + 标题**："我是圣矾""学闲鱼找圣矾""闲鱼虚拟搞钱108计的第X计"+ 本期题目

常在其后接一个**弹幕互动钩子**（为完播/互动服务）："大家都用什么做笔记""你用苹果还是安卓""买过的扣个一"。

变体：13 用"爽点"冷开场（不用发快递/自动发货）再上数据；37 用"官网vs携程"对比截图冷开场；40（纲领）用**自家实时后台**冷开场；32/43（揭秘）用"10秒必出单""只做揭秘"做悬念冷开场。

### 2. 数据用法：三处出现，推算全透明，口径保守

- **出现位置**：①冷开场；②intro 后展示同行链接时**原样再报一遍**（"你可以看这个同行…"）；③拓展/延伸段落再举数据。
- **推算链条透明**：拿货价→卖价→单利润→日单量→月/总收益，一步步算给你看。例：18"两块卖八块净赚六，一天10单60块，一月1800"；24"按3块算，店20万件→60多万纯利润"；44"1000想要×30%转化=300单→2000多"。
- **保守口径**：反复用"最起码""按最保守的算法""就算按…算"，主动压低预期，反而更可信。
- **可验证信号**：同行的店龄（"八年老店""才开一年"）、在售宝贝数、销量，都是"真实存在、可自己去搜"的证据。
- **信息差可视化**：官方价 vs 渠道价并置（GPT 20美金 vs 39.9三个月；万豪官网 vs 携程），把"为什么有钱赚"直接摆出来。

### 3. 信任装置清单（按重要性排序，各附一例）

1. **同行真实数据截图 + 推算透明**（每期必有，最核心）。"口说无凭…带你看后台"（13）。让真实性可自行验证。
2. **风险直说、直指命门**。"这个品有个致命的风险你必须知道"（18 掉签钱货两空）；"这个品是有风险的…一上就封"（23）。敢讲坏处＝可信。
3. **现身说法 / 亲测踩坑**（建立"这人真懂"最强装置）。"我四五个账号轮着用"（23）；自己买了同行的号、截图证明"已经封了"（32）；**自曝被起诉赔5万、去应诉、咨询律师法官**（32）。
4. **承认不确定、不把话说满**。"他这个号能不能活到一星期另说"（32）；"并不是每个品都适用我那个方法"（23）；承认"卖教程客单价肯定最低"（44）。
5. **粉丝案例 / 社群背书**。"80%粉丝7天之内出单"（多期近乎逐字复用）；"闲鱼翻身群里一位小伙伴选品看到的"（44）；朋友卖哪吒二"三个月提了辆宝马"（24）。
6. **反直觉纠偏（内行感）**。"才卖一块钱能赚啥？这么想你就错了"（20）；"很多人以为到这步就结束了，大错特错"（13）。把自己摆在"知道内情"的位置。
7. **合规边界教学（责任感＝信任）**。教你别写"百分百原题、一把过"、卖整理版不做绝对承诺（20）；三层违禁词检测（44/43）。
8. **官方/正版背书**。"这是闲鱼官方的AI"（13）；"我找的是正版题库"（44）；侵权风险咨询律师后再讲（32）。

### 4. 正文结构骨架（稳定复现）

1. 数据冷开场（同行价+想要+浏览+推算）
2. 自报家门 + 期号slogan + 标题 + 互动钩子
3. **这是什么品 / 需求为什么成立**（人群+痛点，常配生活化故事）
4. 同行数据展示（再报一遍数字，亮店龄/宝贝数）
5. 利润推算（透明链条、保守口径）
6. 怎么做 / 渠道（选品→抄同行→截图上品→自动发货；或找同行拿货三标准；或渠道分三类）
7. 风险与合规（封号/掉签/侵权/违禁词，直说 + 规避法）
8. 拓展收益（网盘拉新分成、卖课、多SKU、高客单延伸）
9. CTA收尾（三连关注私信发X计领彩蛋/评论区）+ "闲鱼虚拟搞钱108计，咱们下一计再见"

**一致度**：步骤 1、2、8结尾模板 ≈ 100% 固定；步骤 3–7 的**要素齐全但顺序按题材微调**。揭秘期（32/43）弱化"怎么做"、强化"揭露机制 + 别上当 + 合规"；纲领期（40）打破单期结构，改为"为什么选闲鱼→新规→五步方法→盈利提升"。

### 5. 风险与合规讲法

- **位置**：通常在"怎么做/渠道"之后、CTA之前，作为独立一段。
- **手法**：先点"命门/致命/100%封号"，紧接给**规避方案**（选货三标准、卖整理版、违禁词检测、转嫁风险）。把风险讲透＝把信任建起来。
- **揭秘期**：风险即主题，"100%封号且封得很快""不要上当受骗"，并用亲历侵权诉讼加持权威。

### 6. CTA / 转化

- **整体克制**，不逼单。主转化＝**彩蛋**（免费教程、知识库、违禁词库、避坑资料）→"三连加关注后私信圣矾发X计"或"评论区领取"。
- **软广自有产品/服务**提及克制：违禁词检测工具、上品系统、"闲鱼翻身"群、主页课堂付费资料（32）、工作室高客单代做（13）。
- **高复用转化模板**（多期几乎逐字）："闲鱼虚拟半自动挂机入门教程，80%粉丝7天内出单，资料放评论区了。"

### 7. 口吻特征（简要）

- **人称**：自称第三人称"圣矾"（强化IP），对观众"你/大家"。
- **句式**：短句、口语、高频重复。
- **口头禅**："其实""说白了""等等等等""最起码""轻轻松松""卖就完了""大错特错""没有之一""思路打开"。
- **语气**：接地气的"搞钱老哥带你拆项目"，自信、直白（甚至"这个恶心的玩法"）。
- **真人即兴证据**：字幕含 ASR 错字/口误（圣矾/胜文/圣凡、GBT/Jimmy/Germany 实指 Gemini、cloud 实指 Claude），说明真人即兴口播、非念稿——本身也构成"真实感"。

## 四、必须保留 vs 可被风格替换

### A. 必须保留——"信任配方"核心（换任何写作风格都不能丢）

- **数据冷开场**：先甩同行真实数字（标价/想要/浏览/店龄/宝贝数），后讲一切。
- **透明利润推算链**：拿货价→卖价→单利润→单量→总收益，且**保守口径**（"最起码/按最保守"）。
- **同行真实截图＝可验证证据**（可自己去搜的店铺/数据）。
- **现身说法/亲测**：自己在用、自己踩过坑、自己被起诉赔过钱。
- **风险直说 + 规避方法**：命门、封号、掉签、侵权、违禁词、不做绝对承诺。
- **承认不确定、不把话说满**。
- **反直觉纠偏**带出内行认知（"你以为…其实错了"）。
- **合规边界教学**（教用户避坑）。
- **需求逻辑先于方法**（先讲"为什么成立"，再讲"怎么做"）。
- **先免费给料、再要三连**（价值前置的克制CTA）。

### B. 可被风格层替换——纯个人口吻（可换成任意人设/文风）

- IP 包装：自称"圣矾"、slogan"学闲鱼找圣矾"、"108计第X计/下一计再见"系列话术。
- 口头禅与江湖亲和腔（"说白了/搞钱/等等等等/轻轻松松"）。
- 弹幕互动小钩子的具体问法（"扣个一/顺便问一嘴"）。
- 举例题材与私人故事（提宝马、大学买的switch、汽车冰箱彩电大沙发）。
- ASR 错字、口误、即兴啰嗦与重复。
- 三连话术的具体措辞（"私信发X计" vs "评论区领"）。

**一句话**：把这套文案搬到任何写作风格，只要保住"真实数据 + 透明推算 + 亲测 + 风险直说 + 合规教学 + 保守不夸大"这套**证据链式信任配方**，成交力就在；被替换的只是"谁在讲、用什么腔调讲"。
