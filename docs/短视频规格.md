# 短视频规格（v1，2026-09-24 用户定）

状态：v1 定稿（2026-09-24 两类各 3 条试稿用户评「差不多对了」）。试稿样本在 `scratch/短视频试稿-20260924/`（SRT 类 3 条、知识类 3 条）。

## 总规矩
- 时长 **1–2 分钟，写 300–600 字**（用户 2026-09-29 定竖版账号和真人出镜的长度；原"60–90 秒、280–340 字"作废）。字数多了是把闭环交代完整、把关键做法讲透，不是塞第二个技巧；下面骨架各段的字数按比例放大。风格照旧钱十七线，写稿规则表（`docs/写稿规则.json`）和用户校准词表照常适用（话说全、人话、禁词）。
- **每条都在讲"在闲鱼上靠这个赚钱"**（用户 2026-09-24：「你要记得我是在讲闲鱼赚钱……这种短视频文案里面要讲数据，要讲闲鱼」）：前两句里必须出现"闲鱼"，并且带至少一个闲鱼上的数据（想要人数、浏览数、标价）。数据来源：该期 SRT 原话，或 `research-runs/<期>/事实卡-终版.md` 里的闲鱼实采数据；两处都没有闲鱼数据的选题不写。收益数字仍不写。
- **一条讲完一个最小闭环**（用户 2026-10-02：「短视频的文案普遍完整性都太低了，文案读下来整体感觉都不完整」；原"一条只讲一件事"被写手理解成只讲一个细节，读着像长视频截下来的一段，作废）。不管用哪个骨架，下面几样每样至少一两句交代到位，篇幅主要花在骨架要讲透的那个关键做法上：
  - **产品题（A 类）**：①这是什么生意、钱从哪来（开头就交代）②谁在买、为什么买 ③货或工具从哪来、怎么交付给买家 ④一个关键做法（骨架的重点）⑤新手怎么开始——落到第一步，读完有收尾感，但不是金句总结。
  - **知识题（B 类）**：①这是什么问题、谁会碰到 ②为什么会这样 ③怎么做（骨架的重点）④做对了会怎样 / 做错了亏什么 ⑤新手先做哪一步。
  - 闭环之外冒出的第二个技巧、第二个坑，留给下一条。
- 第一句就是钩子（长短不限，见开头菜单）；不预告（"今天聊聊""我讲三点"）。
- 中间不用"首先/其次/接下来/第一第二"；靠问句推进或直接接。
- 结尾不总结（不说"所以说""记住这三点"）。
- 不放收益数字、不放资源引流（彩蛋/扣关键词也不放，用户 2026-10-02 再次确认）；诱导改用反差、悬念、信息缺口、损失、互动钩子；必须过 `npm run check:compliance`。

## 讲述人（用户 2026-09-24 纠正："这应该是做了很多年项目的我来说，你不能用别人来说"）
- 短视频里所有知识、做法、道理都由"我"（做了很多年项目的圣矾）来讲，不写"同行 X 说过""我看同行的做法""某某专门讲过"，不点同行名字。
- 边界：道理和做法直接用"我"的口吻讲（"我的做法是""我一般会"）；原文里别人的具体踩坑故事不改成"我踩过"，改成"我见过很多人……"；"我"的具体经历仍只用经历清单/SRT 里有的。

## 骨架（按素材挑合适的，再在合适的里轮换；每个骨架都要装下上面的最小闭环，骨架只决定重点放在哪）
A. SRT 改写（讲产品）
- A1 反差型：反常识钩子(40) → 这东西是什么、谁在买(70) → 为什么能卖(120) → 一个坑(70) → 收尾(30)。适用：产品本身有"没想到这也能卖"。
- A2 场景型：一个买家场景(60) → 他真正要什么(70) → 卖家怎么接住(150) → 收尾(30)。适用：SRT 里有具体买家/成交经过。
- A3 拆一个细节（细节之外，生意是什么、谁买、货从哪来、怎么开始仍要各用一两句交代）：点出细节(40) → 多数人怎么做(80) → 应该怎么做、差在哪(170) → 收尾(30)。适用：SRT 里有具体操作（标题/主图/定价等）。

B. 知识分享（知识库文章）
- B1 误区型：很多人这么做(50) → 错在哪(100) → 正确做法(150) → 收尾(30)。
- B2 损失型：不知道会亏什么(50) → 为什么(120) → 怎么避开(130) → 收尾(30)。适用：有真实后果。
- B3 一问一答：卖家常问的问题(40) → 直接答(120) → 补一个想不到的点(130) → 收尾(30)。

## 开头菜单（2026-09-24 按用户给的 7 条样本重做；记结构，不记句子）
核心：开头讲**观众想要的**（搞钱、翻身、自由、少走弯路）或**"我"的态度/经历**，不讲产品细节；项目名压到句尾揭晓，产品细节放到开头之后。用"我""你"直接说话。长短不限，关键是第一句就是钩子。
1 后悔：先抛情绪结论（后悔没早做），做什么先不说
2 资历+唯一：我换过很多项目 → 唯独一个没换 → 揭晓
3 向往+卖点连发：为了某种生活 → 我一直在做 → 连串"不用……" → 揭晓
4 门槛+承诺：如果你能吃苦/熬夜 → 像我一样做 → 你会庆幸早点开始
5 时间窗口：想在剩下的时间里翻身 → 别只做常规的事 → 趁现在用这个方法
6 信息差：还有谁不知道，X 也能卖钱
7 多数人卡住：大部分人都卡在第一步 → 这一步就是 X
- 2/3/4 以及任何"我"的经历，只能用 `docs/圣矾真实经历清单.md` 或该期 SRT 里有的真事，不编。
- 力度（用户 2026-09-24 定"保留结构、直接承诺换软"）：不写"回来感谢我/大搞一笔/搞到米/99%/具体月份或暑假"；换成"你会庆幸早点开始""大部分人""趁现在"这类说法。
- 开头之后第一步就是把项目揭晓/落到本条产品上，再进骨架正文。
- **开头钩的问题必须是正文主体回答的问题**；正文要到最后一两行才回应开头，就换开头（2026-09-24 dbs 审稿发现，用户认可）。
- 开头先翻本期 SRT 找硬数字：想要人数、单价、浏览数优先放进第一句（收益数字照旧不写）。
- 开头留一个"为什么"不答，答案放正文。
- 同一个问句说法（如"为什么……能吸引 N 人想要？"）一批里最多 2 次；硬数字也可以直接说出来，不一定要问。

## 正文
- 行话当场说成人话；容易混的词（如"链接"和"规格"）一句里只讲一个。
- 结尾点到的人、问的事，前面要铺垫过。

## 结尾三步（用户 2026-10-02 定；取代下面结尾菜单的"最后一句"用法）
用户原话：「你这个结尾太突然了」「这个短视频里面需要对自己做下包装，要不然用户看完没有想添加我好友的欲望」；裁定「只包装，不放彩蛋」。
1. **收拢一句**：闭环第⑤样（新手第一步）说完后，用一句话把这门生意收拢（如"片源有了、标题写对、片子挂多，这个品就跑起来了"），不是金句、不讲道理。
2. **自我包装**：自报家门 + 一条真实资历或成绩，只用 `docs/圣矾真实经历清单.md`、该题选题核心、SRT 里有的真事（如"我自己做过一个号，三百八十四单"），不编收入；同题几篇、相邻几篇换不同的资历说法。
3. **口号收尾**：最后两行固定「我是圣矾。」「学闲鱼，找圣矾。」，两行各自独占一行、相邻（视频项目合同要求「我是圣矾」独占一句、全篇一次），资历那句放在它们前面。
- 不放彩蛋、不放"评论区扣关键词"，不写加微信、私信、主页链接。
- 下面结尾菜单（抛问题 / 反转 / 动作 / 说完就停）只能用在第 1 步之前的正文收束处，不能当全篇最后一句。

## 结尾菜单
1 抛问题让人评论　2 留悬念引下一条（下一条真存在才用）　3 反转一句　4 今天就能做的一个动作　5 说完就停
- 不写"……把这条转给他/转给你身边的……"这类转发结尾（用户 2026-09-24：「正常短视频文案没有这样的结尾」，已从菜单删除）。
- "说完就停"的最后一句必须是一件具体的事或一个具体步骤，不能是评价或总结；"反转"要翻转一个事实，不能讲道理。
- "很多人以为……实际上……"算反转句壳，一批最多 1 次；反转说的那件事必须出自 SRT/事实卡，不能为了凑反转编事实（2026-09-24 批量验收：两条结尾编了"买家主动续费""评价最认可打卡提醒"）。
- "足足有""实打实"这类加重词一批最多 1 次。
- 反转一句不等于金句总结；不用"不是……而是……""从来不是……只是……"这种纠偏句壳收尾。

## 防重复
- 批量前先排表（条目 × 骨架 × 开头 × 结尾）：同一开头 10 条内 ≤2 次；相邻两条开头、结尾都不同；骨架轮到。
- "其实/说白了/关键是/你想想/省心/交付起来非常……"类口头禅一批每个 ≤1 次。
- 已用账、机器查重：批量开始后再补。
