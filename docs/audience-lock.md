# 受众锁

**状态：已确认（用户 2026-09-26：我的客户是不懂闲鱼的，他是想赚钱的）**

以 DECISIONS 2026-09-26 和 daily-write 为准：观众固定是"不懂闲鱼、想赚钱的人"，正文不分三类起点、不分流，开头先回答小白的问题（这是什么生意、谁在买、怎么交货、难不难、钱从哪来）再进主题；下面正文里跟这条冲突的旧说法（比如三类起点分流、券类例子、"零成本第一步"）不再适用，仅供参考。

这是项目级事实，不属于任何单个 IP。所有赚钱项目类成稿在生成前必须先对齐这里，与具体用哪个 IP 的风格无关。

## 四个角色

| 角色 | 锁定为 | 不是 |
| --- | --- | --- |
| `narrator` 讲述者 | 圣矾，正在实操这个项目的人 | 局外评论者、研究者 |
| `target_viewer` 目标观众 | **想找副业、还没开始做这个项目的人**（三类起点共存，见下） | 已经在做、正在找问题出在哪的卖家 |
| `case_buyer` 案例买家 | 在闲鱼上买券的普通消费者 | 观众。买家痛点只用来证明需求存在 |
| `content_goal` 内容目标 | 让观众看懂从零到第一单要过哪几关，并做出一个零成本的第一步动作 | 帮已入行者诊断卡点；教买家怎么买 |

## 三类起点共存，开头必须分流

目标观众不是单一人群，下面三类同时存在，不能只吐一种：

| 起点 | 他的第一个问题 | 稿子要给什么 |
| --- | --- | --- |
| 在找副业，没用过闲鱼 | 这事靠谱吗？我能做吗？ | 需求怎么自己验证，以及试错成本几乎为零 |
| 卖过闲置，没做过项目 | 卖东西我会，难在哪？ | 直接指向货源，那才是真门槛 |
| 在几个副业里挑 | 这个比别的强在哪？ | 可比较的真实天花板，不是“月入过万” |

**做法是分流，不是切成三段各讲一遍。** 开头用一句话告诉每类人从第几关开始听，正文按最零起点的人写，让另外两类人自己跳。

分流句必须给具体动作或具体价值，只念章节名不算（A2）。

## 判断方法

写完后逐句问：**这句话，一个还没开始做的人听得懂、用得上吗？**

以下都是受众漂移的信号：

- 拿两个卖家做对比（"有人挂一个月没动静，我三天出单"）——只有已经在卖的人才关心
- "你听完就知道自己卡在哪一环"——预设你已经在跑
- "你的拿货成本是下限"——预设你已经有货源
- 直接进操作细节，没先回答"这生意到底成不成立"
- 用行业黑话而不解释

## 收益数字的处理

观众还没开始，所以任何收益数字都必须同时满足：

1. 明确归属于讲述者或案例人物，不是对观众的承诺
2. 紧跟一句下调预期的话（"你要是一天只出三五单，那就是三五单的收入"）
3. 说清它取决于什么
