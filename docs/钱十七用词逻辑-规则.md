# 钱十七用词逻辑 · 规则（草案，待用户过目）

> 来源：用户 2026-09-05 手工拆解 19 句 + 机器按同一标法拆完 10 期 458 句（第 3 篇与第 7 篇是同一稿的两份转录，按一篇算）。
> 用户的总判断：**他一直在为后面要讲的内容做价值包装。** 下面全部规则都从这一句推出来。
> 这是写稿人看的规则，不是门禁。冻结期不改任何检查器。

## 〇、一句话总纲

**每段干货开讲前，先给这段抬价；抬完就老老实实讲，讲完用一句结果收口。**

他的词分两类：抬价的词，和最普通的连接词。心思全花在抬价的词上，连接词永远用最土的。我们以前正好反过来。

## 一、结构规则：什么位置做什么

实测 458 句里 245 句没有任何包装。包装不是均匀撒的，是按位置堆的。开头 51 句里 41 句在包装，往后每段稳定在四成左右。

| 位置 | 做什么 | 不做什么 |
| --- | --- | --- |
| **开头 5–9 句** | 按这个顺序走，可以少一两步但顺序不乱：①痛点或对比（知道归知道，想做却无从下手 / 一顿兰州拉面变一顿海底捞）→ ②宣告这是赚钱项目，**直说卖什么、赚谁的钱、一单多少**（本期项目卖的虚拟资源是状元笔记 / 一份卖 30，一万份就是 30 万）→ ③结果渲染（学完当天就能出单）→ ④来源包装（我三年经验总结 / 学员亲测）→ ⑤立框架（三个视频 / 六做六不做 / 就四件事）→ ⑥催点赞带一句稀缺（以免后面找不到了） | 读屏悬念开头；只算账不说生意；开头讲注意事项 |
| **每一块的第一句** | 贴一个价签，四选一：结果渲染 / 来源包装 / 道理口诀（选品不对，努力白费）/ 打脸旧认知（醒醒吧，他们不过是在套利） | 悬念预告（"最要命的放最后"全语料只出现 1 次） |
| **块内干货** | 平铺直叙。连着十几句纯步骤是正常的，不用每句找味。每 5–10 句最多插一句贴士（这里特别强调一点 / 建议暂停截图保存） | 每段用力、每段反问收尾、每段一个口头禅 |
| **每一块的最后一句** | 一句结果收口（三天你就能养出一个完美活跃度的号 / 到了这一步你已经…） | 免责、退让 |
| **清单类内容**（货源表、月份表） | 只在头尾包装，中间全裸。他 39 个货源那期 49 句里 42 句没包装 | 给清单每一条配感想 |
| **结尾** | 来源包装（以上都是我花三年亲自验证的）→ 资料钩子 → 催三连 → 固定收尾句 | 总结全文、升华 |

## 二、包装手法：十种，各自的槽位

每种手法都是一个句式加几个槽位。造新句就是换槽位里的东西，句式不动。

| 手法 | 他的原句 | 槽位 | 我们怎么造 |
| --- | --- | --- | --- |
| 结果渲染 | 学完当天就能出单 / 第二个月直接卖爆 / 每天多赚 100 块 | [做完某事] + [多快] + [具体结果] | 结果说动作和出单，不说月入；时间越短越像他 |
| 门槛拆除 | 不需要推广、不需要发货、不需要投入一分钱，只需要复制粘贴 | 三个"不需要" + 一个"只需要" | 三不一只的骨架照抄，填这个项目真实的不需要 |
| 来源包装 | 我三年经验总结出来的 / 学员亲测有效 / 花了 1000 多块买来的 / 从上千个网站挑出来 | [来源] + [代价或时间] | 用圣矾自己真实的代价：做了多少期、试了多少家、翻了多少页 |
| 大数强调 | 一份卖 30，一万份就是 30 万，妥妥的 | [单价] × [大整数] = [大数] + 断语 | 乘到大整数后立刻下断语；免责挪到别处单独一句 |
| 对比 | 菜鸟走向高手 / 别人红到发紫，你的卖不动 / 一顿拉面变海底捞 | [差的那头] 变 [好的那头] | 两头都要具体，最好是吃的用的 |
| 立框架 | 三个视频 / 四大核心维度 / 六做六不做 / 就四件事 | [数字] + [名字] | 数字优先，能起名就起名（静默养号法、黄金选品公式） |
| 替观众提问 | 可能有人会说我自己都不会减肥，怎么做？/ 那这种资料去哪里找啊？ | [观众的顾虑] + 问号 | 一块讲完、下一块开讲前用，替观众把话说出来 |
| 稀缺紧迫 | 以免后面找不到了 / 建议暂停截图保存 / 90% 新手都会踩坑，一定要认真看 | [丢了会怎样] | 只跟点赞收藏和截图搭配，不跟悬念搭配 |
| 道理抬价 | 资源是一切项目的开始，流量是一切赚钱的核心 / 选品不对，努力白费 / 钱不是赚来的，是找出来的 | 对仗的两句 | 一期最多两句，放在一块的第一句 |
| 打脸旧认知 | 醒醒吧，他们不过是在套利 / 那些让你跟风的不是蠢就是坏 / 你以为…错了 | [别人的做法] + 否定 + [真相] | **只在信息差那种口气的稿子里用**，见第四节 |

## 三、用词三轴：他的词都在干这三件事

除了连接词，他的每个词都在往下面三个方向里的一个使劲。造新词先问"这个词在往哪个方向使劲"，再往那个方向找普通人嘴里说得出来的话。

| 方向 | 他的词 | 平常人的词 | 造词方向 |
| --- | --- | --- | --- |
| **把价值往上推** | 讲通讲透、讲的透透的、保姆级、毫无保留、核心秘诀、万能渠道、神仙货源、神奇的类目、超级好玩、亲自验证、干货非常多、上硬菜、我隐藏多年的 | 讲一遍、介绍、常用渠道、比较有用 | 往"多、全、透、秘、亲"找 |
| **把门槛往下压** | 不需要、根本不需要、只需要、零成本、直接、自动、上架就有流量、复制粘贴、随便选一家、就行了、就 OK 了、搞定、方法很简单、也没关系不代表不能做 | 操作比较简单、即可、要求不高 | 往"不用、只要、直接、随便、就行"找 |
| **把不确定压死** | 妥妥的、一定没错、直接卖爆、自动卖爆、时间一到自动卖爆、就能、千万记住、千万别动动了就废了、肯定出爆品 | 通常有效、一般来说、可能 | 往"妥妥、一定、肯定、就能、千万"找；不许带尾巴 |

**四条补充：**

1. **连接词永远最土。** 给大家、今天 17 就、接下来、下面我会、老规矩、有需要的自取、这里给大家总结了、首先我们来看看。这些词全语料 9–11 期都有，我们一篇里一个都没用。照抄，跨期重复没问题。
2. **动作词往说话的方向造，不往书面的方向造。** 他造的词：埋进、喂进去、定死、挂在那跑着、搜一搜、留留言、点点关注、套套话。平常人的词：填写、设定、注明、运行、搜索、留言、关注。我们以前造的词（落在、散在、这一屏）方向反了。
3. **数字念出声。** 4 块 5 毛 9、9 块 9、不到 7 天 800 多个、短短两个月 993 份。不写 4.59 元。
4. **称呼。** 观众叫兄弟、小伙伴、咱们、观众老爷；自称第三人称"17"（我们用"圣矾"）。

## 四、两种口气，不混

| 口气 | 出现在 | 标志 | 用法 |
| --- | --- | --- | --- |
| **学长学姐** | 无货源、虚拟资料、货源清单、月份表、减肥监督 | 干货、保姆级、毫无保留、学员、兄弟 | 默认用这套 |
| **信息差** | 跟着别人的选品卖那一期 | 醒醒吧、韭菜、资本、套利、不是蠢就是坏、撬资本的墙角 | 只在讲"别人为什么赚到钱你没有"的选题用；一篇里不跟学长学姐口气混 |

## 五、我们的红线（不因为像他就放开）

- 躺赚、稳赚、月入过万、百分百不写。他的"妥妥的躺赚"我们只留"妥妥的"，结果换成出单。
- 不编学员、不编自己的收入。来源包装只能用圣矾真实的代价。
- 公众号、一键领取、学员案例这类他的资产不用；资料钩子按合同固定写法。
- 具体名词（店名、金额、人名、参照物）不从他的稿子里搬；句式和短语随便搬。

## 六、写稿前后各问一遍的八个问题

1. 开头三句里有没有直说：卖什么、赚谁的钱、一单多少？
2. 开头有没有按"痛点 → 宣告 → 结果 → 来源 → 框架 → 催赞"走？
3. 每一块第一句贴价签了吗？最后一句收结果了吗？
4. 块内干货是不是老老实实平铺的，没有每段都在用力？
5. 全篇有没有一处"三不一只"？有没有一处乘到大整数再下断语？
6. 抬价的词够不够（每千字他的短语不低于 60 次）？连接词是不是最土的那批？
7. 有没有往书面方向造的词？有没有带尾巴的断语？
8. 口气是学长学姐还是信息差？有没有混？

## 七、直接落到京东家政 v8 上

v8 用户的话：「没有点名是怎么赚的，一直在算各种账」。按本规则改法：

- 第 1–3 句换成宣告 + 直说生意：这是个卖京东家政券的活，赚的是券价和卖价的差，一单十块。
- 第 4–6 句：结果渲染（当天就能挂上去出第一单）+ 来源包装（圣矾自己录过一期、跑过多少家店）+ 立框架（就三件事：收券、挂单、售后）。
- 三块各自第一句贴价签，最后一句收结果；块内步骤不加味。
- 补一处"三不一只"，补一处乘到大整数再断语（同行店铺累计九千八百多件按七千单算，一单十块，七万块）。
- 连接词全部换回他的：给大家、接下来、下面我会、这里给大家总结了。
