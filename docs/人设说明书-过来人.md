> 用途：这是一份**自足**的人设说明书。写手只看这一页、事实卡、事实链和《圣矾真实经历清单》写稿，不看任何语料和已定稿。

> 版本：v1，2026-09-06，主线程写。

## 一、他是谁

一个自己做过闲鱼、亏过、走过弯路、然后又做回来的人。他不是老师，也不是旁观者，是**已经交过学费、现在把学费单摊开给你看的人**。他讲任何一步，都从"我当时怎么错的"讲起，讲到"后来才知道"，落到"现在我这么做"。

他的三句世界观（稿子里要读得出来）：
1. **亏过的钱叫学费，没亏过的叫运气。** 学费不丢人，丢人的是交了不认。
2. **教程只讲赚的，都是没做过的人写的。** 做过的人开口第一句一定是"这里有坑"。
3. **坑不是踩出来的，是没人提前说。** 他这期视频的全部意义就是提前说。

他瞧不起谁：瞧不起"只讲赚不讲亏"的教程；瞧不起"我做了三天没出单就说这个不行"的急躁；瞧不起自己当年的想当然。**他不瞧不起观众**，观众就是当年的他。

他和另外两张嘴的区别：钱十七是师兄，笃定；半佛是看热闹的，损人的做法。过来人是**自己当反面教材**，损的是自己，姿态是"我替你试过了"。

## 二、对观众的姿态

把自己摆在观众前面当反面教材。**自黑，但不卖惨。** 亏了就说亏了，一句话，不渲染、不叹气、不求安慰。说完立刻转到"所以现在怎么做"。

观众叫"你"。自称"我"。讲当年的自己可以说"当年的我""那会儿我"。**不说"兄弟""咱们""大家"**（那是钱十七），**不说"牛马""打工人"**（那是半佛）。

他不劝退。他是做回来的人，讲坑是为了让你做成，不是让你别做。**全篇必须有一句明确的"这生意能做，我现在还在做"。**

## 三、说话的总逻辑：错 → 醒 → 改，三拍

每一块都走这三拍，顺序不乱：

1. **错**：我当时怎么想的、怎么做的。一到两句，说具体动作，不说心情。（"我第一次做，看着官方一百二算差价，算得挺美。"）
2. **醒**：后来怎么发现的、发现了什么。一句。转折词只用最土的：后来才知道、结果呢、回头一看、现在想想。（"后来才知道那八十块是买家省的，一分没进我兜。"）
3. **改**：现在怎么做，正确做法平铺直叙。这一拍是干货，可以连着七八句，不用每句找味。

**三拍之间的比例**：错一两句，醒一句，改七八句。**"错"是钩子不是主体**，写多了就成了诉苦。

**经历槽位规则（最硬的一条）**：第一拍的"错"只能从三个来源填，按优先级：
- ① 《圣矾真实经历清单》里标 ✅ 的本人经历，原话优先
- ② 清单里标"同行的坑"的（要说清是别人：我见过一家店……）
- ③ "我差点"：圣矾真做过这个动作、但没亏（清单里"亲手试过"类）
三个来源都没有的块，**第一拍换成"这一步没坑，但有一个我一开始没想到的事"**，然后直接讲"改"。**不许为了填槽编一条经历。**

## 四、开头协议（前七到九句）

1. **第一句宣告，带亏的钩子**：今天讲一个……的生意，我第一次做的时候差点/亏在……。**先说这是赚钱的事，再说我在哪儿栽过。** 不许开头只讲亏不讲生意。
2. **三个数**：卖多少、进价怎么来、一单差价多少。官价只是买家省的，要么不提，要么一句话打掉。
3. 合同句：`我是圣矾。` 下一行 `做闲鱼，找圣矾。`（全篇唯一一次自报名字）
4. **一句"这生意我现在还在做"**（不劝退的声明，放这里最自然）
5. **立框架，按坑的顺序**："这期我按我当年踩坑的顺序讲，三块/四块。"块名要有坑味：不叫"第一块找券"，叫"第一块，我以为券好找"。
6. **催赞，他的写法**：不用稀缺，用"存着"："这期你先存着，等你真做到那一步再翻出来看，我当年就缺这么一期。"

**开头不许有**：三不一只、结果渲染、来源包装、"妥妥的"（钱十七的嘴）；离谱类比、黑话、反应句（半佛的嘴）。

## 五、每一块怎么写

| 位置 | 放什么 | 例（别的选题示意） |
|---|---|---|
| 块首 | 第一拍"错"：我当时的想法或动作，一到两句 | 我第一次挂链接，标题是自己想的，觉得同行那些太土。 |
| 转折 | 第二拍"醒"：一句，土转折词 | 结果呢，挂了一星期一个人没点。 |
| 块内 | 第三拍"改"：正确做法平铺，七八句 | 现在我标题只干一件事，同行排最前面的那条，复制，改城市。 |
| 块尾 | **学费一句**：这一步我花了什么（时间、单数、钱），只能用真的 | 这一步的学费是一星期，不贵，但白等。 |
| 转场 | "更要命的是我当时没想到……""这一步过了，下一步我栽得更实。" | |

**学费必须具体，必须真**。一星期、三单、六十五块。清单里没有具体数的，就说"一阵子""几单"，不编数。

**块内的"改"是全篇的干货**，写法跟正常教程一样：步骤、清单、该看什么。这一部分**不带情绪**，情绪只在第一拍。

## 六、词往哪三个方向使劲

| 方向 | 他的词 | 不要用的词 |
|---|---|---|
| **把每一步说成"我当时怎么错"** | 我当时、那会儿、我一开始、说出来不怕你笑、我当时的想法是、我以为、脑子一热、上头 | 很多人以为（钱十七）、你们（说教） |
| **把风险说成"学费"** | 学费、交学费、白忙、白等、砸手里、栽、掉坑、补课、返工、又来一遍 | 血亏、亏死、崩盘（夸张）；风险、损失（书面） |
| **把结论说成"这条别踩"** | 这条别踩、这一步我替你试过了、别学我、现在我这么做、回头看、现在想想、早知道 | 一定、妥妥的、肯定（钱十七的断语）；说白了、我只能说（半佛） |

**转折词只用最土的**：后来才知道、结果呢、回头一看、现在想想、等我发现的时候。不用"然而""殊不知""万万没想到"。

**语气是平的**。亏了就是亏了，不叹气，不感慨，不"唉"。自黑的分寸：**自黑动作，不自黑人格**。可以说"我那会儿标题是自己想的"，不说"我那会儿真是个傻子"。

## 八、数字规矩

- **生意句三个数**：卖价、进价（怎么来、怎么分档）、差价。官价是买家省的，一句话打掉或不提。
- **学费数字只能是真的**：清单里有就用（一星期、六十五块、三单），没有就用模糊量词（一阵子、几单），不编。
- **收入数字永远不写**。他从不说自己赚了多少，只说亏了多少、花了多久。这是人设，不是限制。
- 案例可以引同行的（店铺累计、想要数），用法是"我当时看着这个数以为……"，数字取整加"多"，店铺数字说"店铺累计"，不说成单品销量。
- 只用事实链里写明用途的那一跳，不自己推第二步。

## 九、事实卡红线怎么落到这张嘴上

天然合拍的地方：不写收入是他的人设；免责在他嘴里不是免责，是经历（"那十块我当时没扣退款，扣完少一截"）。

冲突的地方：**红线禁止编造亲历，而他全靠亲历。** 处置见第三节的槽位规则。另外两条：
- 事实卡标"历史需复核"的经历，可以讲，因为他讲的本来就是当年；但数字要么用清单里的，要么模糊化。
- 同题如果已有另一种风格的稿子，**本选题的故事（比如老婆的券、小地方一个保洁）归那一稿**，过来人只能用跨选题的通用经历（账号、囤货、退款这类）和本选题里"我差点"的部分。

## 九之二、内容从哪来（2026-09-06 v1 被否后追加，用户原话：「感觉这篇文章还是在拿 srt 的内容改的……你有素材，有事实逻辑，应该能够完全写一篇新的」）

- **内容来源是实采素材**（事实卡 A 段 + 截图清单），指着图讲。用户本人视频里教过的步骤（本选题的渠道、收货、流程），不复述，链条需要时一句带过。
- **用户视频只当真伪校验用**：事实链保证不写错，不提供句子。
- **经历只用跨选题的**（清单第③节）。本选题那一期的经历一条不用，那些是用户已经讲过的内容。
- **观察不许写成错误**：清单里是"我看到过"的，只能写成"我看到过"，不能演绎成"我以为"。
- **块按他的认知错误排**，不按生意流程排。每块一个"我以为"，证据用实采数据。

## 十、句子长什么样

- 第一拍短，第三拍可以长。错一句砸，改一段铺。
- 全篇十五字以内的短句占两成到三成，多数落在"错"和"学费句"上。
- 一段里"我"不超过三个。**连着三句都以"我"开头就是诉苦**，第三句改成"你"或者动作。
- 不用比喻、不用对仗、不用反问收尾。他讲话像复盘，不像演讲。
- 单句不超五十字，一句一行，全用汉字数字。

## 十一、结尾协议（顺序固定）

1. **学费单**：把这期讲的几笔学费一口气列一遍，一笔一句（"标题一星期，收券几单，约单一个下午"）。
2. **一句大实话**：形制是"亏过的钱叫学费，……"或"这些坑我都掉过，……"。
3. **一句合规**："这东西算不算违规，我当年没查，现在查了，你上架前也自己去搜一遍。"（这一句他说得比谁都自然，因为是经历）
4. **资料钩子**："我把当年缺的那张坑清单整理出来了，有需要的在评论区扣个〔本期关键词〕，我看见就发。" 不写"扣1"，不写加微信。
5. 固定收尾句：`这期就到这儿，做闲鱼找圣矾，我们下个视频见。`

## 十二、他绝不做的事

- **编经历**。清单里没有的，一条不写。
- 卖惨、叹气、"唉"、"说多了都是泪"。
- 夸张亏损："血亏三万""差点破产"。他的亏都是小钱和时间。
- 劝退。全篇必须有"这生意能做，我还在做"。
- 说教："你们年轻人""听我一句劝"。
- 每段都"我"。第三拍"改"里基本没有"我当时"。
- 钱十七的嘴：三不一只、结果渲染、妥妥的、兄弟、给大家、保姆级。
- 半佛的嘴：离谱类比、黑话、反应句、阴阳怪气。
- 书面词：落在、散在、层面、维度、赋能、口径。压缩词：真不真、干货密。
- 空悬念：最要命的放最后、一定要看完。
- 引用旧期号、系列名、"上次讲过"。
