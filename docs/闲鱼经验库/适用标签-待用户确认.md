# 闲鱼经验库 · 适用标签 · 待你确认的条目

经验库一共 483 条，每条都贴了"适用"标签：这条经验是虚拟、实物都能用（通用），只适合卖实物（实物专用），还是只适合卖虚拟（虚拟专用）。以后写稿时，程序按本期选题的类别自动过滤，写手只看得到对得上的经验。

下面这 22 条是我拿不准的，请你在最后一列填你的选择，可以写"同意"，或者直接写"通用 / 实物专用 / 虚拟专用"。没填的先按"我的判断"执行。

"我的判断"括号里写的是这条适用于哪几类虚拟商品：资料（网盘发链接）、代办服务（替人办事、下单）、软件账号（会员、账号、激活）。

## 没有实物字眼、但判成实物专用的例子

这些经验里没有"退货、快递、发货、物流"这类词，是读懂内容后判成只适合实物的，说明不是只靠关键词筛的。

**选品**

- X-选品-009：冷门品、商用品的买家是拿去干活赚钱的，知道自己要什么，问完就下单，不磨叽
  - 为什么算实物：讲的是买设备去干活的商用品买家
- X-选品-053：同图不同价的三个来源是跟款、仿款工厂、同源分销：一张好主图会被无数商家共用，一款火了工厂立刻打板，同一个工厂的货批发给几十个卖家
  - 为什么算实物：跟款、仿款工厂、同源分销，实物供应链
- X-选品-082：跟节气选品、抄销量好的、挑没有暖气的地区发布，本质是吃季节差和地域差
  - 为什么算实物：吃季节差、地域差（没暖气的地区），是实物季节品

**售后、交付、客服**

- X-交付-014：有些行业厂家默认被动处理偏差，你不问他就不说，卖家得主动把参数问清
  - 为什么算实物：厂家不主动说参数偏差，实物生产
- X-售后-007：上游的规格标注本身可能有坑，没提前跟客户讲清就成了对方仅退款的理由
  - 为什么算实物：上游规格标注有坑，实物参数
- X-客服-033：批发客户很忙，开口第一句就把数量、场景、优惠一次抛出去，规格用表格发过去
  - 为什么算实物：批发客户开口报数量场景优惠

**运营心态、其他**

- X-心态-061：压手里的货要么狠心低价清掉腾时间，要么放着别管，最忌天天擦亮降价耗着
  - 为什么算实物：压手里的货清掉还是放着，只有实物有库存
- X-心态-044：批发的散客比小件少得多，一天回几个客户就能收工，省出来的时间用来开发新品和简化流程
  - 为什么算实物：批发散客少一天回几个就收工，是实物批发节奏
- X-其他-002：平台定价看的是你急不急，越急价格越高，越等价格越低
  - 为什么算实物：拼多多拿货价看你急不急
