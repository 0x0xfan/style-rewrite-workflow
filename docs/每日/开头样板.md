# 长稿开头样板（2026-09-27 起，唯一标准）

> 用户 2026-09-27 定。以前的开头规矩（开头顺序、五到九句、"前三句五问"、开头角度清单、说明书第三节开头协议）全部作废，以这份为准。
> 以后用户认可的新开头，往第五节末尾追加，写清出自哪一期、哪天认可的。

## 一、一句话标准

**看完开头就清楚这期讲什么生意、钱从哪来。开头突出结果，用数据或结果留人。**

- **产品稿**：第一句就点名「闲鱼上的一个赚钱生意 + 能赚多少 / 一个硬数据」，接一句「今天给你拆解拆解 / 今天给你讲清楚」，简单明了；怎么做的全放正文。角度是"分享给你一个能赚钱、能当副业的东西"——不是揭秘"他"的生意，也不是先铺生活场景。
- **经验稿**：站在已经在做闲鱼、遇到问题的人的角度，开头点出问题 + 结果（怎么解决），同样简单直接。
- 开头之后接固定两行：`我是圣矾。` 下一行 `学闲鱼，找圣矾。`
- 小白要问的"闲鱼是什么、怎么交货、难不难"放到这两行之后讲，不塞进开头。

## 二、公式：话题 + Hook + 可信度

来自 `.claude/skills/dbs-hook/SKILL.md`。

- **话题**：讲什么生意（闲鱼上的淘客、驾考资料、电影票代买……）。
- **Hook**：为什么要听——一个结果或硬数据（一个月能搞到多少、已售多少件、多少人想要）。
- **可信度**：为什么信——闲鱼上看得到的真数据、用户给的收益数、"我去闲鱼搜了一下"。

## 三、三法怎么用（每篇先各写一个候选，挑最好的用）

| 法 | 怎么用 | 适合什么时候 |
|---|---|---|
| 方法一 素材提取 | 从手里现成的真素材里挑最有冲击力的一个数或一个结果（截图里的已售件数、上架品数、想要人数；选题卡或字幕里的收益数），直接摆在第一句 | 截图或字幕里有硬数据，最稳，优先用 |
| 方法二 补素材 | 素材不够冲，就补一个"怎么发现的"外壳（听说有家公司、我比价买东西时顺手发现），把用户给的收益数装进去 | 有用户给的收益数，但现成画面不够冲 |
| 方法三 留悬念 | 把结论改成问题："他靠的是什么？""为什么有人一个月能搞到【X】？"，不直接给答案，答案放正文 | 生意本身反常识（一件不卖也赚钱、挂低价也赚钱） |

- 每篇写稿前先列 3 个候选开头（三法各一），写进 `说明.md`，挑最好的一个进稿。
- 同一选题写多篇：每篇用不同的法、不同的素材，不共享开头结构。

## 四、【X】（收益数）怎么处理

- 选题卡"怎么赚钱"或字幕里有用户亲口说的收益数 → 用它，照原话口径（"大概""一个月流水"照写）。
- 没有收益数 → 只能选不需要收益数的写法：方法一用截图里的真数据（已售、上架、想要），或方法三的悬念不带数；**也可以在交核心卡时问用户要数**。
- **绝不自己编数。** "听说有人 / 有家公司一个月能搞到【X】"这种说法，【X】也必须来自用户，"听说"不是编数的理由。
- 样板里的【X】是占位，写稿时要么换成用户给的数，要么换写法，不许把【X】或"XXX"留在稿里。

## 五、用户认可的样板（只学结构，不抄句子）

### 5.1 第 47 期「闲鱼淘客」，dbs-hook 三法产出（2026-09-27，10 条认可 9 条）

方法一 素材提取：
1. 闲鱼上有家店，挂了三百多个大牌，卖出去两千多件，可他真正赚钱的地方不在闲鱼，今天我来给你拆解拆解。
2. 官方卖三千多的椅子，闲鱼上有人只挂一千多，他不靠卖椅子赚钱，靠的是一个淘客生意，今天我给你讲清楚。
3. 淘客这个生意做了快二十年，现在有人把它搬到了闲鱼上，一个月能搞到【X】，今天我来给你拆解拆解。
4. 在闲鱼上挂低价大牌，一件货都不卖，一个月也能搞到【X】，这是闲鱼上一个很多人不知道的赚钱生意。

方法二 补素材：

6. 听说有家公司就靠在闲鱼上做淘客，一个月能搞到【X】，养活了整个公司，今天我来给你拆解拆解。
7. 我比价买一把椅子，顺手发现了闲鱼上一个一个月能搞到【X】的淘客生意，今天我给你讲讲它是怎么做的。

方法三 留悬念：

8. 闲鱼上有人把三千多的大牌椅子挂一千多，一把都不卖，一个月还能搞到【X】，他靠的是什么？
9. 同样是在闲鱼上挂东西，别人赚差价，有人一件货都不卖，一个月搞到【X】，差别就在一个淘客的路子上。
10. 不囤货、不压钱，只在闲鱼上挂几个低价大牌，为什么有人一个月能搞到【X】？

### 5.3 更早一轮认可的（第 47 期自由实验开头 8、9，开头要把生意交代清楚的例子）

- 已售两千多件，上架三百个品，全是大牌。这家闲鱼店，看着像在卖货。其实每个来问价的人，都被他带进了自己的群。群里天天发好物，有人下一单，他就拿一单佣金。
- 大牌官方不让在闲鱼上卖全新的，他怎么敢挂这么低？挂这么低，他又靠什么赚钱？答案就一句：他卖的根本不是货。他要的是人。

## 六、被否的（不许这么写）

第 47 期第 5 条：

> 我自己有个业务就在用这个思路引流，一个月能给我带来【X】，今天我把这个闲鱼淘客的路子分享给你。

错在哪：把用户说成在做淘客。用户的原话是"有业务在用这个思路做引流，但不是做淘客"。**用户说"我有业务在用 X 思路"时，只能照原话说（"我自己也有业务在用这个思路引流"），不能推成"我也在做这个项目"，也不能给这个业务安一个收益数。**

2026-09-27 自由实验里其余 8 个开头也被否：看完开头完全不清楚后面要讲什么生意。
