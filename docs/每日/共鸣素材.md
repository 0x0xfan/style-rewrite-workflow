## 拿不准的地方

1. G10（怕资料发出去对方反悔）：同行文章里讲"仅退款"的大多是实物场景，虚拟版是按常识改写的，用之前最好问一下用户虚拟品实际碰到的情况。
2. G11 的示范句只说了"自己整理的、帮人动手操作的服务"。有些期里卖的是网上公开免费拿到的东西，这类能不能说"心里踏实"，按具体选题判断。
3. G41–G43 用"很多人"开头；如果写成"很多人加我都说……"就是圣矾本人的经历，来源是他自己视频里说过的，可以这么写，但别扩写出新细节。
4. 示范句里"第一次成交""一大笔钱"这类说法算不算"数字"，我按不算处理（没报具体量）。
