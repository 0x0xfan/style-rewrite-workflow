# 账号选题台账

2026-09-29 建（DECISIONS 2026-09-29「皮肤 = 账号」「每日出稿新节奏」）。排「今日选题表」前先读这份（`.claude/skills/daily-plan/SKILL.md`）。

**选题硬规矩只有两条：**
1. **同一账号不重复**：某个账号的表里出现过的选题，这个账号以后不再写（不管是存稿还是已发）。
2. **同一天各篇选题不同**：一天 16 篇（13 个账号 + 3 篇真人出镜）选题两两不同。

横版和竖版是不同账号（同一套皮肤的横版账号和竖版账号各记各的）。不同账号之间撞题不算违规，但能错开就错开。

**追加规矩（和 `docs/每日/故事登记.md` 一样）：**
- 写稿 agent 交付后，在对应账号那一节的表格**最后追加一行**，只追加，不改、不删旧行。
- 走 `daily-plan` 一天分批并行写时，worker 不直接写这份文件（几个 worker 同时追加会互相覆盖），把要追加的行写在报告里，由主会话汇总时按顺序追加；单独跑一个写稿技能时由写稿 agent 自己追加。
- 唯一允许改旧行的是「状态」一格从「存稿」改成「已发」，这个由主会话或用户改，写稿 agent 不改。
- 选题写法和 NAS 文件夹名一致（`待审文案\<选题>\` 的 `<选题>`），方便对照；topicSlug 填视频项目素材库 `public\ips\xianyu-fanshen\assets\<slug>\` 的 slug，素材库还没有这个品就写「无」；真人出镜那节 topicSlug 可以写「无」。
- 稿件文件名只写文件名，不写整条路径（都在 `Z:\素材生成库\ai文案\待审文案\<选题>\` 下）。
