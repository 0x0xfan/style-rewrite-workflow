## 讲什么 / 核心诊断逻辑
破解很多新手在闲鱼发了宝贝后最头疼的问题：“后台数据显示每天有几百上千曝光，但点击率低得可怜，根本没人点进来看，到底该调主图还是降价格？”

## 诊断排查三步法
1. 第一步看点击率（点击量除以曝光量）：
   - 如果点击率低于百分之三，说明在搜索瀑布流里买家看了一眼直接滑过去了，问题百分之九十出在【首图】和【标题前十个字】；
   - 解决办法：去闲鱼大盘搜同类爆款，看同行排名前三的主图用了什么底色、大字痛点文案和实物质感，重新换一张高对比度、痛点突出的首图；
2. 第二步看定价与同行锚点：
   - 如果同行标价九块九带自动秒发，你标了二十九块九还不带说明，曝光虽多但买家比价后直接绕道；
   - 解决办法：采用“梯度SKU法定价”——基础版设两块八拉低起步门槛提高点击，完整版设九块九作为主销利润款；
3. 第三步看点击后的停留与咨询转化：
   - 如果点击进来了但没人点“我想要”，问题在详情页内页和信任感，需要补齐资料截图、买家好评和交付方式说明。

## 避坑说明
- 绝不要一没流量就盲目降价到一毛钱亏本甩卖，也不要频繁在几分钟内反复修改标题主图导致系统重新审核限流。改动后观察二十四到四十八小时数据再做调整。
