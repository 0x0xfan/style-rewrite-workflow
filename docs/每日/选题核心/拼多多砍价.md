卖什么：帮人在拼多多上"助力砍一刀"。买家拍下的是一定次数的助力，你替他去把次数补上，赚的是闲鱼卖价和下单价之间的差价。

这门生意让外行最意外的一点：居然有人花一块钱，买别人帮他在拼多多上点一下。（2026-10-02 用户定：原"卖家手里没货"当卖点删掉，服务类本来就没货，说了是废话。）

钱从哪来：赚差价。字幕原话：「这个项目它的盈利逻距就是赚差价 / 咸鱼上面卖的价格 / 是要比渠道价格要高出来很多的 / 所以 / 能够有70%左右的利润率」（00:02:23–00:02:33）；「它的价格是一元15次 / …… / 真人7.8 80次送人工五次 / 新用户9.9送人工五次 / 这些数据它是卖价 / 实际上的成本 / 大概是在30%左右 / 最低成本可能只有百分之十」（00:01:52–00:02:14）。

主推做法：卖的是"次数"，不是"一定砍成"——这门生意差价不小，但砍不成是常事，新手最容易栽在"答应了一定砍成"上；先把只保证次数说清楚，砍不成就退，才做得下去。
交付怎么做：「谈完了之后再去渠道下单 / 而且大概率还砍不成功 / 最后还会有一些售后需要处理 / 因为各个渠道 / 他能够砍下来的只是次数 / 我们没办法给用户保证 / 100%给他砍掉」（原片 00:03:01–00:03:13）；「遇到这种不讲理的客户 / 我们一般就是退钱」（原片 00:03:26–00:03:29）。渠道在稿里只说"你去下单的地方"。

稿件类型：产品——讲拼多多助力这一个具体生意，对还没做过闲鱼的人讲。

观众：不懂闲鱼、想赚钱的人
