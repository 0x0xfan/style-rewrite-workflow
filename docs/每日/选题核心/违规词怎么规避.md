卖什么：—（经验题，不讲具体产品；讲的是在闲鱼写标题、详情、回消息时，哪些说法会被判违规，怎么用合规的说法把同一件事讲清楚）
这门生意让外行最意外的一点：违规词不光是脏话——"加我微信"、别人的品牌名、"破解"这类字眼都会被判，连看着没毛病的普通词也可能因为以前有违规的品带过它而被标成风险；而且词每天在变，背一张表背不完。真正的问题常常不在词上，在卖的东西上：品本身侵权，换什么说法都救不了。
钱从哪来：没有收益数。本题不讲钱从哪来，稿里不写任何收益、出单数。
主推做法：违规词分两种处理——
  - 说法有问题、事情本身没问题的，换成合规的说法把同一件事讲清楚：例如往站外带人的话（"加我微信""1对1指导"）改成"拍下后有问题直接在闲鱼聊天里问"，交易和沟通全程留在平台里（X-合规-026、X-合规-024）。
  - 事情本身有问题的（没授权的破解版、盗版资料、蹭别人品牌），不是换词，是换品（X-合规-027、X-合规-042「类目本身在打击范围内，运营技巧救不了」）。
  - 上架前把标题和详情过一遍违规词，拿不准的品宁可不上（X-合规-043；圣矾经历清单 #109「出现明确违规的词，那这种品呢就不要上了」）。
  - 别照搬同行标题：带违规词一样压曝光（X-上架-021）。
  - 违禁词是动态变化的，任何词表、检测都不是万能的，最后以闲鱼平台规则为准（经历清单 #104；X-合规-045 剩下的风险来自平台政策临时调整）。
