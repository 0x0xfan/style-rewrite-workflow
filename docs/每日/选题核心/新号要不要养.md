卖什么：—（经验题，不讲具体产品；讲的是在闲鱼做虚拟之前，新注册的号要不要先"养"、怎么养）
钱从哪来：没有收益数。本题不讲钱从哪来，稿里不写任何收益、出单数、"养好就出单"。
主推做法：养号是让新号的操作像一个真人在用闲鱼，不是刷数据、刷任务。做法落到圣矾自己总结的三样（E40《虚拟全套玩法》原话：「这个养号我们分为 3 点。第一是日常浏览……后面两个是圣矾在做咸鱼的时候自己总结出来的。首先就是买家行为……其次就是卖家行为。」，经历清单 #93）：
  - 日常浏览：正常逛，看到感兴趣的点进去停一会儿，不一路快划（X-养号-002）。
  - 买家行为：真买点自己用得上的便宜东西（资料、软件、日用品），或做闲鱼币任务、签到（E40 原话；X-养号-002）。
  - 卖家行为：站在自己想卖的品的角度去搜同行、看同行链接，点赞收藏记下来——养号的同时顺手选品（E40 原话；X-养号-002「顺手把要测的品收藏起来」）。
  - 周期：机械刷三五天只是自己心里踏实；真要认真养，一个月左右才有点意义；没时间养也可以边做边养，上架、改价、回消息本身就是在用（X-养号-003，原文同篇「直接做，本身也是一种活跃」；X-养号-009「白号每天上新下架也能追上去」）。
  - 养号阶段有人咨询照样及时回，回复率从一开始别弄差（X-养号-005）。
