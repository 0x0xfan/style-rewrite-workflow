卖什么：一门做淘客（返利）的副业路子——在闲鱼上挂比官方便宜很多的大牌商品当钩子，把来问价的人引到自己的私域，在私域里发返利链接，别人从你的链接买东西，你拿佣金。卖家手里没有货，也不是真按闲鱼标价卖；闲鱼只是流量入口，钱是在私域里赚的。
钱从哪来：「就相当于返利 / 你从我的链接买东西 / 我就能拿到佣金 / 我赚的就是这个佣金」（原片 00:00:22–00:00:27）。没有收益数——一单佣金多少、一个月多少字幕里都没有；不讲圣矾自己赚多少，只讲模式和钱从哪来，不补收益数，也不拿商品价（官方三千多、闲鱼一千多）顶收益（用户确认 0928 第 1 条）。
主推做法：把闲鱼当流量入口做截流——低价只是钩子，目的不是卖货，是把想买东西、到处比价的人截到你自己的私域去做淘客赚佣金。让小白听完能说清"钱从哪来"：挂低价钩子 → 有人来问 → 引到私域 → 发返利链接 → 他下单你拿佣金。交付：「淘客新路子 / 把闲鱼当流量入口做截流」（原片 00:00:05–00:00:06）；「就相当于返利 / 你从我的链接买东西 / 我就能拿到佣金 / 我赚的就是这个佣金」（原片 00:00:22–00:00:27）；「那以往淘客的流量渠道 / 都是各个自媒体平台 / 大电商平台的评论区 / 今天呢 / 圣矾分享的是闲鱼」（原片 00:00:35–00:00:43）；「他这里的意思是咨询他拿补贴」（原片 00:01:09）；「那么他到底真的能便宜卖给我吗 / 答案就是不能 / 但是他这种方式可以说在闲鱼上面做 / 引流 / 引流到他的私域去做淘客 / 他的成本是非常低的」（原片 00:01:24–00:01:35）；「你同一个商品可以去发很多个不同的链接 / 每个链接可以涵盖各种各样的关键词」（原片 00:03:56–00:04:00，只当"怎么让更多人看到钩子"的一个环节）。
稿件类型：产品——讲"闲鱼挂低价钩子引到私域做淘客"这一个具体路子，站在"给你分享一个能赚钱、能当副业的东西"的角度，对还没做过闲鱼的小白讲。
观众：不懂闲鱼、想赚钱的人
