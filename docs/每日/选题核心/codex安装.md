卖什么：帮不会装的人把 Codex（做 ChatGPT 那家公司出的写代码的 AI 软件）装到他自己电脑上——主力是远程连上去帮他装好；变体是发一份打包好的安装包（安装包、安装脚本、安装教程），以及整理好的 Codex 细分行业教程。
这门生意让外行最意外的一点：一个官方免费公开、安装包都已经打包好的软件，有几千人愿意花九块九请别人帮忙装——因为很多人连它从哪下载都找不到。

不能说的：用户没给（"—"）。写稿时按常识守：远程连别人电脑只装说好的东西；不卖破解、不卖账号额度、不碰 API 中转代充（百度结果里同屏有这类灰色生意，不提）。
不能讲偏的方向：
  - 不写成"要会写代码才能接"；也不写成"装完就不用管"之外的技术教学（不教命令、不教参数）。
  - 不说"官网找不到下载按钮"当铁事实（原片帧 demand/06 官方页其实有"下载"一项，说"很多人找不到从哪下"即可）。
  - 不提旧期（27 季、第 8 季、龙虾、赫尔墨斯）。
  - 不说零成本、躺赚、单品利润上万（片头字幕"单品利润上万"不进稿）；七千多只当推算流水说一次。
  - 模型对接、API 的后续收入只能照原话点一句"还有后续的活"，不给数、不教 API 中转。
  - 行业教程是"把 GitHub 上公开的资料整理到一起"，不说是自己原创。
