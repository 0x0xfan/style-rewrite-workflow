【2026-09-29 拆分说明】原来一张核心卡的十一行，拆成了两部分：
- 卖什么 / 本期主推 / 交付怎么做 / 虚拟子类 / 稿件类型 / 观众 / 不能讲偏的方向 → 现在是「选题核心」，一个选题一份，第一次写这个选题时确认一次，长期有效，模板见 `docs/每日/选题核心模板.txt`。
- 开头 / 本篇讲法 / 本期要讲透的经验 / 彩蛋 → 现在是「每篇写法」，每篇一份，不设用户确认门，写稿 agent 自己按"同题不共享"规矩定，直接写进该篇 `说明.md`（见下面的字段说明），不用单独出卡文件。

本文件只保留「每篇写法」四行的字段说明和填好的例子，供写进 `说明.md` 时参照。

---
每篇写法（四行，写进该篇 `说明.md` 开头，不设门；同一选题写多篇，每篇这四行都不一样）：

开头：
本篇讲法：
本期要讲透的经验：
彩蛋：

---
填写说明
- 开头：本篇开头用哪一法（素材提取 / 补素材 / 留悬念，dbs-hook 三法）+ 用什么结果或数据（写出处：截图哪张 / 选题卡或字幕原话）。标准和样板见 `docs/每日/开头样板.md`：看完开头就清楚讲什么生意、钱从哪来。收益数只能用选题核心「钱从哪来」「用户给的数」两行里有的；没有就选不需要收益数的写法，或者停下问用户要，绝不自己编。同题各篇用不同的法、不同的素材。
- 本篇讲法：六选一，后面半句写这篇怎么走——分点讲（两到四点）/ 跟着一单走 / 问答式 / 先算账再拆 / 只讲透一件事 / 先说新手误区再讲正确做法。
- 本期要讲透的经验：三到四条，写经验库编号加一句话（编号从 `pick-experience` 候选清单里挑）。
- 彩蛋：从固定五个彩蛋（入门版 / 自动发货工具 / 违规词 / 爆品表 / 官方知识库）里选一个跟本期最搭的，写选哪个 + 一句理由。

---
填好的例子（电影票代买，2026-09-26 试跑用的那一期；选题核心部分见 `docs/每日/选题核心模板.txt` 的例子）

开头：方法一 素材提取。第一句用"电影票代买，全程无人值守"这个结果，加上选题核心「钱从哪来」/「用户给的数」里有的数；没有收益数，就改用闲鱼截图里的想要人数，或停下问用户要。
本篇讲法：跟着一单走——从买家搜到你，到看说明、发截图、系统报价出票，到他拿取票码去影院，一路讲下来，不分点。
本期要讲透的经验：X-上架-018 标题按词匹配，片名要写进标题；X-上架-079 说明写清楚，买家自己就能走完流程，系统才接得住；X-售后-015 虚拟品没有物流凭证，退款时只有聊天记录能拿出来；X-合规-004 说明里别写「秒发」「自动发货」，会被当成商家（全自动这期必须留的坑）。
彩蛋：违规词。这期讲全自动、说明里不能写"秒发""自动发货"，本来就在讲违规风险，跟"一份五千五百多个违规词的词库，还有侵权词检测工具"接得上。
