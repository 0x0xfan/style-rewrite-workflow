填写说明（每篇长稿一张；写完先交用户确认，用户点头才能写稿）
- 卖什么：一句话，买家花钱买到的是什么。
- 本期主推：这期最想让观众记住的那个卖点，只写一个（例：全自动，不用人盯）。
- 交付怎么做：抄原话，不改写。每日选题抄选题卡「怎么做」那一行；改用户原片的，抄原片字幕原话，后面括号写出处（第几句或时间）。
- 虚拟子类：三选一——资料类（网盘发链接、发文件）/ 代办服务类（替人办事、替人下单）/ 软件账号类（会员、账号、激活码、卡密）。拿不准就写两个里你倾向的那个，再加一句为什么，交用户定。
- 稿件类型：讲具体产品写"产品"，讲闲鱼通用经验写"经验"（2026-09-27 定）。
- 观众：产品稿写"不懂闲鱼、想赚钱的人"；经验稿写"已经在做闲鱼的人"。
- 开头：本篇开头用哪一法（素材提取 / 补素材 / 留悬念，dbs-hook 三法）+ 用什么结果或数据（写出处：截图哪张 / 选题卡或字幕原话）。标准和样板见 docs/每日/开头样板.md：看完开头就清楚讲什么生意、钱从哪来。收益数只能用选题卡或字幕里用户给的；没有就选不需要收益数的写法，或者交卡时问用户要，绝不自己编。同题各篇用不同的法、不同的素材。
- 本篇讲法：六选一，后面半句写这篇怎么走——分点讲（两到四点）/ 跟着一单走 / 问答式 / 先算账再拆 / 只讲透一件事 / 先说新手误区再讲正确做法。
- 本期要讲透的经验：三到四条，写经验库编号加一句话（编号从 pick-experience 候选清单里挑）。
- 彩蛋：从固定五个彩蛋（入门版 / 自动发货工具 / 违规词 / 爆品表 / 官方知识库）里选一个跟本期最搭的，写选哪个 + 一句理由。
- 不能讲偏的方向：写具体做法，不写空话。跟本期主推相反的做法、选题卡「不能说的」、原片没有而你担心写手会自己补的动作，都写在这里。
同一选题写多篇：每篇一张卡，"开头""本篇讲法"和"本期要讲透的经验"每篇都不一样，其他几行可以相同。

填好的例子（电影票代买，2026-09-26 试跑用的那一期）

卖什么：电影票代买。买家拿到的是一个取票码，自己去影院取票，卖家手里一张票都没有。
本期主推：全自动，对接好配套系统以后，认截图、报价、下单、发取票码都不用人盯，卖家只管把店铺和链接做好。
交付怎么做：「买家把电影院座次表截图发给客服，告诉他城市，AI 自动识别影院和座位，自动下单，全程无人值守」（原片 00:25–00:37）；「把这个系统对接好，后面你只需要去优化你的店铺就好了」（原片 04:00–04:04）。
虚拟子类：代办服务类。
稿件类型：产品
观众：不懂闲鱼、想赚钱的人
开头：方法一 素材提取。第一句用"电影票代买，全程无人值守"这个结果，加上选题卡「怎么赚钱」里用户给的数；卡上没有收益数，就改用闲鱼截图里的想要人数，或交卡时问用户要。
本篇讲法：跟着一单走——从买家搜到你，到看说明、发截图、系统报价出票，到他拿取票码去影院，一路讲下来，不分点。
本期要讲透的经验：X-上架-018 标题按词匹配，片名要写进标题；X-上架-079 说明写清楚，买家自己就能走完流程，系统才接得住；X-售后-015 虚拟品没有物流凭证，退款时只有聊天记录能拿出来；X-合规-004 说明里别写「秒发」「自动发货」，会被当成商家（全自动这期必须留的坑）。
彩蛋：违规词。这期讲全自动、说明里不能写"秒发""自动发货"，本来就在讲违规风险，跟"一份五千五百多个违规词的词库，还有侵权词检测工具"接得上。
不能讲偏的方向：不讲卖家自己去渠道问价、自己出票、自己一条条接待；不讲"手动你也要会"；人工只能当兜底说一句；不讲躺平、必卖爆。
