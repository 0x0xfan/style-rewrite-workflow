## 三、钱十七线：偏移清单

按"说明书的锅"、"写手的锅"、"实验设计的锅"三类分开记。

### 3.1 说明书没写到位（要改说明书）

1. **生意机制没点透。** 定稿前四句：倒券 → 低价收进来挂闲鱼 → 赚差价 → 一单十块。盲写稿说"赚的是不想掏一百二的人的钱"，全篇没有"一单十块"，也没说"收进来再挂出去"这个动作。说明书写了"卖什么、赚谁的钱、一单多少"，写手按字面答了"赚谁的钱"，"一单多少"因为事实卡把"一单约十块"的授权行放在 🚫 小节下面，写手没敢用。**改法**：说明书开头协议直接写"第二到四句必须说出：收什么、挂哪儿、差价一单多少"，并注明事实卡里授权口径的位置。
2. **案例拿来警示了，没拿来炫。** 定稿拿专营店"累计九千八百多件，按七千单算一单十块七万块，这钱人家早装兜里了"。盲写稿专营店一字没提，只用 Top1 当反面教材；"乘到大整数下断语"被倒过来用成"一年一千二百个账号，妥妥的凑不出来"。写手报告说"能乘的数全被封了"。**改法**：说明书第八节明写唯一合法的乘法：同行店铺累计件数往下折 × 单利，并给出这一句的形制；第九节把"炫"改成硬要求：正文里至少一家店是拿来炫的，反面教材不许是唯一案例。
3. **短句砸没了。** 定稿四分之一是十五字以内的断语（"这个需求是真的。""妥妥的，不用再问了。""进去就是送人头。""单子就该进来了。"）。盲写稿只有 5%，句长几乎全在二十四字上下，节奏是平的。说明书第十三节把篇幅花在"三成长句三十八到五十字"上（那是语料的数，五分钟定稿也做不到），短句砸只提了半句。**改法**：第十三节改成"断语单独成行，五到十二字，全篇四分之一"，删掉三成长句那条。
4. **江湖词的下限没给。** 定稿有：妥妥的、别做梦了、进去就是送人头、这就是信息差、千万别碰、人家就是专门吃这碗饭的、这钱人家早就装进兜里了。盲写稿只有"妥妥的""排个雷"。说明书写"每段最多一个"，写手把下限当成了零。**改法**：给下限（全篇五到八处）并指定槽位：断语后、坑处、案例炫完、块尾收口。
5. **密度和"块内平铺"被写手读成了冲突。** 写手说"六十次/千字和平铺是死结"。但定稿 67 次/千字，块内照样平铺，密度来自"就可以了""直接""这里给大家总结了""照着做""方法很简单"这些最土的连接词。**改法**：第二节加一句"块内不加抬价，但连接词、口头虚词照用，密度主要靠它们"。
6. **谨慎话太多。** 盲写稿有六句口径澄清和免责（想要不等于卖出 / 覆盖城市口径很乱不给具体数 / 这条是早前截的你自己进去看 / 不给群名不替你找群 / 七千零二十件是店铺口径 / 想要数是累加的别当销量）。定稿只有两句。写手把事实卡的"不许写错"理解成了"要在口播里解释清楚"。**这是伤钱十七最重的一条**，因为他的人设就是笃定。**改法**：说明书第十七节加"事实卡的红线是不许写错，不是要写免责；口径澄清放分镜备注不进口播，全篇免责一句"。
7. **块的划分跟着动作走。** 定稿三块是"券去哪找 / 怎么挂 / 怎么交付"，全是动作；盲写稿四块是"需求真不真 / 券从哪来 / 怎么交货 / 哪里会赔钱"，把开头证据升成了一块，把"怎么挂"（同行标题直接复制、详情页三件套、价格带）整块删了，而"怎么挂"恰恰是"能抄的赶紧抄"这条世界观落地的地方。**改法**：第三节加"块按动作分（找货 → 上架 → 交付），需求验证是开头证据不是块"。
8. **数字取整。** 定稿说"九千八百多件""四千多人想要"，盲写稿说"两万八千八百九十三个人""七千零二十件"。说明书第六节只说"念出声"，没说取整加"多"。**改法**：补一句。
9. **说明书里的目标数与定稿对不上的一处**：第十三节"问句每千字三到四个"来自语料，定稿只有 0.7。盲写稿写了 2.7，反而更像语料、不像定稿。要不要保留，用户定。

### 3.2 说明书写了、写手没照做（说明书没问题，是执行问题）

- 第十三节点名"需求真不真"是压缩词反例，盲写稿用了三次（第 7、11、13 句）。
- "一条链子你已经走完了"是自造比喻，第十三节禁了。
- 结果渲染写成"你今晚就能自己验一遍这需求真不真"，说明书要的是"今天就能挂上第一条"这种动作承诺，写手把整期定位成了"验证需求"而不是"教你做"。

这三条说明：**说明书写到了不等于写手会做到**，以后每份说明书都要配一道"写完对反面清单逐条勾"的硬步骤，写手自己勾的那份可信度不够（写手自查报告里这三条全打了勾）。

### 3.3 实验设计造成的（不算说明书的锅）

- 事实卡 3C 小节标题是 🚫，但用户授权的"一单约十块"口径也放在这一节，写手不敢用。事实卡排版问题，建议把授权行挪到 3A。
- 说明书要求来源包装用圣矾真实代价，事实卡里的亲历只有四条，写手全用了，导致半佛写手无料可用。

## 四、半佛线：偏移清单

**总体判断：半佛说明书传递得比钱十七好得多。** 盲写稿的开头、三块、结尾骨架和定稿几乎一致，拐弯十五个（定稿口径也是十二到十五），阴阳对象全是做法，老师腔零命中。几句是定稿没有的好句："听着像个水龙头，实际上是个滴管""注意，是买。""一个刚学会走路的业务，你指望它敞开了发券，你是不是对它有什么误解"。

### 4.1 说明书没写到位

1. **反应句同一个模子用了三次**："就，有点荒诞""就，很赛博""就，挺魔幻的"。定稿只用一次。说明书第六节列了反应句，没说"同一句式全篇一次"。**改法**：反应句四种以上轮换，同一形制不重复。
2. **句子太碎。** 96 句对定稿 74 句，短句占比 0.57 对 0.34。说明书第六节"短段为主，一段一到三句"是他公众号的排版习惯，搬到口播上就碎了。**改法**：第十节加"口播里长短交替，一句长句铺完再砸，短句不超过一半"。
3. **收券这一块变薄了。** 定稿有"收，收别人手里闲着的"和北京价带的具体算例；盲写稿只有"可这一步没有公开入口，我也不给你编一个"。原因有一半是禁用清单锁了线报群和收价数字（见 4.3），另一半是说明书第十节没要求"最难的那块要给具体机制"。
4. **密度口径没定**。写手按全表数是 43，只数实义黑话是 27，机器按词表数是 34。三个数三个结论。**改法**：说明书写明"按 `ips/半佛/corpus/phrasebook.json` 贪心匹配口径，目标四十"，或者干脆改成按拐弯数验收。
5. **"每个拐弯一句之内完成"跟三连排比、设问自答天生冲突**，写手自己定了"结构强制的收口句不计"。**改法**：写明这两招按簇计，其余按句计；结尾固定件不计入拐弯数。
6. **第一人称吃亏故事没有兜底方案**。写手靠任务说明补的口子（换成自己查规则的过程）处理得不错，应该写进说明书。

### 4.2 说明书泄漏（我的问题）

第 10.4 节把定稿结尾的写法复述得太贴，盲写稿结尾四句和定稿几乎逐字重合。下次写说明书，本选题定稿的句子一个字都不能进说明书，例句只从语料或别的选题取。

### 4.3 实验设计造成的

禁用清单把"全年一次""线报群""六十三收通州"锁给了钱十七盲写稿，半佛写手只能写成"规则卡上写着兑换次数限制，你点进去看一眼就死心了"，论点在、证据弱了一档。这是同题两稿不共享证据的规则和"两稿都要写最难的那块"之间的固有矛盾，不是说明书能解的；以后同题两稿应该先分证据再派工。

## 五、这次实验对"自造人设"的四条结论

1. **说明书能把人设传过去，但传得好坏跟人设的类型有关。** 半佛的味在"招式 + 位置"，说明书按招式写，写手照做就有七八成。钱十七的味在"词密度 + 笃定的腔 + 该炫的地方炫"，说明书写了要求，写手仍然写得比他谨慎、平、圆。**笃定型人设最容易被写手的谨慎抵消**，说明书要把"不许谨慎"写成硬规则，而且要给下限（多少处断语、多少处江湖词、至少一家店拿来炫），不能只给上限。
2. **词要按位置给，不能只给清单。** 两个写手都拿着词表，密度都掉了三到四成。清单告诉写手"有这些词"，不告诉他"这句该甩哪个"。新人设的词表从第一天就按开头 / 块首 / 块内 / 坑处 / 块尾 / 钩子分格。
3. **说明书写到了不等于写手做到了。** 三条明写的反面清单条目被写手违反，写手自查还全勾了通过。以后说明书配一道独立的机器或第二人核对，写手自查只作参考。
4. **事实卡的红线会反向塑造人设。** 同一份事实卡，把钱十七写手变得畏首畏尾，对半佛没影响（他本来就是怀疑者）。自造人设时要给每个人设配一条"事实卡红线怎么落到这张嘴上"的翻译规则，比如钱十七是"红线只管不写错，口播里不解释"，半佛是"红线可以直接当段子讲"。
