# 信任配方 · 保留清单（写稿硬规则）

> 这份清单从 `docs/用户文案模式研究.md`（12 期字幕通读提炼的"八个信任装置" + "必须保留 vs 可被风格替换"两栏）改写而来，专给**写稿环节**照着用。
>
> 一句话来由：把圣矾这套文案搬到任何写作风格，只要保住"真实数据 + 透明推算 + 亲测 + 风险直说 + 合规教学 + 保守不夸大"这条**证据链式信任配方**，成交力就在；被换掉的只是"谁在讲、用什么腔调讲"。
>
> **本清单是终审抽检的依据。** 六道门禁只保证"不违规/不重复/不像 AI"；这份清单管的是"可不可信、成不成交"，由用户按条抽检终审。任何一条硬规则违例，稿子打回。
>
> 用户非技术背景也能直接照着查：每条给出【规则】【为什么】【违例示例】三样，读稿时逐条对。

## 一、必须保留的硬规则（换任何风格都不能丢）

### 规则 1 · 数据先行，开场先甩真实数字
- **规则**：开头先给同行的真实数据（标价 / 想要 / 浏览 / 店龄 / 累计已售），再讲别的。数字一律来自事实卡，不许自己编。
- **为什么**：这是最核心的信任装置——真实、可自己去闲鱼搜到，读者才信这事成立。
- **违例示例**：开头先讲一堆"这个赛道很火、很赚钱"的形容词，正文才补数据，或者数据是拍脑袋写的。

### 规则 2 · 单品数据和店铺数据分开，绝不混说
- **规则**：想要 / 浏览是**单品**数据；累计已售 / 好评率 / 店龄是**店铺**数据。累计已售是店铺卖出总数，**不是这一单的销量**，不许说成"这个品卖了 297 件"。
- **为什么**：口径一混就是造假，被人拆穿信任全塌；这也是采集红线。
- **违例示例**："这个 MiniMax 拼车已经卖了 297 单"（297 是店铺累计，不是本单）。

### 规则 3 · 推算链条透明，且口径保守
- **规则**：要算收益，就把链条一步步摆出来：想要数 → 估算单量（想要×30%–50%）→（有拿货价才）单利 → 收益区间。**只写区间、不写点估计，每处标"推算"，拿不准取下限。**
- **为什么**：一步步算给人看＝可验证；主动压低预期反而更可信（"最起码""按最保守算"）。
- **违例示例**："这个品一个月轻松赚三万"（点估计、无链条、不标推算、往高了吹）。

### 规则 4 · 没核实的利润，不出数字
- **规则**：利润 = 单量 × 单利，单利 = 售价 − 拿货价。**拿货价没核实，就不出利润数字**，只能说估算单量和流水量级（且注明流水未扣成本、不是利润）。
- **为什么**：拿货价一缺，利润就是瞎猜；宁可不说，也不给假数。
- **违例示例**：不知道进价，却写"一单净赚 80"。

### 规则 5 · 风险直说，指命门，紧跟规避法
- **规则**：这个品的风险（封号 / 掉签 / 侵权 / 货源不稳 / 平台条款）必须直说，点到命门，然后马上给规避办法。不许只报喜不报忧。
- **为什么**：敢讲坏处＝可信；把风险讲透，信任才立得住。
- **违例示例**：通篇"稳定、靠谱、包售后"，对"账号共享可能被官方封"只字不提。

### 规则 6 · 亲测/踩坑只用真的，没有就不写
- **规则**：现身说法、亲测、踩坑、粉丝案例只能来自用户（52 期字幕库 + 口述）。**事实卡里标缺口的，就不写，AI 绝不编。**
- **为什么**："我自己在用/我踩过这坑"是最强的"这人真懂"信号，一旦被发现编造，反噬最狠。
- **违例示例**：事实卡第 8 项标缺口，稿子却写"我自己开了四五个号轮着用"。

### 规则 7 · 承认不确定，话不说满
- **规则**：拿不准的地方就说拿不准（"能不能一直稳定用不好说""不是每个品都适用"）。不许把话说死、打包票。
- **为什么**：不把话说满，反而显得诚实、内行。
- **违例示例**："这个号绝对封不了""百分百稳定一年"。

### 规则 8 · 合规边界要教，不碰红线词
- **规则**：涉及合规就教读者避坑（别写"百分百""一把过""绝对不掉"，卖整理版/不做绝对承诺）。供应路径没溯源核实前，**不许写"零成本 / 直接拿货 / 稳赚 / 绝对稳定"**。
- **为什么**：教人避坑＝有责任感＝可信；红线词既违规又反信任。
- **违例示例**："官方直连零成本拿货，稳赚不亏"。

### 规则 9 · 先讲需求成不成立，再讲怎么做
- **规则**：先回答"这生意为什么成立、给谁的痛点"，再进操作。面向"还没开始做的人"写，不预设读者已入行。
- **为什么**：受众是"想做还没做的人"；上来就讲操作细节＝受众漂移（历史四次拒稿的根因）。
- **违例示例**：开头就是"你的拿货成本是下限"（预设读者已有货源）。

### 规则 10 · 先免费给料，再要三连（克制 CTA）
- **规则**：转化靠"先给价值"（免费教程/资料/避坑清单）带出三连，不逼单、不硬广。
- **为什么**：价值前置的克制 CTA 才不掉信任；逼单显急、掉档。
- **违例示例**：通篇催"赶紧买赶紧拍，手慢无"。

## 二、可被风格层替换的（不算违例，交给各 IP 档案）

以下只是"谁在讲、用什么腔调"，换 IP 就该换，**不在信任配方抽检范围内**：

- IP 包装：自称、slogan、"第 X 计 / 下一计再见"这类系列话术。
- 口头禅与个人腔（"说白了 / 搞钱 / 轻轻松松"之类）。
- 弹幕互动小钩子的具体问法（"扣个一 / 顺便问一嘴"）。
- 举例题材、私人故事（提了辆宝马、大学买的 switch 之类）。
- 即兴啰嗦、口误、重复。
- 三连话术的具体措辞（"私信发 X 计" vs "评论区领"）。

> 判断口径：**换了 IP 还该在的，是信任配方（第一部分）；换了 IP 就该变的，是风格层（第二部分）。** 抽检只盯第一部分。

> **⚠️ 2026-09-03 补一条口径（诊断 §3.2）**：上面这张「可被风格层替换」的清单里，「口头禅与个人腔」和「弹幕互动小钩子的具体问法」两项，**按本文档自己的定义就是该被当前风格 IP 的写法替换掉的东西**——可 2026-09-03 那一轮却把它们（圣矾的口头禅表、圣矾的弹幕钩子例句）当成「真人的做法」注入了钱十七档，还给口头禅配了下限门。**替换物必须来自当前风格 IP 自己的语料，不是来自本仓库里恰好存在的那一份研究文档。** 现在有两道机器门看着这件事：`check-style-floor` 的 `foreignIpFillerCount = 0`（block），以及口头禅表按 IP 分档（`ai-flavor-rules.json` 的 `profiles[ip].fillerWords`）。
>
> 还要记一条本文档自身的性质：**这份清单整份是从 `docs/用户文案模式研究.md`（圣矾 12 期）改写来的**，第一部分十条是圣矾的信任装置。它跟别的 IP 的风格不天然冲突（mac 参照稿就是在这十条下写出来的、用户也认可），但它把讲述者的默认姿态定成了「**摆证据的调查者**」。当别的规则又把某个 IP 的「**教练姿态**」压掉之后，稿子就只剩调查者姿态了——那正是用户说的「没有钱十七的感觉」的本质。规则 19 就是为了把这一头顶回来。

## 二之二、装置轮换（2026-09-03 新增 · 硬规则）

**来由（用户原话）**：看完五篇钱十七草稿后——「我发现基本上你每一期都在用这种内容来点这3类人，虽然说风格都一样，但不应该每次都这样」。

五篇稿把第一部分的十条硬规则**机械落地成了同一批句子**：五篇全用「在找副业没用过闲鱼的… / 卖过闲置没做过项目的… / 手上几个副业在挑的…」分流；五篇全说「这是推算，不是实数」；五篇全说「拿货价没核实，一分钱净利我都不报」「我不装懂」「今天你就能做一件不花钱的事，写在评论区」。装置对，写法一模一样，观众一听就知道是模板。

### 规则 11 · 装置保留，表面写法必须轮换

- **装置层（第一部分十条）＝内容硬规则，一条都不能删。** 推算要声明、没核实的利润不报、不确定要认、风险要直说、CTA 要克制——每期都得在。
- **表面写法层＝必须每期换。同一句式不得跨期复用。**「这是推算，不是实数」这句话本身不是信任配方，它只是信任配方的一种说法；换成「我拿三成算是往少了算，五成算是往多了算，中间那段才是它可能的样子」，装置一点没丢。
- 每个装置的可选写法（各至少三种）写在 `engine/variation/device-rules.json` 的 `devices[].rotations`，生成时自动注入提示词，机器按指纹比对近期稿。

### 规则 12 · 「受众分流三类人」**彻底停用**（2026-09-03 升级）

- 原口径是「不是必用装置，近期用过就换」。2026-09-03 主线程拍板改为**彻底停用**：`engine/variation/device-rules.json` 里 `audience-split` 的 `scope` 由 `device` 改成 `banned`，**命中即 fail，与历史稿池无关**。
- 升级理由：`docs/用户文案模式研究.md` 第二节逐期记录了真人 12 期的开场推进，**没有任何一期有「分流三种人」**。它不是这个 IP 的签名，是我们自己发明并固化的模板，同时踩了跨稿骨架复用、报幕、强行三段式三条（`docs/AI味治理-外部对照.md` §3.1）。
- **这个位置换成什么，取决于当前风格 IP，不取决于圣矾。**（2026-09-03 二次修正，见下方勘误）钱十七档一律用**他自己的动作指令**（「这一期数字有点密，先点个关注，回头你还得翻回来对着看」），说法从 `engine/variation/device-rules.json` 的 `devices[a7-action-instruction].rotations` 里挑一种没用过的；**弹幕问答形制只在没有指定风格 IP 时才用**。要做别的导航，从下面挑一条与近期不同的：按问题单线推进 / 两三个词先讲清楚 / 先给结论再倒推 / 编号推进 / 按试错成本推进 / 按时间线推进 / 按「谁在赚这笔钱」推进。
- **勘误（2026-09-03，`docs/钱十七风格流失诊断-20260903.md` §3 R4 / §3.2 路径二）**：本条原来写的是「真人在这个位置放的是一句弹幕互动小钩子：大家都用什么做笔记 / 你用苹果还是安卓 / 这个品买过的扣个一」。**那三句是圣矾的原句**（出自 `docs/用户文案模式研究.md` §1/§3.1），不是钱十七的。更要命的是，本文档第二部分「可被风格层替换的」那一栏自己就写着「弹幕互动小钩子的具体问法」属于**换了 IP 就该变**的东西——却在这里被当成「真人的做法」硬性注入了钱十七档。五篇新稿因此全部照抄了这个形制（「你手里是苹果还是安卓，弹幕打一个我看看」「考过驾照的扣个一」「你们那边开通京东家政了没有，开了的吱一声」）。钱十七在这个位置放的**不是弹幕问答，是动作指令**：一个是要互动数据，一个是催完播＋催收藏，功能不同、语气不同。停用「三类人分流」这件事本身没错，错的是替换物。
- 换手法不等于放弃受众锁：**规则 9（面向还没开始做的人）照旧**，只是不再每期点名那三类人。

### 规则 12-b · 收口动作序列每期必须换（2026-09-03 新增）

- 「打开闲鱼 → 搜 X → 数第一页 → 写评论区 → 零成本」这个五拍序列**五篇完全一致**（`docs/AI味治理-外部对照.md` §3.5）。动作本身可以留，**序列写法必须每期换**：换动作、换验证对象、换交回给听众的形式。
- **勘误（2026-09-03，诊断 §3 R6）**：本条原来还允许「或者干脆不给动作、只给里程碑」，`device-rules.json` 的轮换菜单里也摆着两条「不给动作」的出口。模型每次挑最省事的那个，结尾指令从真人语料的 6 次/期掉到 1.4 次。**轮换的是说法，不是做不做**——那两条出口已删除，`closing-action-sequence`、`restrained-cta`、`nav-save-progress`、`free-homework` 四组现在都标了 `mustChoose: true`，每期必须选一种。
- 指纹已进 `device-rules.json` 的 `closing-action-sequence`（phrase 级轮换），跨期复用即打回。

### 规则 13 · 这是全新系列的第一次讲述

- **稿子里没有「上一期」。** 禁止期号 / 计号（第N期、第N计）、系列名（闲鱼虚拟搞钱一百零八计 / 108计）、「上次讲过」「我当时录」「那一期」「下一计」「私信我N计」「那期画面里」。
- **亲历照讲，只是不挂期号**：「我第38期拆过这个题」→「这个题我自己做过一轮」；「那一期的画面」→「这张图是我自己录的」；收口用「下期见」，不用「下一计见」。
- 这条是硬阻断门禁（`engine/variation/check-devices.mjs` 的 `seriesReference`），命中即打回重写。

### 规则 14 · 口播词域：书面词禁入

- 用户原话：「**『落在』，人类没有用这个词来写文章的**」。
- 禁用（出现即打回）：落在、旁证、上界、下界、上沿、下沿、量级、折算、分档、援引。
- 少用（进终审报告）：口径、时效、覆盖区、异常值、纠纷、变量、维度、颗粒度、抓手、闭环、赋能、复盘。
- 口语替代候选统一写在 `engine/naturalness/lexicon-hints.json`（唯一词表，提示词与门禁共读）：落在→在 / 挂在 / 都是；旁证→另一个证据；上界→最多也就；量级→大概多少；折算→按…算；分档→分几个价；时效→有效期；异常值→这条特别反常。

### 规则 15 · 日期戳 ≤2 次，编号结构自洽

- 同一个采集日期（如「九月二号」）全篇最多出现 **2 次**：第一次交代「这是我几号看到的盘面」，之后一律用「当天」「那天」「我看的那次」回指。
- 说了「拆成四步」，正文就**只**按这四步走。某段不在编号里（比如「需求真不真」），要么并进编号，要么放在编号宣告**之前**当铺垫，绝不许宣告了四步却先讲一个编号之外的段落。「三关」「两条路」同理。

### 规则 16 · 讲述者必须有立场（2026-09-03 新增 · 硬规则）

- **保守报数 ≠ 没有态度。** 真人的信任来自「敢说坏话 + 敢承认自己踩过坑 + 数字保守」三件事，我们只保住了最后一项，把前两项也执行成了免责（`docs/AI味治理-外部对照.md` §3.9 / U14）。
- 硬要求：全篇**至少一句**明确的「我的看法是做 / 不做 / 怎么做」。判断句后面**不许**跟「你自己判断 / 你自己定 / 我不替你下结论 / 信哪句你自己看」这类退让尾巴。
- 反例（现稿）：「是机会也可能是坑，我不能替你说成同行都在这么赚。」
  正例：「我自己的看法是可以做，但只能小成本先试一把，把渠道摸熟了再加量。」
- 这条第一部分十条一条都没冲突：规则 5（收入话术禁入）、规则 7（话不说满）限制的是「说满」，**没有一条禁止有立场**。
- 检测：正则只抓得住壳（`fenceSitting`，warn 级）；「整篇到底有没有态度」交 LLM 二审（`cli/lib/review.mjs`，warn 入报告不拦稿）。

### 规则 17 · 免责改词级压低，不许段级堆叠（2026-09-03 新增）

- 铁律 2/3/4 要求交代缺口，这条不变。变的是**怎么交代**：
  - **硬规则**：不许连着三句都是免责句（`disclaimerRun` block）。
  - **软上限**：全篇显式免责句 ≤3（long 档）/ ≤2（standard、short 档），超出只 warn 入报告，不 fail。密度硬上限留到回归集校准之后再定。
  - 其余位置一律改用**真人的词级保守口径**：「最起码」「按最保守的算」「就算按……算」「往少了算」。
- 反例（段级声明堆叠）：「拿货价我没核实到，一分钱净利我都不给你报。」
  正例（词级压低）：「拿货价我这回没问到，所以下面这个数你按最保守的算。」
- 参照：真人 9 期语料里**一次显式免责句都没有**（`engine/naturalness/baseline/qian17-baseline.json`）。这套话术是本项目铁律诱发的，不是这个 IP 的说话方式。

### 规则 18 · 报幕与自贴标签（2026-09-03 新增，同日二次修正）

**先说修正结论：被禁的是「空报幕」和「空标签」，不是「报幕」和「自标重要性」这两类动作本身。** 这两类是钱十七的招牌推进方式（真人语料里预告式报幕 10 处、自标重要性 23 处），本条第一版把整类都禁掉了，五篇新稿因此双双归零（诊断 §3 R1/R2 判定「误杀（重度）」）。

- **空报幕全篇 ≤1**。不许说「这里得讲清楚一件事」「我插一句」「两个词先说清楚」「还有一条我要单独说」——报了幕却没交付新结构。
  - **带清单的报幕不算，该写，每期 1 到 4 处。**「我给你总结了四条，分别是：一、……二、……三、……四、……」——报幕的同一句里就把清单交出来。门禁侧：钱十七档 `announceCount` 上限由 1 放到 4、由 block 降为 warn，且带清单/带数字的整句由 `exemptPattern` 豁免不计。
- **空标签全篇 ≤2**。不许说「这段最值钱」「重点听」「全篇最长的一段」——标了重要却没跟着给内容。
  - **「标签 + 立刻交付」不算，该写，每期 2 到 6 处。**「最关键的是 X，因为 Y，所以你得 Z」。门禁侧：`selfLabelCount` 上限由 3 放到 6（仍 block），命中 `exemptPattern` 的句子不计。
- 上限放宽之后**必须同时给下限**，否则模型仍然会选「一处都不写」这个安全解——下限在规则 19 的 `signatureFrameCount`。
- 「空 vs 交付」这个切法正则只抓得住「标签后面还有没有内容」，语义上到底交没交付要靠 LLM 二审（`cli/lib/review.mjs`）。

### 规则 19 · 风格标志下限（2026-09-03 新增 · 硬规则）

**来由（用户原话）**：五篇稿做完「去 AI 味」重写、九道门禁全绿之后——「**这次 ai 味少了点，但是没有钱十七的风格感觉了**」。

- **问题的结构性原因**：到这一天为止，九道门**全是「不许超」**，一道「不许低于」的都没有。门禁全是上限时，模型的安全解就是**什么都不做**——把这个 IP 的定义性动作（边讲边催、口语化确定句、编号推进、利益话术、教学承诺）一起删掉，指标全部优化到 0，比真人还干净。
- **对策**：新增第十道门 `engine/naturalness/check-style-floor.mjs`（`npm run check:style-floor`），十一项指标全是下限，按 IP 分档（`style-floor-rules.json`）。没有专属档的 IP 整道门跳过，绝不拿一个 IP 的下限去卡另一个。
- **写稿时要数的九项**（钱十七档）：动作指令句 ≥6%（<3.5% 打回）、确定句 ≥9%、确定÷迟疑 ≥1.5（<1.35 打回）、方向词句 ≥14%、利益句 ≥5.5%、教学承诺句 ≥2 处、自标+带清单报幕 ≥1 处（目标 2–6）、长句（>35 字）≥30%、带「你/咱/大家」的句子 ≥30%。
- **另有一条 block**：`foreignIpFillerCount = 0`——**别的 IP 的口头禅一个都不许出现**（说白了 / 最起码 / 等等等等 / 大错特错 / 卖就完了 / 我跟你讲 / 轻轻松松 / 没有之一 / 思路打开）。这九个词在钱十七 20,199 字语料里一次都没出现，却曾被写进钱十七档的口头禅表并配了下限门，等于拿门禁逼稿子写进另一个人的口音。这条就是那次事故的直接对策。
- **阈值怎么定的**：block 级一律取「9 期真人语料 + mac 参照稿 + 人工校准通过稿」共 11 份已认可文本的实测最小值再留余量，**误伤率 0**；warn 级取诊断给的目标值（拆解型内容按语料的 55% 折）。逐项实测数见 `style-floor-rules.json` 的 `calibration.observed`。
- **它跟前九道门的关系**：前九道查「像不像 AI」，这道查「像不像这个 IP」。**两边冲突时以这道为准**——提示词里的「风格标志」一节明写了这一条。

## 三、终审抽检怎么用（给用户）

拿到成稿，对第一部分十条**逐条打勾**，问自己：

1. 开场是不是先甩了事实卡里的真实数字？（规则 1）
2. 单品/店铺数据有没有说混？（规则 2）
3. 收益推算是不是区间 + 标了推算 + 口径保守？（规则 3）
4. 没核实拿货价的地方，是不是没出利润数字？（规则 4）
5. 风险有没有直说 + 给规避？（规则 5）
6. 亲测/案例是不是全真、缺口没编？（规则 6）
7. 有没有把话说满、打包票？（规则 7）
8. 有没有踩合规红线词（零成本/稳赚/百分百）？（规则 8）
9. 是不是先讲需求成立、面向没开始做的人？（规则 9）
10. CTA 是不是先给料再要三连、不逼单？（规则 10）

再加五问（2026-09-03 新增，对应规则 11–15）：

11. 这期的装置句式，是不是跟上一期长得不一样？（同一句话别连着两期说）
12. 有没有又用"三类人分流"开场？换掉之后放的是**这个 IP 自己的动作指令**，还是别人的弹幕问答？
13. 稿子里还有没有期号 / 系列名 / "上次讲过 / 我当时录 / 那一期"？（新系列一处都不许有）
14. 有没有"落在 / 量级 / 折算 / 上界"这类书面词混进口播？
15. 日期戳是不是念了三遍以上？说了"四步"是不是真按四步走？

再加三问（2026-09-03 二次新增，对应规则 18–19 —— 这三问查的是「写少了」，不是「写多了」）：

16. 这一篇有没有**边讲边催**？开场 / 干货密集处 / 结尾收口前，三个位置至少占到两个？
17. 讲述者是**教练**还是**记者**？全篇有没有至少两句「我教你 / 我给你讲透 / 照着做就行」？还是通篇都在「我数了三十条 / 我这回没问到人」？
18. 迟疑词是不是撒满全篇了？段级免责句降下来之后，词级迟疑有没有反而变多？（确定句必须比迟疑句多出至少一半）

**任一条不过，打回重写。** 全过只代表"可信、不掉档"，"好不好"仍以"这个 IP 的读者听不出换了人"为终极判据。
