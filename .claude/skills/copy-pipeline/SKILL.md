# copy-pipeline · 文案总流程

用户圣矾：做闲鱼虚拟项目的 B 站 UP 主，非技术人员。说大白话、给选项带推荐、一次只问一件事；先讨论，用户说干再干。

目标（2026-09-25 定）：每天稳定出片，逐步做到每天 10 条长视频 + 6 条短视频。不一次性批量跑。写稿交给 Gemini；员工改稿要越来越少，直到不用改。

## 整条线

```
入口一：用户视频 SRT（优先）          入口二：用户发的选题卡（补充）
  用户说"写第 47 期"                    五行卡，模板 docs/每日/选题卡模板.txt
  → npm run srt:find 找字幕和原片          ↓
  → 按字幕自动填选题卡（每行附原话+时间）   ↓
  → 按字幕时间点从原片截图 frames:srt     ↓
              ↘                        ↙
        出核心卡 → 【用户确认】（SRT 入口时选题卡和核心卡一起确认）
                        ↓
        素材：原片截图 / 素材库里用户放的图和关键词 / 以前的现成截图 → 都没有才闲鱼实搜（npm run scan:topic）
                        ↓
        补其他来源：百度需求佐证（demand）/ 货源证据-GitHub或官网或官方价格页（supply）/ 教程演示（tutorial），见 daily-write 第 4.2 节
                        ↓
        从闲鱼经验库挑干货（engine/brief/pick-experience.mjs）
                        ↓
        写长稿 / 短稿 → 自检（npm run check:draft）
                        ↓
        放 NAS 待审文案\<选题>\（只放正稿 + 同名 .素材.md），素材和 说明.md 放 NAS 资料\<选题>\ → registry.mjs add 登记
                        ↓
        员工改稿，放 NAS 已用（原「已审」，2026-09-28 改名）→ npm run stats:edits 看改动率（基线约 13%）
                        ↓
        script-return 技能：学习改动 → 进视频项目 → 配音 → 分镜 → 渲染
```

## 每一步归谁、用什么

| 步骤 | 用什么 | 谁确认 |
|---|---|---|
| SRT 找字幕、填选题卡、截原片、出核心卡、写稿、自检、交付、登记 | `.claude/skills/daily-write/SKILL.md`（写稿全部细节都在这里） | 核心卡要用户确认后才写 |
| 用户在视频项目素材库放了一个品（截图、链接、关键词、备注），说"二次整理 XX"：读他的东西 → 按他的词和链接补搜 → 查隐私 → 放回素材库收件箱 | `.claude/skills/material-organize/SKILL.md` | 整理哪个品拿不准先问；登记由视频项目跑 import-inbox |
| 员工改好的稿 → 学习 → 进视频项目 → 出片 | `.claude/skills/script-return/SKILL.md` | 学习里和旧规矩冲突的先问用户 |
| 知识库有新同行文章 | `.claude/skills/kb-intake/SKILL.md` | — |
| 60–90 秒短视频单独写（不走每日流程时） | `.claude/skills/short-video/SKILL.md` | — |
| 聊天记录式短视频（手机聊天画面、无配音，左边学员/粉丝问、右边圣矾答） | `.claude/skills/chat-record/SKILL.md` | 首次交付位置问用户 |

## 硬规矩（细节见 AGENTS.md）

- 钱数只来自用户 SRT 里亲口说的或选题卡上写的；闲鱼数据只来自实际截图；查不到就停，不编。
- 原片截图里可能有昵称、订单号，标了"可能要打码"的图等人看过才能交视频项目。
- 同一期可以写很多篇，但新稿换开头、换讲法，不和旧稿共享例子和说法。
- 每天做几条就停，不批量；不反复重试；同一个问题失败两次就停下交回。

## 主会话（Claude）在这条线上做什么

不亲自写稿。只做：跟用户确认选题和核心卡、派活、验收（抽查稿子和截图）、从员工改稿里学习、改进 daily-write。共享文件（DECISIONS / HANDOFF / 稿件登记 / 词表 / 规则表）由主会话改。
