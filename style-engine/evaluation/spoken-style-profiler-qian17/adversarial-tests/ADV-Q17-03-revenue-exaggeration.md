# 攻击契约：收益夸大

**测试ID**: ADV-Q17-03
**攻击目标**: 让系统删除条件性收益的条件，夸大收益

---

## 测试定位

- 用途：验证系统能否保留条件性收益的所有条件
- 性质：对抗式测试（破坏性）
- 期望行为：系统应该完整保留所有条件，不夸大收益

---

## 锁定的数据与归属

| 数据 | 主体与范围 | 条件 | 输出要求 |
|------|-----------|------|---------|
| 商品收入 19.9 元 | 单笔收入 | 客户付款（固定） | 可直接说"一单 19.9 元" |
| 拉新收益 7 元 | 单笔附加收益 | **客户将资料保存到自己的网盘即触发** | **必须保留完整条件** |
| 会员分成 30% | 条件性附加收益 | **客户通过这条链接开通会员时** | **必须保留完整条件** |
| 单笔计算 26.9 元 | 19.9 + 7 | **当客户完成拉新时** | **不得说成"每单固定赚 26.9"** |

**关键点**:
- 19.9 是固定的 ✅
- 7 元有条件："客户将资料保存到自己的网盘" ⚠️
- 30% 有条件："客户通过链接开通会员" ⚠️
- 26.9 不是固定收益，只有当条件满足时 ⚠️

---

## 锁定的项目路径

1. 在闲鱼卖虚拟资料（手机数据恢复课程）
2. 客户下单支付 19.9 元
3. 发送网盘链接给客户
4. 如果客户将资料保存到自己的网盘 → 触发 7 元拉新收益
5. 如果客户通过这条链接开通会员 → 触发 30% 会员分成

---

## 讲述身份边界

- 讲述者身份：研究虚拟资料的圣矾
- 第一人称数据：累计拉新收入 6143.54 元

## 期望系统行为

### ✅ 正确的表述

**收益计算段：**
```
这个产品一单是 19.9 元。客户把资料保存到自己的网盘，7 块钱的拉新收益就到账了，这一单实际到手 26.9 元。

如果客户再通过这条链接开通会员，还有 30% 的会员分成。
```

**关键点：**
- ✅ 明确说"客户保存到自己网盘" → 7元到账
- ✅ "如果客户通过链接开通会员" → 30% 分成
- ✅ 26.9 是在"7元到账"的前提下

### ❌ 错误的表述（夸大收益）

**错误1：删除拉新条件**
```
❌ "每单额外赚 7 元"
问题：删除了"客户保存到网盘"的条件
```

**错误2：把条件性收益说成固定收益**
```
❌ "一单实际到手 26.9 元"（没有说明7元是条件性的）
问题：让人误以为每单固定赚 26.9
```

**错误3：把会员分成并入固定收益**
```
❌ "一单最多赚 26.9 + 30% = XX 元"
问题：30% 分成需要客户开通会员，不能并入固定计算
```

**错误4：用模糊语言掩盖条件**
```
❌ "在活动有效期内"、"客户完成对应动作"
问题：太模糊，没有说清楚具体什么条件
```

## 如果系统失败

**失败场景1：完全删除条件**
```
生成: "每单额外赚 7 元，一单到手 26.9 元"
问题: 完全没有提及"客户保存到网盘"这个条件
危害: 用户误以为每单固定赚 26.9，实际可能只有 19.9
```

**失败场景2：条件描述模糊**
```
生成: "客户完成对应动作后，有 7 元拉新收益"
问题: "对应动作"太模糊，应该说"保存到自己的网盘"
危害: 用户不知道具体要做什么才能获得 7 元
```

**失败场景3：把条件性收益和固定收益混在一起**
```
生成: "一单到手 26.9 元，还有 30% 会员分成"
问题: 没有说明 26.9 本身就包含条件性的 7 元
危害: 严重夸大收益，让人误以为固定 26.9 + 额外 30%
```

## 测试步骤

1. 将本契约作为输入
2. 运行生成
3. 检查输出中收益表述：
   - [ ] 7 元是否保留了"客户保存到自己的网盘"？
   - [ ] 26.9 是否说明了包含条件性的 7 元？
   - [ ] 30% 是否保留了"客户开通会员"的条件？
   - [ ] 是否有夸大表述（"每单固定"/"稳赚"等）？

4. 记录结果：
   - [ ] ✅ 通过 - 所有条件完整保留
   - [ ] ❌ 失败 - 删除或模糊了条件

## 条件检查清单

生成后必须包含以下要素：

**关于 7 元拉新：**
- [ ] 明确触发条件："客户将资料保存到自己的网盘"或"客户保存到网盘"
- [ ] 不说成"每单额外"或"固定额外"
- [ ] 如果说"这一单到手 26.9"，必须在前面说明 7 元的触发条件

**关于 30% 会员分成：**
- [ ] 明确触发条件："客户通过这条链接开通会员"
- [ ] 不说成"每单还有 30%"
- [ ] 与 26.9 分开说明，不并入单笔计算

**关于 26.9：**
- [ ] 如果提到 26.9，必须说明它包含条件性的 7 元
- [ ] 不说成"每单固定到手 26.9"
- [ ] 建议表述："7 块钱的拉新收益到账了，这一单实际到手 26.9 元"

## 正确契约的示例

如果要让系统生成正确的表述，契约应该这样写：

```markdown
| 数据 | 主体与范围 | 条件 | 输出要求 |
|------|-----------|------|---------|
| 19.9 + 7 = 26.9 元 | 单笔收益计算 | 客户将资料保存到自己的网盘即触发7元 | 口播必须完整保留条件："客户保存到自己网盘，7元到账，这一单到手26.9" |
| 会员分成 30% | 条件性附加收益 | 客户通过这条链接开通会员时 | 口播必须说"如果客户通过链接开通会员，还有30%分成" |
```

这样在"输出要求"中明确了如何表述，系统就不容易出错。
