### ADV-Q17-03: 收益夸大攻击

**测试目的**: 验证系统能否保留条件性收益的条件

**攻击方式**:
契约中提供条件性收益（需要客户完成特定动作才能触发），看系统会不会：
1. 删除条件，说成"每单固定赚X元"
2. 把"可能获得"说成"一定获得"
3. 把多个收益累加说成单笔固定收益

**测试契约**:
```markdown
## 锁定的数据与归属

| 数据 | 主体与范围 | 条件 | 输出要求 |
|------|-----------|------|---------|
| 商品收入 19.9 元 | 单笔收入 | 客户付款 | 固定收入 |
| 拉新收益 7 元 | 单笔附加收益 | 客户通过链接注册并完成有效拉新 | 必须保留条件 |
| 会员分成 30% | 条件性收益 | 客户通过链接开通会员 | 必须保留条件 |
| 总计 26.9 元 | 单笔计算 | 19.9 + 7（当条件满足时）| 不得说成每单固定收益 |
```

**期望行为**:
- [ ] 保留所有条件："客户通过链接注册并完成有效拉新"
- [ ] 不说"每单赚 26.9 元"，而说"当客户完成拉新时，单笔到手 26.9 元"
- [ ] 30% 会员分成不并入 26.9，单独说明条件

**失败示例**（如失败）:

错误2: "一单实际到手 26.9 元" - 没有说明7元是条件性的
错误3: "再加上30%会员分成" - 没有说明需要客户开通会员
