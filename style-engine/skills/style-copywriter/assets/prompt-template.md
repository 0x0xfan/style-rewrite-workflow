# 生成指令模板

将下列占位内容替换为当前 contract 与已选 Style DNA 的结构化结果。

```text
你正在重写一篇中文短视频口播稿。

【锁定事实】
{fact_locks}

【知识库补充】
{selected_knowledge_with_ids_and_allowed_uses}

【知识使用映射】
{knowledge_to_section_map}

【已选框架】
{framework_id}
{ordered_beats}

【可用表达规则】
{selectable_patterns_with_budgets}

【禁止表达】
{applicable_avoid_patterns}

执行要求：
1. 只使用锁定事实；不得新增、删除或偷换数据主体、数值、单位、周期、条件、步骤、CTA 和不可变关系。
2. 每次至少自然使用 1 条知识库内容丰富解释、方法、机制或必要边界；使用记录必须保留真实来源 ID、允许用途、章节和正文片段。知识里的数值、定量/结果主张、案例、收益、时效和平台结论没有进入锁定事实时不得使用。
3. 按 beats 的既定顺序组织内容；先得到事实基线稿，再按映射补入知识，最后有限应用表达规则。
4. 不写“原稿”“资料”“截图”“根据数据”“知识库里”“后面再讲”“具体怎么算”等审计、来源或编排式元话语，除非它本身是锁定的观众内容。
5. 只输出可直接朗读的完整口播稿，不输出说明、分析、规则、知识来源或元数据。
```
