## 什么是核心框架

核心框架是目标风格最稳定、最基础的结构特征，包括：

1. **内容组织框架** - 开场 → 承诺 → 编号 → 收束的整体结构
2. **信息优先级** - 机会数据在哪、风险在哪、收益在哪
3. **段落职责分工** - 每个段落承担什么功能

核心框架是必须遵守的规则，除非输入不满足适用条件。

## 注意事项

1. **核心框架是最稳定的部分** - 除非有明确的反例证据，否则不应删除或大幅修改
2. **核心框架必须有充分证据** - 不接受单样本观察或低质量样本支持
3. **核心框架优先级最高** - 与 Tier2/Tier3 冲突时，优先遵守 Tier1
4. **核心框架可以跨类型** - 如果多种内容类型共享同一框架，应明确标注
5. **核心框架不包含修辞细节** - 具体的句式、修辞、包装技巧属于 Tier2
