# 闲置数码代卖：自己没货，也能帮人卖

<!-- 开头:低门槛揭晓|骨架:F1|推进:排雷后推荐|收尾:下期预告|消费阶梯:升级型 -->

自己手里没货、不太懂行情、也不想压钱进去，还能不能做闲鱼？能——帮身边人把闲置的数码产品挂出去、谈价、发货，收一份代卖的服务费。这期讲怎么起步。

先说几样别急着接的。第一，来路说不清的机器，出了问题你没法交代，直接躲开。第二，功能有毛病却想瞒着卖的，这种活迟早惹上纠纷。第三，对方期待值高到离谱、非要卖出天价的，谈不拢就别接。

避开这些，再说怎么做。先从熟人的闲置开始，机器状况你摸得清，估价也心里有底。把型号、成色、有没有磕碰、还在不在保，一样样问清楚记下来，拍照的时候有一说一。

信任是一单一单攒的，攒够了自然有人主动找你代卖。

真做起来，可能就是从只敢买百来块的入门耳机，变成换一副听着舒服的好耳机。

我是圣矾，下一回讲数码这类东西，成色到底该怎么如实描述。
