# 核心卡 · 电影票代买 · 长稿 v3（用户 09-26 已确认）

卖什么：在闲鱼代买低价电影票。买家在猫眼/淘票票/美团选好座位截图发来，拿取票码自己去影院取。

本期主推：全自动。对接好闲快票这类配套系统后，识别影院座位、报价、下单、发取票码都由系统做，不用人一直盯。你要做的是把店铺和链接做好。

交付怎么做：「买家把座次表截图发给客服、告诉他城市，AI 自动识别影院和座位，自动下单，全程无人值守」（原片 00:25–00:37，内容包 F8）。

钱（v2 已确认，模板没有这一行，照抄保留）：只用原片数——客单价二十到六十，一单几块到十几块；利润主要在节假日旺季；大城市 3D、IMAX 厅节假日一单可能二三十。闲鱼数据沿用员工定稿里已有的那几个数。

虚拟子类：代办服务类（替人下单，买家拿到的是取票码，不是文件或账号）。

本篇讲法：跟着一单走。不分"第一点、第二点"，按顺序讲：买家发截图 → 系统自动报价出票 → 买家拿码取票。干货插在各个环节里：链接怎么挂、说明里写清哪些规矩、旺季前做什么准备。框架句改成预告这条路线，比如"这期就跟着一单走一遍，从买家发截图到拿到票"，不要用"三点"。

本期要讲透的闲鱼经验（四条，候选清单里把握都是"高"，没有用"低"的）：

1. **X-上架-018**
   - 大白话：闲鱼搜索是把标题拆成一个一个词去对的，标题里没有买家搜的那个词，他就搜不到你。
   - 环节：买家发截图之前——买家先得在闲鱼搜到你（链接怎么挂）。
   - 示范：这里有个很多新手不知道的地方，我都是一部电影单独挂一条，片名放在标题最前面；因为买家搜的是"片名加电影票"，闲鱼是按标题里的词去对的；你要是只写"低价电影票"，他搜"哪吒电影票"，你的链接根本不会出来。

2. **X-合规-004**（提醒全自动里要小心的坑）
   - 大白话：说明里写"自动发货""秒发""一手货源"这类话，等于自己跟平台说"我是商家"。
   - 环节：买家点进链接看说明（说明里写清哪些规矩）。
   - 示范：这里有个坑，系统虽然是全自动的，但说明里我从来不写自动发货、秒发、一手货源这些字；因为这几个词一写上去，平台就会把你当成经营的商家来认定；不注意的话，后面就要按商家那一套来管你，这一点上架前一定自己去看平台规则。
   - 注意：认定规则是同行转述的，稿里只能说"会被当成商家"，不能说具体后果，要以平台公告为准。

3. **X-上架-013**
   - 大白话：没开通店铺的话，一条链接只能卖一次，卖掉就自动下架，下架了就搜不到了。（店铺名：鱼小铺、闲小铺都不念，一律说"这个店铺""店铺"——用户 09-26 定）
   - 环节：买家确认报价、拍下付款。
   - 示范：很多新手不知道，系统能自动接单，前提是链接一直挂在那里；没开通店铺的话，一条链接卖掉一单就自动下架了；所以我对接系统之前，第一件事就是先把店铺开通好，不然买家拍完这一单，后面的人就搜不到你了。
   - 用户 09-26 定：鱼小铺、闲小铺都不念出来，一律说"这个店铺"或"店铺"。

4. **X-售后-015 ＋ X-售后-009**
   - 大白话：电影票没有能寄的东西，也就没有凭证；真碰上买家申请退款，能拿出来的只有闲鱼聊天里他确认过的记录。
   - 环节：系统报价出票之后（出票、退款）。
   - 示范：这里特别强调一点，报价那条消息里我会把影院、场次、座位都写清楚，买家确认了再拍；因为电影票没有别的凭证，出了票又退不了，真碰上他说座位不对要退款，你能拿出来的就只有这段聊天记录；这一步没留下来，钱一般就只能退给他了。
   - 用户 09-26 确认：系统发出去的报价消息里能带上影院、场次、座位，按示范写，不用备选说法。

不能讲偏的方向：不讲手动去渠道问价，不讲"手动你也要会"；不写躺平、必卖爆、朋友提宝马；系统里的"人工介入"最多一句带过，只当出问题时的兜底。

## 候补经验（用户想换时从这里挑）

- **X-上架-036**（把握高）：买家老是问同一个问题，说明你的说明没写清。环节：系统报价的时候。示范：买家老来问"座位会不会变""多久能出"，我就把这两句补进说明，因为问的人多了系统就得转人工，全自动也就不自动了。
- **X-上架-007**（把握高）：新链接先拿一小笔推荐，跑出数据平台才接着推。环节：旺季前准备。示范：节假日前把要上映的新片提前挂上，因为新链接要先跑一段时间才有推荐，等到节假日当天再挂就来不及了。
- **X-上架-041**（把握高）：发布地址按买家所在的城市设，推荐里会放本地链接。环节：链接怎么挂。示范：按"城市加影院名"挂一条，发布地址设到那个城市，同城想买票的人更容易刷到；可以接原片"小城市小影院票价低、大城市万达万象票价高"那句。
