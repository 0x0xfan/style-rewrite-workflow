## 核心模型（两句话）

先用具体问题、案例结果、市场反差或一组数字，把本期为什么值得看迅速摆出来，并紧接着报清范围或路线。随后按真实环节或编号推进：先回答观众刚产生的问题，再把事实翻译成它对当前项目意味着什么，并在主要节点自然带出下一项仍未解决的问题，最后用目标内容自己的互动、资源与身份收口。

## 二、稳定主干

### A1. 开头先交付“值得听的具体对象”

**抽象公式：**

- 具体结果或反差 → 这期要解释什么；或
- 观众卡点 → 这期给什么路径；或
- 低门槛条件 → 具体项目揭晓。

**执行：**

- 前 1-3 句出现项目、结果反差或问题；研究过程、案例关系和经验背景可以在具体钩子后出现，但不是固定第一句。
- 有可靠数据时只放最能建立问题的一组，后续数据留到对应环节。
- 开头不强制收益数字；没有证据时，用明确问题、动作结果或范围承诺。

**结构规格（2026-08-22 结构化修订）：** 旧版只有三条“X → Y”标签，补齐槽位如下。

- **槽位：** [钩子对象 H]（具体结果／反差／观众卡点／低门槛条件，四选一）→ [本期承诺 P]（这期要解释什么／给什么路径／揭晓什么项目）。
- **槽位关系：** H 必须是观众一眼能接住的具体物；P 由 H 直接引出，两者指向同一件事。三种 H→P 变体（结果反差型／卡点型／低门槛揭晓型）任选其一，同一开头不叠用。
- **失效条件：** 第一句先报研究过程／经验背景／自我介绍而不是具体对象；用“月入过万”这类不可比空承诺当 H；H 抛出“为什么有人买”、P 却转去朗读后台流程（H 与 P 不指向同一件事）。
- **示例（仅演示结构，用词全新，不照抄；目标观众＝想找副业、还没开始的人）：**
  1. 卡点型：想做副业又怕踩坑、怕投钱打水漂？这期只讲一个零成本、能自己先验证真假的方向。
  2. 低门槛揭晓型：不用囤货、不用本钱、一部手机就能做——这期把这个方向从头到尾讲一遍。
  3. 结果反差型：有人把每天通勤路上的碎时间，做成了一个不占本钱的小生意，这期讲它靠不靠谱、你能不能上手。

**证据簇：** u01、u02、variant-03-07、u04、u06、u08、u09、u10、u11。

### A2. 尽早报路径或清单

**抽象公式：**

开头价值 → 本期分成 N 个环节/规则/类目 → 逐项推进。

**执行：**

- 路径必须来自目标内容的真实结构，不能为了“像钱十七”硬凑数字。
- 清单可以是步骤、排雷项、判断维度、月份、渠道、类目或注意事项。
- 只有一个结论时直接说，不强行编号。
- 自我介绍不是新的结构起点。它出现在开头钩子中间时，后一句先继续当前项目、案例、反差或核心问题；不要在身份句后重启一段泛化的“今天讲项目、商品、咨询和交付”课程目录。
- 路径预告要说具体价值、具体对象或具体动作；只把后台章节名念给观众，不算有效路径。
- **悬念绑定（状态：candidate / review_only）：** 报清单/路径时，可固定预告“最后一项最有价值”，把清单里价值最高的一项压到末尾并提前点名，逼观众看完。抽象公式：报路径 → 指定末项为最高价值并说明为什么值得等 → 逐项推进到末项兑现。边界：预告的价值必须真实兑现（末项确实是清单里最能改变判断的一项），不得空头承诺；一篇最多用一次，不与其他悬念钩子叠用。证据：审计确认原稿在报路径时固定使用此构造（见 `audits/source-reread-20260822.md` 漏项二，引 3 处原文位置）。

**结构规格（2026-08-22 结构化修订）：** 旧版主体只有一条“开头价值 → 分成 N 项 → 逐项推进”标签，补齐槽位如下。

- **槽位：** [开头价值 V] → [N 个并列项 I₁…Iₙ]（环节／规则／类目／月份／渠道，取一类）→ [逐项推进]。
- **槽位关系：** N 由目标内容真实结构决定，不为“像钱十七”硬凑数字；每个 Iₖ 必须能给出具体价值／对象／动作，只念后台章节名不算有效项；只有一个结论时不强行编号。
- **失效条件：** 用自我介绍或泛化课程目录（“今天讲项目、商品、咨询和交付”）冒充路径；预告的项之间其实没有并列关系；报了 N 却不逐项兑现。
- **示例（仅演示结构，用词全新）：** 这事从零到第一单要过三关——怎么自己验证需求、货源从哪来、第一笔怎么成交，一关一关来。
- 悬念绑定子构造（上一段）已含“抽象公式＋边界”，结构完整，此处不再展开。

**证据簇：** u01、u02、variant-03-07、u04、u06、u08、u09、u10、u11。

### A3. 每一点快速完成“判断—理由/证据—意义—动作”

**段落职责：**

点名当前项 → 给一个明确判断 → 用理由或证据解释 → 说清它对观众当前要做的项目意味着什么 → 给动作。

**执行：**

- 一段优先解决一个环节，不同时塞入多个新框架。
- 原因和动作贴在判断后面，不连续堆抽象结论。
- 实操段不强制加工成一句工整金句。优先把具体对象、动作、结果和赚钱关系说完；章节复盘或全文收束可以使用一句有前文支撑的口号式判断。
- 数据、案例和截图事实只证明当前这一点，不提前宣读后台审计过程。
- “意义”必须消费目标内容已有的收益、效率、风险、依赖或行动结果；只是复述数据、喊“很重要”或增加空悬念，不算完成。
- 主要章节可以在解决当前问题后自然带出下一项未解决的问题；小步骤直接进入动作，不强制制造钩子。

**2026-08-22 结构化审计：** 结构完整——本条已是结构规格（“判断—理由/证据—意义—动作”职责序列＝槽位，段内约束＋“意义”失效判定俱全），不为改而改。

**证据簇：** u01、u02、variant-03-07、u04、u06、u09、u10、u11。

### A4. 用口语化确定句推进，不写成研究报告

**可观察行为：**

- 高频使用“先看、接下来、第一、第二、最后、这里注意”等方向词。
- 直接对“你/大家/新手”说话；解释落到日常动作。
- 长句承担信息，短句承担判断、转场和提醒；密集内容中插一条轻互动重置注意力。
- 大结构可以清楚编号，段内小句不反复朗读逻辑关系。方向词只在真的换步骤时出现，不能把每句话都写成“先看 A、再看 B、因此得到 C”。
- 自我介绍常是钩子中的短暂停顿，后一句继续当前未解问题；这类身份插句不得把语气重置成培训课开场。

**边界：**

- 确定语气不等于事实确定；平台、收益和效果仍受 contract 锁约束。
- 不机械复制口头禅，不连续三段使用同一个转场壳。

**2026-08-22 结构化审计：** 结构完整——本条是“可观察行为＋边界”的语域规则（不是造句槽位公式），已含失效条件（不机械复制口头禅、不连续三段同一转场壳），不改。

## 三、内容类型框架库

候选框架必须有至少两个完整、同序的独立证据路径。框架只决定段落职责，不携带来源项目事实。

### F1. 项目/机会全路径拆解

**状态：** candidate / review_only

**适用：** 目标内容至少有可验证的需求信号、能力形成路径和可执行步骤，能够说明“为什么值得测试、怎样形成最小服务、下一步如何验证”。历史订单和收益只决定结论强度，不是所有机会测试稿的前置条件。

**禁用：** 只有市场信号、没有能力形成或服务动作；关键步骤只能靠猜测；风险无法给出必要边界。缺少真实成交、完整交付或收益时，不得补写成熟商业闭环，只能把对应段落降级为测试动作、未知项或省略。

**组织原则：**

- 先回答开头制造的核心问题，再进入证明；不能提出“为什么有人买”，随后改去朗读技术审计。
- 每个主要环节优先揭晓最能改变观众判断的一项事实，再解释它对当前项目的意义，最后给动作。
- 主要环节之间用“当前已解决什么 → 还缺什么 → 下一步解决什么”推进；这属于框架内部的信息揭晓顺序，不按钩子数量计费，也不要求每个小步骤包装。
- 风险只在会改变是否能做、怎么做或如何交付时进入观众稿；普通证据边界留在私有审计，不能抢走开头和主体的价值推进。

**路径：**

1. 具体结果、市场反差或低门槛项目钩子，并提出本期真正要回答的问题。
2. 用一组近邻证据回答该问题，立即翻译它对目标观众和项目意味着什么。
3. 报出当前证据等级能够支持的执行路径。
4. 按顺序拆能力/产品、获客测试、咨询/成交条件与最小交付；每个主要环节解决一个问题，并自然带出下一项未解决问题。
5. 有事实时说明效率、定价、复制、放大或收益关系；没有真实结果时改为下一步验证动作，不制造完成态。
6. 必要边界 + 资源/身份 CTA。

**完整同序证据路径：** variant-03-07、u10。u05 与 variant-03-07 有明显模板复用，只作为补强，不充当第二张独立票。

**2026-08-22 结构化审计：** 结构完整——本框架已是完整 beat 序列（六步路径＝槽位与顺序，适用＝功能，禁用＝负面样例，组织原则＝槽位关系），不改。

## 四、低预算辅助模式

辅助模式不能改变 F1-F3 的段落顺序。短稿最多选 1 个，长稿最多选 2 个；同一种句壳不相邻重复。

### P1. 三连低门槛

**公式：** 不需要条件 A → 不需要条件 B → 不需要条件 C → 揭晓项目。

**适用：** 目标 contract 明确支持这些门槛条件。

**结构规格（2026-08-22 结构化修订）：** 旧版只有一行公式标签，补齐槽位如下。

- **槽位：** [门槛否定项 C₁][C₂][C₃] → [揭晓项目 X]。C 是目标观众默认“做这个得先有”的东西（本钱／货／粉丝／技术，取其中三类）。
- **槽位关系：** 每个 C 都必须由目标 contract 真实支持（确实不需要）；三项否定同类门槛、层层降低心理成本，最后 X 才揭晓。不得为凑排比编造并不成立的“不需要”。
- **失效条件：** 某个 C 其实是需要的（虚假降门槛）；否定项与项目无关；同篇连用两组三连显刻意。
- **示例（仅演示结构，用词全新）：** 不用先囤一堆货，不用自己打包发快递，也不用先交一分钱学费——门槛低到只要一部手机。

**证据：** variant-03-07。u05 出现同一模板，只记为模板复现，不增加独立证据票。

### P2. 结果反差

**公式：** 同一市场/同一动作 → 两种明显不同结果 → 提出“差在哪里”。

**适用：** 两组数据主体、单位、时间窗和条件可比。

**结构规格（2026-08-22 结构化修订）：** 旧版只有一行公式标签，补齐槽位如下。

- **槽位：** [不变量 K]（同一市场／同一动作，两边逐字相同）+ [结果 R₁] vs [结果 R₂]（明显不同）→ [提问“差在哪”]。
- **槽位关系：** K 两边必须真正可比（主体、单位、时间窗、条件一致），差异只落在一个变量上；提问指向那个变量，随后正文回答它。切勿拿两个不同的人／卖家对比（会漂到已入行者视角，见 `docs/audience-lock.md`）。
- **失效条件：** 两组结果口径不可比；变量不止一个；只抛反差却不回答“差在哪”。
- **示例（仅演示结构，用词全新）：** 同一个人、同一批货，头一次挂上去没人问，换了个思路第二次当天就有人咨询——变量只有一个，就在这一步。

**证据：** u06、u08、u10。

### P3. 先排雷再推荐

**公式：** 先列不能做/容易踩坑的项 → 再给可执行选择。

**适用：** 目标内容同时有明确禁用项和替代方案。

**结构规格（2026-08-22 结构化修订）：** 旧版只有一行公式标签，补齐槽位如下。

- **槽位：** [排雷项 D₁…Dₙ]（不能做／容易踩坑）→ [可执行选择 S]。
- **槽位关系：** D 与 S 必须落在同一决策空间（都在“选什么品”或都在“用什么渠道”里），先排除后给替代；D 必须有目标事实支持，不能凭空恐吓。
- **失效条件：** 只排雷不给替代；D 和 S 不在同一决策空间；把普通步骤伪装成排雷。
- **示例（仅演示结构，用词全新）：** 先说三种新手最爱挑、其实最难出单的品类，避开之后，再讲一类真正好上手的。

**证据：** u02、u10。

### P4. 一句公式压缩

**公式：** 多个判断 → 压成一条可记规则 → 后文逐项验证。

**适用：** 公式能由目标证据支持，不掩盖必要条件。

**结构规格（2026-08-22 结构化修订）：** 旧版只有一行公式标签，补齐槽位如下。

- **槽位：** [多个判断 J₁…Jₙ] → [一条可记规则 R] → [后文逐项验证]。
- **槽位关系：** R 必须真正覆盖 J₁…Jₙ 的共性、且不掩盖任一必要条件；压缩后正文仍要把每个 J 验证回来，不能只喊口号。
- **失效条件：** R 漏掉关键条件（把公式说得比事实简单）；R 与后文验证脱节；同篇连用多条“一句公式”稀释记忆点。
- **示例（仅演示结构，用词全新）：** 选品别背那么多规矩，就一句——别人搜得到、你拿得到、还能加价卖，三条占齐才值得测。

**证据：** u02、u06、u10。

### P6. 数据意义直译

**公式：** 数据 → 只解释它直接证明的一层 → 回到动作。

**适用：** 数据归属完整，且不把相关性写成因果。

**结构规格（2026-08-22 结构化修订）：** 旧版只有一行公式标签，补齐槽位如下。

- **槽位：** [数据 N] → [它直接证明的那一层 M] → [回到动作 Act]。
- **槽位关系：** M 只能是 N 字面直接支持的一层结论，不外推、不把相关写成因果；Act 顺着 M 落到观众下一步能做的事。
- **失效条件：** 把“有搜索量”读成“你能卖出去”（相关当因果）；M 超出 N 的归属范围；只解释不回到动作。
- **示例（仅演示结构，用词全新）：** 这个类目一天几万次搜索——它只说明有人在找，不等于你发上去就能成交，接下来还得看货源拿不拿得到。

**证据：** variant-03-07、u04、u06、u08、u10、u11。

### P7. 阶段价值重置

**公式：** 当前阶段完成 → 下一阶段为什么值得继续或还缺什么 → 进入下一动作。

**适用：** 项目步骤确有依赖，或长稿在关键节点需要重新说明当前价值。它可以是执行、效率、结果或问题价值，不强制写生活消费场景。

**预算：** 风格规律不固定 1-2 次或 3-5 次，也不覆盖每个章节。当前 Enhanced 评测为防止过度控制，临时设最多 2 次；这不是钱十七稳定频次。

**结构规格（2026-08-22 结构化修订）：** 旧版只有一行公式标签，补齐槽位如下。

- **槽位：** [当前阶段完成 Done] → [下一阶段为什么值得继续／还缺什么 Gap] → [进入下一动作 Next]。
- **槽位关系：** 只在步骤确有前后依赖、或长稿关键节点才用；Gap 必须是真实未解的一环（能力／效率／结果／问题价值均可，不强制写成生活消费场景）；不覆盖每个小步骤。
- **失效条件：** 步骤间本无依赖却硬加承接；Gap 是空悬念（“接下来还有更关键的”却没内容）；每章都重置显啰嗦。
- **示例（仅演示结构，用词全新）：** 到这儿需求验证就算过了，接下来最花功夫、也最决定能不能赚到钱的是货源，咱们接着往下说。

**证据：** variant-03-07、u05、u10。

### P8. 生活消费阶梯

**状态：** candidate / review_only（2026-08-22 结构化修订：由“一句话公式”重写为完整结构规格，作为全档案示范）

**结构模板：**

> 从 [频率框架 F] [低档日常消费 A]，变成 [同一频率框架 F] [高档但仍日常可及的消费 B]

**槽位定义：**

- **F 频率/场景框架**：一次消费发生的频率或场景（“每天早上”“每周”“每次换季”“每天上下班”）。F 两边必须逐字相同——变的只有消费档次，不变的是“这件事你本来就在做”。
- **A 低档日常消费**：目标观众此刻真实在做的低档消费，从 `docs/audience-lock.md` 的目标观众画像取（想找副业、还没开始做这个项目的人）。必须是他已经在花的钱，不是想象出来的。
- **B 高档但仍日常可及的消费**：与 A 同类别、更高一档、观众知道且向往、但平时舍不得、只当作“犒劳”的消费。够得着，不遥远。

**槽位关系（硬约束）：**

- **A、B 必须同类别**：都是吃 / 都是通勤 / 都是买衣服 / 都是买水果。跨类别比较（吃 → 旅游）会让“同一件事升了一档”的感知失效，结构作废。
- **价格比约 5–10 倍**：B/A 大致落在 5–10 倍。比值太小（两三倍）没有向往感；太大（几十上百倍）就从“实在人过日子”变成吹牛，破坏“谈钱不伤感情”的实在人设。
- **两边都要具体、有画面、可感**：说得出物件、说得出场景，观众脑子里立刻能浮出画面；不能是“低消费→高消费”这种抽象词。

**功能：**

把收入差翻译成生活差——观众看到的是生活升了一档，收入到底涨了多少，由他自己在心里推断，讲述者一个数字都不报。正因为不报数、只给生活画面，它在小红书 / 抖音这类对收益承诺敏感的平台才能用（报数即触合规，见负面样例）。

**变体——里程碑型（功能不同，单列）：**

- 形态：把“第一个成果”缩到极小、极具体的一次消费（如“第一顿想吃的早饭钱”“第一张电影票钱”“食堂多打一个荤菜的那几块”）。
- 功能差异：主型表达的是“收入差 / 生活升级”；里程碑型表达的是“起步门槛极低”——第一笔小到你不可能做不到，用来降低“还没开始的人”迈出第一步的心理成本，不是炫耀收入。两者功能不同，不可混用。
- 注意：来源原文的里程碑说法里的参照物（如“奶茶”）是来源参照物，不得照搬；里程碑消费同样从目标观众画像现取。

**生成程序：**

1. 确定目标观众当下真实的 A（从 `docs/audience-lock.md` 受众锁取，不能凭空设）。
2. 在**同类别**里找一个 5–10 倍的 B（观众向往、平时当犒劳的那一档）。
3. 选一个两边共用、能逐字复用的 F。
4. 套入模板后回读检查：它是否还像炫耀 / 是否报了数 / 两边是否真同类。任何一条不过，就换 B 或换 F。

**负面样例（什么情况下这条会坏）：**

- **同时报数字**：“从每天早上路边煎饼变成每天现磨咖啡，也就是月入过万”——数字一出，观众不用自己推断了，结构白搭，且在短视频平台直接触收益承诺合规红线。
- **B 过高**：跳到米其林、马尔代夫、豪车——脱离“日常可及”，变成吹牛，毁实在人设。
- **跨类别**：拉面 → 一场说走就走的旅游——不是同一件事升级，感知断裂。
- **复用来源参照物**：兰州拉面、海底捞、奶茶——这三个是来源原稿里的具体参照物，不得出现在任何新稿里。
- **一篇用两次**：重复用会显得刻意炫耀，冲淡实在感。

**示例（仅演示结构，生成时不得照抄示例本身；目标观众＝想找副业、还没开始的人，A/B 均为新造、非来源物件）：**

1. 从每天早上买两三块的路边煎饼，变成每天早上喝得起二十来块的现磨咖啡配点心。（F＝每天早上买早饭）
2. 从屋里添件电器只敢在网上淘两三百的杂牌，变成屋里添件电器能进门店提两千多的品牌。（F＝屋里添件电器）
3. 从换季只在线上挑几十块的基础款，变成换季能进商场买三四百的当季款。（F＝每次换季添衣服）
4. 从每月房租只出得起两千的合租单间，变成每月房租能付一万的整租一居。（F＝每月房租）
5. 从平时只去楼下三十块的快剪，变成隔段时间能进两三百的沙龙打理头发。（F＝打理头发）

> **生成时的额外硬约束**：除不照抄以上示例外，还须先查批次账本（`npm run ledger`）——避开本批次其他稿件已用过的 A/B 物件。2026-08-22 记录：两个独立生成任务在同一套结构约束（F 逐字相同、同类别、5–10 倍、目标观众＝想找副业还没开始的人、避开来源参照物）下各自选出了同一款高档水果作 B 侧实例，说明“结构约束越硬 → 可选实例落点越窄”，示例列表本身挡不住批次内撞车，必须靠账本做批次去重。

**适用位置：** 开头价值（把“这期能赚多少”换成生活场景的升级）、CTA 前（把继续做下去的理由锚在生活消费上）。

**边界：**

- 消费参照必须与目标观众的收入水平匹配，用目标输入自己的场景，不得复制来源的具体参照物。
- 只在目标内容有真实收益证据时用；没有结果证据时不写，不能凭空造消费升级。
- 每篇最多一次，不与其它开头价值钩子叠用。

**证据：** 审计确认至少 3 个单元在关键位置（开头价值、CTA 前）稳定使用，是稳定手法而非零星观察（见 `audits/source-reread-20260822.md` 漏项三）。

## 六、负面风格与硬边界

### 对立煽动语气：真实存在，分级管控（状态：candidate / review_only）

回源审计发现原稿存在明显的强对立、煽动语气——把观众和“平台/资本/大多数人”对立起来，用抢占、损失厌恶和道德指控驱动行动（见 `audits/source-reread-20260822.md` 漏项四，引 3 处原文位置）。旧档案完全没记录这一层，既没作为特征也没设边界，是一个真空地带。此处补记并分级：

- **长视频：可用但需节制。** 单篇最多一处；对立语气必须服务当前内容的真实判断，不能变成通篇煽动。
- **短视频（小红书/抖音）：一律禁用。** 对立煽动叠加平台合规风险极高，禁止出现。诱导能量改由好奇、悬念、信息缺口、损失厌恶承载，约束框架见 `docs/platform-compliance.md`。
- 不搬来源的具体对立话术原句作为模板；语气层可复用，措辞由目标输入自己生成。

以下为原有硬边界清单：

- 不把清单写成“第一章、第二章”的培训课语气。
- 不在每段前重复“为什么值得做、真正关键、本质上、核心逻辑”。
- 不把粗粒度目标事实扩写成未经验证的诊断话术、固定问法或微型 SOP；风格只能改变呈现，不能替目标内容补经验。
- 不用“你不用一开始都会—先练最简单的—就能做基础单”这类通用安慰句代替真实项目动作。
- 允许有证据的语义对比；禁止连续多段机械复用“不是 X，而是 Y”或“很多人以为……其实……”同一句壳。
- 不把买家痛点写成观众目标；先锁 `narrator / target_viewer / case_buyer / content_goal`。
- 不把钱十七样本中的收益、案例、教程、账号、平台判断、资源、公众号或关键词带进新稿。
- 不把未核验的平台机制、合规、安全、收益确定性写成事实。
- 不向观众暴露原稿、截图、知识检索、风格审计、版本或改写过程。
- 版权、隐私、违法、资金损失或会使步骤失效的红线必须保留；普通不确定性留在私有审计，不把口播写成免责声明合集。

### AI 味负面清单（2026-08-23，依据 `docs/de-ai-writing.md`）

生成钱十七稿时，除上述硬边界外，额外过这五条去 AI 味排查：

- **电报体与悬空"的"字句清零。** 不得为求精炼删掉主语、宾语或助词到不像口语；句尾悬空、吞掉中心词的"的"字结构（"只收……的""挑……的"）一处都不留，补回中心词再说。
- **破折号、冒号、引号、总结壳按阈值控量。** 破折号基本不用；冒号金句壳、引号框词、总结壳口头禅（说白了 / 这就是 / 一句话 / 记住一条 / 核心是 / 本质上）按 `engine/naturalness/ai-flavor-rules.json` 的钱十七阈值封顶——钱十七仿写的冒号、引号偏离真人最大，尤其收紧。
- **编号分点保留，但拆僵硬。** 编号与对仗是钱十七本人签名，保留；但不得"点点等长、四平八稳"，不得每一点都写成"动宾 + 动宾 + 动宾"的整齐对仗。要拆的是这种机械对齐，不是编号本身。
- **规矩句与结尾动作序列不得与其他 IP 稿件同构。** 核心规矩句 / 判断句、结尾的动作序列（打开某平台 → 搜 → 发某处）必须是钱十七自己的一套，不得与半佛或其他 IP 的稿件撞同一句骨架；同一 IP 的多篇之间也要换（见 `docs/variation.md` 连接壳缺口）。
- **用词以本档 `corpus/lexicon.json` 为准。** 实词优先用钱十七本人常用词：业务名词走"货源 / 渠道 / 出单 / 上架 / 养号 / 权重 / 话术 / 客单价 / 选品 / 售后 / 发货 / 详情页"这一套，**不缩略**（"货"必须写"货源"）、**不生造搭配**（不写"散在……口子里"，写"都在……渠道里"或"藏在……渠道里"）、**不硬装口语 / 方言**（不写"打哪来 / 掂量掂量 / 蹲得住"，写"从哪来 / 想清楚 / 撑得住"）、**不压缩反复问**（不写"说不说得清"，写"能不能搞清楚"）。交付前跑 `npm run check:lexicon -- --ip 钱十七 --drafts <文件>` 报告并人工逐条过目。**严禁把来源原句、来源具体数据、来源账号或来源关键词写入新稿。**
- **自检**：写完过 `npm run check:ai-flavor` 与 `npm run check:lexicon`，再人工读——有没有一句"人嘴里说不出来"的压缩句、有没有一段"换个 IP 也能原样用"。

依据：`docs/research/ai-flavor-diagnosis-20260823.md` 第 4 节。

## 七、生成权重与最小对照

### Baseline：只用主框架

1. 根据 content contract 唯一选择 F1、F2 或 F3；无唯一匹配则 abstain。
2. 只排列框架 beats，不添加 P1-P6。F1 内部仍必须完成“当前疑问 → 事实揭晓 → 意义翻译 → 下一问题”，因为这是框架推进，不是辅助钩子。
3. 保持事实、主体、数字、单位、时间、条件、步骤顺序和 CTA 锁。

### Enhanced：主框架 + 少量辅助

1. 保持与 Baseline 相同的框架和事实顺序。
2. 短稿最多 1 个、长稿最多 2 个辅助模式。
3. 互动指令已升为主干 A7，不再计入辅助模式预算：按 A7 的固定位置分布，每篇 2-4 处常见、不设硬上限，同句壳不相邻重复；目标输入已有 CTA 时并入 A7 的结尾位置。

### 选择规则

人工并排比较以下五项：

- 开头是否更快进入项目/问题。
- 结构是否清楚但不像课程目录。
- 口语是否自然，是否出现重复句壳。
- 证据是否贴着对应判断，事实是否完全保真。
- Enhanced 是否真的比 Baseline 更像钱十七；没有明显改善就保留 Baseline。
