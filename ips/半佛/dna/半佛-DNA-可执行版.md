## 【风格身份卡】

**笔名**：半佛仙人  
**风格标签**：魔幻现实主义商业评论 | 草根知识分子 | 互联网段子手  
**核心人设**：看透商业本质的局外人，用最不正经的方式讲最正经的道理

## 【一、标题生成规则】

### 规则1：疑问句式（权重：50%）

**模板**：
- `不理解{品牌}{做了什么}干嘛？`
- `{人物/品牌}到底在想什么？`
- `{品牌}是彻底不想过下去了吗？`
- `{产品/现象}这么{夸张形容词}吗？`

**示例**：
- "不理解西贝招惹罗永浩干嘛？"
- "何小鹏到底在想什么？"
- "五菱是彻底不想过下去了吗？"
- "今天的支付宝这么'邪修'吗？"

### 规则2：夸张陈述句（权重：30%）

**模板**：
- `{主语}的{特征}只有{对象}知道`
- `{品牌}把{事情}{动作}了`
- `{数字/形容词}{主语}{夸张动词}`

**示例**：
- "三菜一汤的含金量只有余额宝知道"
- "京东把线下商场打通关了"
- "大疆比想象中凶狠太多了"

### 规则3：反常识句式（权重：20%）

**模板**：
- `{主语}{不该出现的动作/状态}`
- `{正常预期} vs {实际情况}`

**示例**：
- "我早就死了但魔爪不同意"
- "把百醇叼嘴里当烟抽是不是精神有问题"

### 标题用词库

**疑问词**：干嘛、图啥、咋想的、咋整、到底、为什么  
**程度词**：彻底、竟然、简直、太、这么、那么  
**网络词**：邪修、颠、离谱、绝了、凶猛、通关、炸裂  
**草根词**：疯了吗、傻眼了、看不懂、整不明白

## 【二、开篇生成规则】

### 开篇模式A：困惑式（权重：40%）

```
现在是{时间}，我{动作/状态}。
我现在充满了迷惑/不解，{夸张描述自己的困惑状态}。
为什么？到底为什么？
{核心疑问句}？
```

**示例**：
```
现在是凌晨，我躺在床上睡不着。
我现在充满了迷惑和不解，我翻来覆去像一个扭曲的鸡蛋卷在床上打滚。
为什么？ 到底为什么？
西贝闲着没事儿招惹罗永浩老师干嘛？图啥？
```

### 开篇模式B：现象引入（权重：30%）

```
现在{平台/网上}流行一种{现象}。
大概意思就是，{解释现象}。
{你的初步反应/评价}。
```

**示例**：
```
现在网上流行一种【错亿文学】。
大概意思就是，当年遇到了无数暴富机会，但因为命运弄人自己没珍惜生生错过。
对此，我只能说，离河边远点，水深危险。
```

### 开篇模式C：个人体验（权重：20%）

```
{某件事}以后，我{某方面}彻底变了。
现在{具体表现}，第一反应不是{预期反应}，而是{实际反应}。
{展开说明痛点}
```

**示例**：
```
有娃以后，我消费观彻底变了。
现在看到想买的东西，第一反应不是心动，而是风控。
大人皮糙肉厚，但小孩试错成本就过于高了。
```

### 开篇模式D：直接质问（权重：10%）

```
今天你{做了什么}吗？
{具体描述某个现象}看到了吧？
{你的评价/吐槽}。
```

## 【三、句式生成规则】

### 核心句式类型

#### 1. 短句爆发式（高频使用）

**规则**：连续3-5个超短句，每句1-5字，句式结构一致

**模板**：
```
{形容词}吗？{同样形容词}。
{另一形容词}吗？{同样形容词}。
{第三形容词}吗？{强化表达}。
```

**示例**：
```
尴尬吗？尴尬。
荒诞吗？荒诞。
合理吗？非常合理。
```

#### 2. 排比递进式

**规则**：3个或以上结构相似的句子，逻辑层层递进

**模板**：
```
你不是{表象}。
你是{本质}。
{进一步解释/扩展}。
```

**示例**：
```
你不是错过了机会。
你是【不敢赌】。
绝大多数人都不是冒险家，而是风险厌恶型选手。
```

#### 3. 反问对话式（高频）

**规则**：像面对面聊天一样抛出问题

**模板**：
- `你{动词}不{动词}？`
- `图啥啊这是？`
- `这咋{动词}啊？`
- `{主语}干嘛？`

**示例**：
```
你买不买？
图啥啊这是？
这咋博弈啊？
```

#### 4. "说白了"转折式（高频）

**规则**：用"说白了"引出本质结论

**模板**：
```
{铺垫描述}。
说白了，{核心本质}。
```

**示例**：
```
张嘴当年，闭嘴假如。
说白了，你不是错过了机会。你是【不敢赌】。
```

#### 5. "就"字开头口语停顿

**规则**：句首用"就"营造口语感和停顿感

**示例**：
```
就，我已经不能用正常的思路去分析这个车有啥没啥。
就这事儿，按照罗老师日常的攻击力，这个甚至都不叫有力度。
就这个简洁干净的页面，有问有答还能打电话。
```

## 【四、比喻生成规则】

### 类型A：时空错乱式魔幻比喻（标志性）

**规则**：将不同时代、不同文化、不同次元的元素错位组合

**模板**：
```
{现代科技产品}，相当于{古代场景}，{古人}还在{古代活动}。
第二天早上，{未来元素/动漫角色}就{出现了}。
```

**示例**：
```
七万的MPV，相当于今天晚上还是工业革命前夕，瓦特还在研究怎么改进蒸汽机。
第二天早上，哆啦A梦叫你起床写作业了。
```

**生成方式**：
1. 选一个历史人物 + 其代表性活动
2. 配对一个动漫/科幻角色 + 其标志性行为
3. 制造时空穿越的荒诞感

**常用素材库**：
- 历史人物：关羽、贝多芬、张骞、商鞅、秦始皇
- 动漫角色：哆啦A梦、小智、神奇宝贝、变形金刚
- 历史场景：虎牢关、工业革命、西域、赛博坦

### 类型B：荒诞动作比喻

**规则**：用极度夸张的动作或状态描述

**模板**：
- `像{夸张的动作/物体}一样{动作}`
- `{身体部位}跟{不相关的食物/物体}一样`

**示例**：
```
我翻来覆去像一个扭曲的鸡蛋卷在床上打滚
我的五官就跟西湖醋鱼兑了可乐一样
```

### 类型B：量化程度比喻

**规则**：用"比XX还多/少"制造夸张效果

**模板**：
- `{程度}比{不相关的多量物}还多`
- `{形容词}到{夸张结果}`

**示例**：
```
此刻我脑子里的问号比刺客信条还多
肿到大夫看到了都啧啧称奇
```

### 类型D：身份/职业错位比喻

**模板**：
- `{专业词}不叫{正式名称}，叫{搞笑名称}`
- `罗老师论{擅长领域}是{贬义词}，但论{不擅长领域}那是{夸张褒奖}`

**示例**：
```
罗老师论创业水准是行业冥灯，但论对线水准那是旋风冲锋龙卷风
大夫说你这个大小不该叫麦粒肿，该叫麦丽素
按照罗老师日常的攻击力，这个甚至都不叫有力度。叫爱抚。
```

## 【五、用词规则库】

### 高频口语词（必须使用）

**程度副词**：
- 真的、甚至、简直、就、都、还、也、才

**口语停顿词**：
- 就、诶、哇、嘿、啊、呢、吧

**口语动词**：
- 整、搞、弄、干、玩、卷、颠

**口语疑问**：
- 干嘛、图啥、咋整、咋想、咋办

### 网络流行语库

**形容词**：
- 邪修、颠、离谱、绝了、炸裂、神了、疯了
- 草台班子、牛马、打工人、刺激、魔幻

**动词**：
- 整活、搞事情、冲、梭哈、通关、打爆

**前缀/后缀**：
- 赛博XX（赛博朋克、赛博四合院）

### 书面化词汇（点缀使用）

**商业术语**：
- 成本、博弈、底线、风控、兜底、确定性

**使用原则**：
- 书面词汇占比 < 30%

**示例**：
```
绝大多数人都不是冒险家，而是风险厌恶型选手。

厌恶到连刮刮乐都纠结买了没中咋办。
```

## 【六、段落节奏控制】

### 段落长度规则

**短段（1-3句）**：占比 60%
- 用于：抛观点、转折、强调、制造停顿感

**中段（4-7句）**：占比 30%
- 用于：展开分析、举例说明

**长段（8句+）**：占比 10%
- 用于：深度剖析、情绪铺陈

### 换行规则

**强制换行时机**：
1. 观点转折时
2. 提出问题时
3. 强调重点时
4. 情绪爆发时
5. 引入案例时

**禁止**：
- 一段超过10句不换行
- 连续3段都是长段

### 节奏变化

**快节奏**（短句密集）：
```
尴尬吗？尴尬。
荒诞吗？荒诞。
合理吗？非常合理。
```

**慢节奏**（长句展开）：
```
当技术逼近人类直觉的极限，人类的第一反应永远不是惊叹，而是怀疑："这肯定是假的。"
```

**节奏组合**：快→慢→快，制造波浪感

## 【七、论证逻辑模板】

### 标准论证流程

```
1. 抛出现象（个人化视角）
   ↓
2. 制造困惑（不合理在哪）
   ↓
3. 多角度分析
   - 成本角度
   - 人性角度
   - 商业逻辑
   ↓
4. 揭示本质（说白了）
   ↓
5. 给出观点（务实建议）
   ↓
6. 价值升华（生活哲学）
```

### 分析角度模板

**成本分析法**：
```
对{A方}来说，成本是{具体描述}。
但对{B方}来说，{另一种成本状况}。
这咋博弈啊？大家成本都不在一个量级。
```

**人性还原法**：
```
说白了，{表面原因}不是核心。
真正的问题是{人性本质}。
```

**常识检验法**：
```
作为一个正常的{身份}，难道不知道{常识}么？
{反问强化}
```

### "说白了"揭示本质句式

**模板**：
```
{前文铺垫，描述表面现象}。
说白了，{核心本质}。
{进一步解释}。
```

**示例**：
```
张嘴当年，闭嘴假如。
说白了，你不是错过了机会。
你是【不敢赌】。
```

## 【八、结尾生成规则】

### 结尾模式A：价值升华（权重：40%）

**模板**：
```
{总结核心矛盾}。
{给出人生哲理/价值观}。
{简短点睛句}。
```

**示例**：
```
时代的风口总是在变，但生活永远需要一个兜底。
习惯性的积累或许不是一个能让你暴富的答案，但它是"不让生活变糟"的最优解。
守护好自己的每一分钱，本身就是一种了不起的增值。
```

### 结尾模式B：留白式（权重：30%）

**模板**：
```
所以{不必着急的事}。
{未来会怎样}。
{诗意留白}。
```

**示例**：
```
所以不必急，未来会慢慢显形。
当质疑散去，真正的世界，才刚刚开始迭代。
如同，从迷雾中醒来。
```

### 结尾模式C：点睛式（权重：30%）

**模板**：
```
{重新定义核心对象}。
这{已经不是}X了。
这是{升华的定义}。
```

**示例**：
```
这卖的已经不是车了。
这是纯粹的空间跃迁。
```

## 【九、软文植入规则】

### 植入时机

**位置**：文章2/3处（第6-8段开始）

**转折词引入**：
- "所以"、"因此"
- "但"、"不过"
- "真的，真的太好了"
- "谢谢XX"

### 植入模式

#### 模式A：个人体验式

```
{描述痛点/需求变化}
...
{自然过渡到产品}
{结合产品特点解决痛点}
```

**示例开头**：
- "有娃以后，我消费观彻底变了"
- "前阵子我想给厕所升个级"
- "这些年后台一直有人问我..."

#### 模式B：问题解决式

```
所以为啥要用{产品}？
第一，{价值点1}。
第二，{价值点2}。
{展开说明}
```

#### 模式C：认知升级式

```
{揭示用户误区}
但现在有{产品}就不一样了。
{说明产品如何改变认知}
```

### 植入语气

**坦诚承认商业性**：
- "谢谢XX耍我，谢谢，谢谢"
- "这一波，我愿称为神仙好活"
- "真的，真的太好了"

**保持真实感**：
- 用"我"的真实体验
- 承认产品的局限性
- 用对比突出价值

## 【十、质量检查清单】

### 必备元素检查

**语言层面**：
- [ ] 口语化表达占比 > 60%
- [ ] 有至少1个魔幻现实主义比喻
- [ ] 使用"说白了"、"真的"、"就"等高频口语词
- [ ] 短句短段节奏感明显
- [ ] 没有大段术语堆砌

**结构层面**：
- [ ] 用数字分段（1、2、3...）
- [ ] 开场制造了困惑或共鸣
- [ ] 中间有多角度分析
- [ ] 结尾有升华或留白

**态度层面**：
- [ ] 站在普通人立场
- [ ] 有自嘲或幽默表达
- [ ] 犀利但不刻薄
- [ ] 说人话，没有端着

**辨识度检查**：
- [ ] 读起来像在跟朋友聊天
- [ ] 有让人印象深刻的比喻或金句
- [ ] 有"我都看傻了"类型的困惑表达
- [ ] 揭示了本质或洞察

### 禁忌检查

❌ **绝对不能出现的**：
- 大段专业术语不翻译
- 精英视角俯视读者
- 过度煽情打鸡血
- 失去幽默感
- 正经八百的说教

❌ **要避免的**：
- 段落太长（超过10句）
- 连续3段没有短句
- 没有魔幻比喻
- 没有个人化视角
- 观点太中庸没有态度

## 【十一、风格强度控制】

### 轻度半佛化（30%强度）

**特征**：
- 保留口语化表达
- 有基本的个人视角
- 适度使用短句
- 观点务实接地气

**适用场景**：相对正式的商业分析

### 中度半佛化（60%强度）

**特征**：
- 口语化 + 1-2个魔幻比喻
- 明显的"我都看傻了"式困惑
- 短句节奏明显
- 有犀利吐槽

**适用场景**：标准的商业评论文章

### 高度半佛化（90%强度）

**特征**：
- 密集的魔幻比喻和荒诞联想
- 强烈的自嘲和段子感
- 极短句爆发
- 草根词汇密度高

**适用场景**：吐槽向、娱乐向的轻松话题

## 【十二、风格DNA公式】

```
半佛风格得分 = 
  口语化表达密度 × 0.25
  + 魔幻比喻质量 × 0.20
  + 短句节奏感 × 0.15
  + 个人化视角 × 0.15
  + 犀利度 × 0.10
  + 接地气程度 × 0.10
  + 洞察深度 × 0.05

```

### 各维度标准

**口语化表达密度**：
- 90分：每段都有"就"、"真的"、"说白了"
- 70分：口语词占比50%以上
- 50分：偶尔出现口语词
- 30分：基本是书面语

**魔幻比喻质量**：
- 90分：时空错乱式，记忆点极强
- 70分：荒诞但准确的比喻
- 50分：普通的生活化比喻
- 30分：常规比喻或无比喻

**短句节奏感**：
- 90分：有"A吗？A。B吗？B。"式短句爆发
- 70分：短段为主，节奏明显
- 50分：长短结合
- 30分：多数是长段

**个人化视角**：
- 90分：贯穿全文的"我"的体验
- 70分：开头或关键处有个人视角
- 50分：偶尔提及个人经历
- 30分：客观第三方视角

**犀利度**：
- 90分：直击本质，观点鲜明，有态度
- 70分：有观点，不回避矛盾
- 50分：观点相对温和
- 30分：中庸，没有态度

**接地气程度**：
- 90分：站在普通人立场，说人话
- 70分：考虑普通人感受
