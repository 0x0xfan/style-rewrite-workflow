## 测试用例 1: 虚拟产品选品文案

### 输入

```yaml
project_facts:
  product_type: "虚拟产品"
  scenario: "选品"
  target_audience: "闲鱼新手"
  key_points:
    - "0成本"
    - "易操作"
    - "快速变现"
  constraints:
    - "避免提及具体产品名称"

style_preference:
  style_card: "钱十七"
  tone: "亲切"
  length: "中"

knowledge_focus:
  tags: ["选品策略", "虚拟产品", "新手入门"]
  risk_check: true
```

### 预期输出

**内容特征**:
- 符合钱十七的口吻（接地气、有共鸣、编号清晰）
- 融入知识库中的虚拟产品选品经验
- 包含避坑建议
- 提供具体的操作步骤
- 无违规词

**知识来源**:
- 应引用 2-3 篇相关知识库文章
- 标注具体的知识点来源

**合规报告**:
- 违规词检查通过
- 安全状态: ✓

**优化建议**:
- 至少包含 2-3 条实用建议

### 验收标准

- [ ] 内容长度适中（500-800 字）
- [ ] 开头有钩子（痛点/对比/排雷）
- [ ] 正文有编号步骤
- [ ] 结尾有 CTA 或互动
- [ ] 无违规词
- [ ] 引用知识清晰可追溯

## 测试用例 2: 标题优化

### 输入

```yaml
project_facts:
  product_type: "电子产品"
  scenario: "标题"
  target_audience: "学生党"
  key_points:
    - "iPhone 13 Pro"
    - "256G"
    - "九成新"
    - "价格实惠"

knowledge_focus:
  tags: ["标题优化", "流量技巧"]
  risk_check: true
```

### 预期输出

**内容特征**:
- 生成 3-5 个标题方案
- 每个方案包含:
  - 优化后的标题（20-30 字）
  - 优化策略说明
  - 使用的技巧（关键词、痛点、场景）
- 基于知识库的标题优化原则

**知识来源**:
- 引用标题优化相关文章
- 提取关键优化技巧

**合规报告**:
- 检查标题中的违规词
- 提供替代方案（如有违规）

**优化建议**:
- 预估各标题的曝光潜力
- 建议适用场景

### 验收标准

- [ ] 生成 3-5 个标题方案
- [ ] 每个标题长度合理（20-30 字）
- [ ] 包含优化说明
- [ ] 融入知识库的标题技巧
- [ ] 无违规词
- [ ] 有曝光度分析

## 测试用例 3: 客服话术

### 输入

```yaml
project_facts:
  product_type: "服饰鞋包"
  scenario: "客服"
  target_audience: "议价买家"
  key_points:
    - "已是最低价"
    - "包邮"
    - "支持验货"

knowledge_focus:
  tags: ["应对议价", "话术技巧"]
  include_scripts: true
  risk_check: true
```

### 预期输出

**内容特征**:
- 结构化话术:
  1. 开场问候
  2. 理解需求
  3. 解释价格合理性
  4. 突出附加价值（包邮、验货）
  5. 促成交易
- 应对常见异议
- 语气亲切但坚定
- 融入知识库话术模板

**知识来源**:
- 引用议价应对相关文章
- 使用话术库中的模板

**合规报告**:
- 检查话术中的违规表达
- 确保不使用绝对化用语

**优化建议**:
- 提供多个应对变体
- 建议语气调整

### 验收标准

- [ ] 话术结构完整（开场→解释→促成）
- [ ] 应对议价的策略清晰
- [ ] 突出附加价值
- [ ] 语气亲切专业
- [ ] 融入话术库模板
- [ ] 无违规表达
- [ ] 提供应对变体
