## 阶段 1: 开场问候

### 话术 1.1 (标准版)

```
亲，感谢关注！看中这件了吗？😊
有什么想了解的尽管问，我都在线的~
```

**使用时机**: 买家首次咨询或直接问价
**语气**: 亲切、热情、不强势
**知识库依据**: 首次接触避免直接谈价格，先建立信任感

### 话术 1.2 (简洁版)

```
在的呢，这件确实很不错👍
```

**使用时机**: 买家直接问"在吗"或"能便宜吗"
**语气**: 简洁、肯定商品价值
**知识库依据**: 简短回应避免话题被带跑，保持主动权

---

## 阶段 2: 理解需求

### 话术 2.1 (探询型)

```
可以理解想要实惠价格的心情😊
方便问一下，是觉得价格偏高，还是预算有限呢？
这样我好看能不能帮到你~
```

**目的**: 了解议价真实原因
**技巧**: 给选项而不是开放式问题，便于引导
**知识库依据**: 不同议价原因应对策略不同，先判断再回应

### 话术 2.2 (直接型)

```
咱们这个定价已经是诚心价了哈
不过你如果真心想要，咱们可以聊聊~
```

**目的**: 表明底线但留余地
**技巧**: "诚心价"替代"最低价"，合规且有弹性
**知识库依据**: 避免绝对化用语，保持协商空间

---

## 阶段 3: 解释价格合理性

### 话术 3.1 (成本拆解型)

```
这个价格真的是算的很细了：
✓ 吊牌价XX元，我当时买的价格
✓ 只穿过2-3次，基本全新
✓ 已经包邮，省了15-20元运费
✓ 支持验货，不满意可退

算下来实际到手比我卖的价格还划算呢~
```

**适用**: 买家质疑价格偏高
**技巧**: 
- 用勾选符号增强条理性
- 具体数字比"很便宜"更有说服力
- 最后一句话转移焦点到"划算"而非"便宜"
**知识库依据**: 价值拆解法比直接降价更能保住利润

### 话术 3.2 (对比型)

```
理解你想要好价格！
同款现在电商平台还在卖XX元
我这个几乎没怎么穿，价格已经是对折都不到了
而且还包邮+支持验货，这个保障别的卖家不一定给~
```

**适用**: 买家拿其他渠道价格对比
**技巧**:
- 承认对方需求（"理解"开头）
- 用平台价对比而非其他卖家
- 强调差异化（包邮+验货）
**知识库依据**: 对比电商平台比对比同类卖家更有说服力

### 话术 3.3 (真诚型)

```
说实话，这个价格我已经没什么利润空间了😅
主要是自己穿不上了，想让它去到需要的人手里
价格真的是按闲置出的，不是做生意的那种~
```

**适用**: 个人卖家人设，买家怀疑是商家
**技巧**:
- 用表情符号增加真实感
- 强调"闲置"而非"卖货"
- 弱化商业属性
**知识库依据**: 个人卖家标签能降低议价预期

---

## 阶段 4: 突出附加价值

### 话术 4.1 (保障强化型)

```
对了，再说一下咱们的保障：
📦 包邮发顺丰，3-5天到
✅ 支持到付验货，不满意直接拒收
📸 发货前拍视频，有任何问题都有证据

这些保障加起来，心里也更踏实对吧~
```

**目的**: 转移价格焦点，强调服务价值
**技巧**:
- 用 icon 增强视觉冲击
- "到付验货"是强信任信号
- 最后引导认同
**知识库依据**: 服务价值能抵消 10-15% 的价格敏感度

### 话术 4.2 (附赠品型)

```
这样吧，价格咱保持不变
我送你一个配件/小礼物（原本打算自己留的）
这样你觉得怎么样？😊
```

**适用**: 价格已到底线，但买家还在纠结
**技巧**:
- 附赠品代替降价
- 强调"原本自己留的"增加价值感
- 给买家台阶下
**知识库依据**: 附赠品策略比降价更能保住利润和价格体系

## 阶段 5: 促成交易

### 话术 5.1 (限时优惠型)

```
这样吧，看你也是真心想要
今天如果能定下来，我给你包顺丰（原本是普通快递）
但这个优惠只能是今天哈，因为还有其他人在问~
```

**目的**: 制造紧迫感，促进决策
**技巧**:
- 给小额让步（升级快递而非降价）
- 设定时间限制
- 暗示竞争（其他人在问）
**知识库依据**: 限时策略能提升 30% 的即时成交率

### 话术 5.2 (友好结束型)

```
价格这块真的是底价了，没法再降了呢😅
不过如果你还在犹豫，可以先收藏
有问题随时来问我，我一直在的~
```

**适用**: 价格谈不拢，但不想关系僵化
**技巧**:
- 坚持底线但态度友好
- 引导收藏（为后续回流留机会）
- 保持开放态度
**知识库依据**: 20% 的成交来自收藏后的二次咨询

### 话术 5.3 (反向成交型)

```
理解你的预算，不过这个价格确实是我的底线了
要不你再考虑考虑？
如果真的很喜欢，咱们就定下来
如果预算实在不够，也可以看看我店里其他款~
```

**目的**: 反向施压，促进决策
**技巧**:
- 不过分挽留，保持从容
- "你再考虑考虑"制造心理压力
- 提供替代方案（店内其他款）
**知识库依据**: 适度冷处理比过度热情更能促成交

## 🚨 应对常见异议

### 异议 1: "太贵了，XX元行吗？"（报价远低于预期）

**话术**:
```
XX元确实有点低了呢，这个价格连运费都不够😅
我能理解你想要好价格，但咱这个真的是按闲置价出的
要不这样，你看（上述价格）行吗？这已经是我能给的底价了~
```

**策略**: 先拒绝离谱报价 → 解释原因 → 给出可接受范围

---

### 异议 2: "别人家更便宜"

**话术**:
```
能理解你对比了很多家！
不过价格低的要注意看一下：
- 成色是不是比我这个差
- 是不是包邮（不包邮要加运费）
- 能不能验货（有些不支持）

如果对比下来条件一样，那确实那家更合适
如果条件不同，咱还是要看实际到手成本和保障哈~
```

**策略**: 不否定对方信息 → 引导理性对比 → 强化自己优势

---

### 异议 3: "我考虑考虑"（拖延决策）

**话术**:
```
好的呢，理解需要时间考虑~
不过要提醒一下，现在还有2个人在问
如果真心喜欢建议尽快定，不然可能被别人拍了😊
有任何问题随时问我，我都在线的！
```

**策略**: 同意但制造紧迫感 → 强调竞争 → 保持联系

---

### 异议 4: "能不能再便宜点？"（已经接近成交价）

**话术**:
```
看你这么有诚意，那我也表示一下
价格不能再降了，但我给你升级快递/送小礼物
咱们就这样定了吧，现在拍我马上给你发~
```

**策略**: 认可诚意 → 非价格让步 → 快速推进成交

### 实战技巧

1. **响应时间**
   - 首次咨询尽量 5 分钟内回复
   - 议价过程中回复不要太快（30秒-2分钟），显得从容

2. **让步策略**
   - 第一次议价：拒绝或微调（5-10元）
   - 第二次议价：给附加价值（升级快递/送礼物）
   - 第三次议价：如还纠缠，使用反向成交

3. **成交信号识别**
   - 买家问细节（尺寸、成色、发货时间）→ 高意向
   - 买家问能否验货 → 准备下单
   - 买家问优惠 → 在价格和决策之间摇摆
   - 识别后立即推进，不要拖延

### 数据追踪建议

- 议价成功率（让步后成交的比例）
- 各话术的使用频率和效果
