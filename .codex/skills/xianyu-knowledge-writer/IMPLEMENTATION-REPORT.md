## 🐛 遇到的问题和解决方案

### 问题 1: Windows 控制台 UTF-8 编码

**现象**: 
- 运行 `skill_utils.py` 时，emoji 和中文输出乱码
- 错误信息: `UnicodeEncodeError: 'gbk' codec can't encode character`

**原因**:
- Windows 默认使用 GBK 编码
- Python 输出包含 emoji（✓、❌ 等）无法用 GBK 编码

**解决方案**:
```python
import sys
import io
if sys.platform == 'win32':
    sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
```

**结果**: ✅ 成功解决，所有中文和符号正常显示

### 问题 2: 知识库路径配置

**现象**:
- Skill 和知识库在不同目录
- 需要灵活配置路径

**解决方案**:
- 构造函数支持 `kb_root` 参数
- 默认使用绝对路径 `D:\项目仓库\闲鱼知识库`
- 动态将 `scripts/` 目录添加到 `sys.path`

**结果**: ✅ 知识库 API 成功加载

### 问题 3: 违规词"最低价"

**现象**:
- 用户输入卖点包含"最低价"
- 这是闲鱼平台的违规词

**解决方案**:
- 在示例中展示了检测和替代流程
- 提供替代词: "底价"、"诚心价"、"底线"
- 在客服话术中全部使用合规表达

**结果**: ✅ 成功展示了合规修正流程
